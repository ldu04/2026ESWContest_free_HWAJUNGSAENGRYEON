> **⚠ 지위 공지 (2026-08-18).** 이 문서의 **체류 8초·전선속도 0.22cm/s·임계 60℃ 언급은 구버전**이다. 현행: 임계 **80℃**(config.h), 체류 = **당일교정 round(1.7×t80)**, 상한 22초 — 설계헌장_데모_2026-08-17이 우선한다. 45° 거치 전환으로 t80 재측정 후 본 문서의 수치표는 전면 재계산 예정. **방향 참값(75.96°/71.57°/55.67°)은 체류시간 무관이라 유효.**

# D1 — 축소 리허설 체크리스트
### 목표일 **8/19**. 이 날짜가 전체 일정의 단 하나의 핵심.

---

## 이 리허설의 목적

```
정확도를 재는 것이 아니다.  파이프라인이 끝까지 도는지를 본다.
```

열원 조건을 확정했다는 건 **물리적으로 가능하다**는 뜻이지 **소프트웨어가 동작한다**는 뜻이 아니다.
아래 경로는 **아직 한 번도 전 구간이 돌아본 적이 없다.**

```
열 → 센서 → 사망 판정 → 임종신호 → 메시 라우팅 → 게이트웨이
    → 시각 각인 → 좌표 결합 → 국소 평면적합 → 가중 집계 → 대시보드
```

16개를 다 조립한 뒤 여기서 막히면 되돌리는 비용이 크다. **4~6개면 같은 경로를 전부 통과한다.**

## 배치 선택 — 6노드(3×2)를 권장

| 배치 | 이론 방향 | 추정 산포 | DOF | 총 소요 | 판정 |
|---|---|---|---|---|---|
| 2×2 (4노드) | 63.43° | ± 0.87° | **1** | 32 초 | 최소선. 잔차 진단이 겨우 작동 |
| **3×2 (6노드)** | **71.57°** | **± 0.35°** | **3** | 48 초 | ✅ **권장** |
| 3×3 (9노드) | 71.57° | ± 0.28° | 6 | 72 초 | 여유 있으면 |

> 산포는 사망 지터 0.28초 가정, 4000회 몬테카를로. **체류 8초 기준**이다.

**노드 2개 더 붙이는 비용으로 자유도가 1 → 3이 된다.** 명세가 `residual_min_samples`를 3→4로 올린 이유가 DOF ≥ 1 강제였는데, 4노드는 딱 그 하한이라 잔차 기반 이상탐지가 사실상 무력하다. 6노드면 진단이 의미를 갖는다.


## 사전등록 예측 (실행 전에 적고 봉인)

**행 우선 순서 n01→n02→n03→n04→n05→n06, 각 8초 균일 체류**

```
열원 조건   설정 400℃ · 풍량 10 · 노즐~노드 4cm · 공기 190.5℃ (2026-08-16 실측)

예측 방향   = atan2(3, 1) = 71.57°
예측 속도   = h / (d·√10) = 20 / (8·3.162) = 0.791 cm/s
예측 사망시각 = n01:0s  n02:8s  n03:16s  n04:24s  n05:32s  n06:40s
예측 n_eff  = 6.0
예측 방향 산포 = ± 0.35°  (σ_death 0.28초 가정)
```

> **체류가 6초가 아니라 8초인 이유.** 제트 반폭 실측이 1.15cm(예측 0.78cm보다 48% 넓음)로 나오면서,
> 6초 체류는 조준 허용오차가 **±0.58cm**뿐이라는 것이 드러났다. 노드 16개를 연속으로 그 정밀도로
> 겨누는 것은 현실적이지 않다. 8초로 늘리면 **±0.90cm**가 되고, τ가 20~25초 어디에 있든 유지된다.
> 방향 예측은 체류시간과 무관하므로 71.57°는 그대로다. 속도만 바뀐다.

> **3×2에서 방향 공식이 atan2(3,1)인 이유:** 한 행에 3개이므로 `t = (3k+i)·d`, 즉 `t = (d/h)x + (3d/h)y`.
> 일반식: **한 행에 m개이면 방향 = atan2(m, 1), 속도 = h/(d·√(1+m²))**
