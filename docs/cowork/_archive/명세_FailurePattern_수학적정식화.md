# Failure Pattern 알고리즘 — 수학적 명세
### 「불사」· 죽음시각 집합에서 화재 전선의 방향·속도·ETA를 추정하는 절차의 형식적 기술

> **목적:** 지금까지 코드와 실험으로 흩어져 있던 추정 절차를 하나의 형식적 기술로 정리한다. 이 문서는 (a) 제출물의 알고리즘 서술 원본이자 (b) **암묵적으로 깔려 있던 가정을 드러내는 장치**다. 실제로 아래 §7~§9는 우리가 실험에서 부딪힌 실패 모드들이 어느 가정에서 나오는지 보여준다.
>
> **표기 규약:** 벡터는 굵게 쓰지 않고 성분으로 적는다. 용어는 처음 나올 때 괄호로 뜻을 푼다(강령 C-9).

---

## 1. 문제 정의

**도착시각장(arrival-time field) T(x, y):** 위치 (x, y)에 화재 전선이 도달하는 시각. 공간 위에 정의된 스칼라 함수다.

**관측:** 노드 i가 위치 (xᵢ, yᵢ)에 있고, 그 노드가 죽은 시각 tᵢ를 보고한다. 이때

```
tᵢ = T(xᵢ, yᵢ) + dᵢ + εᵢ
```

- `dᵢ` : 노드 i의 **체계적 지연**(센서 열시상수 τ에 의한 임계 교차 지연 등)
- `εᵢ` : 랜덤 오차(양자화, 통신, 위치 오차 등)

**추정 목표:** 관측 집합 {(xᵢ, yᵢ, tᵢ)}로부터 전선의 **진행 방향 n̂**, **속도 s**, 그리고 특정 지점의 **도착예상시각 ETA**를 얻는다.

## 2. 모델 가정

| 번호 | 가정 | 위배 시 나타나는 현상 |
|---|---|---|
| **A1** | **국소 평면성** — 적합 창(window) 안에서 T가 (x,y)의 1차 함수로 근사됨 | 강곡률 전선에서 방향오차 증가 (§9-1) |
| **A2** | **국소 등속** — 창 안에서 전선 속도가 일정 | 가감속 구간에서 속도·ETA 편향 |
| **A3** | **노드 좌표 정확** — (xᵢ, yᵢ)를 오차 없이 앎 | 배치 오차가 기울기에 직접 전파 |
| **A4** | **공통 시계** — 모든 tᵢ가 같은 시간축 | 보드별 `millis()` 사용 시 원리적 파탄 (§9-4) |
| **A5** | **죽음 = 화재 도달** — 침묵의 원인이 화재임 | 통신두절·전원소진이 가짜 사망으로 유입 (§9-5) |
| **A6** | **창 내 이웃 충분** — 적합에 필요한 최소 관측 수 확보 | 방향 추정 자체가 불가 (§9-2) |

## 3. 평면 최소자승 적합

A1에 따라 창 안에서

```
T(x, y) ≈ a·x + b·y + c
```

로 두고, 잔차 제곱합을 최소화하는 (a, b, c)를 구한다.

```
(â, b̂, ĉ) = argmin  Σᵢ [ tᵢ − (a·xᵢ + b·yᵢ + c) ]²
```

**행렬 형태.** 설계행렬(design matrix) M과 관측벡터 t를

```
M = ⎡ x₁  y₁  1 ⎤        t = ( t₁, t₂, …, t_N )ᵀ
    ⎢ x₂  y₂  1 ⎥
    ⎢  ⋮   ⋮  ⋮ ⎥
    ⎣ x_N y_N 1 ⎦
```

로 두면 정규방정식(normal equation)은

```
(Mᵀ M) θ̂ = Mᵀ t ,      θ̂ = (â, b̂, ĉ)ᵀ
```

이고, MᵀM이 가역이면

```
θ̂ = (Mᵀ M)⁻¹ Mᵀ t
```

**자유도(DOF, degree of freedom) = N − 3.** 미지수가 3개이므로 관측이 3개면 DOF=0이 되어 **잔차가 항상 0**이 된다. 즉 노이즈가 전혀 감쇠되지 않고 추정치에 그대로 통과한다. (희소 노드 배치에서 관측된 붕괴의 형식적 원인.)

---

## 4. 방향과 속도의 유도

전선이 방향 n̂(단위벡터)으로 속도 s로 등속 진행한다고 하자. 시각 t에서 전선의 위치는 초기 전선을 p₀ 기준으로

```
(x − p₀) · n̂ = s · t
```

를 만족하는 점들의 집합이다. 따라서 점 x가 도달되는 시각은

```
T(x) = ( (x − p₀) · n̂ ) / s
```

양변의 기울기를 취하면

```
∇T = n̂ / s
```

여기서 두 결과가 바로 나온다.

```
|∇T| = 1/s          →     s = 1 / |∇T|
∇T / |∇T| = n̂       →     n̂ = ∇T / |∇T|
```

적합 결과를 대입하면 `∇T ≈ (â, b̂)` 이므로

```
방향:  n̂ = (â, b̂) / √(â² + b̂²)
속도:  s = 1 / √(â² + b̂²)
```

**주의(속도의 구조적 약점).** 속도는 기울기 크기의 **역수(reciprocal)**다. 역수는 볼록함수이므로 옌센 부등식(Jensen's inequality)에 의해 `E[1/|∇T|] ≥ 1/E[|∇T|]` 가 되어, 노이즈가 있을 때 **속도 추정에 상방 편향(과대추정)**이 생긴다. 방향에는 이 편향이 없다.

---

## 5. ETA — 방향·속도와 구조가 다른 이유

목표 지점 x* = (x*, y*)의 도착예상시각은

```
ETA(x*) = â·x* + b̂·y* + ĉ
```

**핵심:** 방향과 속도는 (â, b̂)만 쓰지만, **ETA는 절편 ĉ를 반드시 쓴다.**

이것이 §7에서 보일 비대칭의 원인이다 — **균일 지연은 ĉ에만 흡수되므로 방향·속도는 보존되지만 ETA는 그대로 편향된다.**

---

## 6. 오차 전파

관측 오차가 독립·동일분산 σ²라 가정하면 추정치의 공분산은

```
Cov(θ̂) = σ² (Mᵀ M)⁻¹
```

**기울기 오차를 두 성분으로 분해한다.** 참 기울기 ∇T에 대해, 오차 δ∇T를

- `δ∥` : ∇T와 **평행한** 성분 (크기 방향)
- `δ⊥` : ∇T에 **수직한** 성분 (방향 회전)

으로 나누면, 1차 근사에서

```
방향(각) 오차:      δφ  ≈  δ⊥ / |∇T|                [rad]
속도 상대오차:      δs/s ≈  δ∥ / |∇T|
```

**여기서 중요한 관찰 하나.** 두 식의 분모가 같다. 즉 **등방성 노이즈 아래에서 방향과 속도는 절대적 민감도가 비슷하다.** 그럼에도 실험에서 "지터 τ에 방향은 196배, 속도는 1.2~23배 나빠졌다"처럼 **배율이 크게 달라 보이는 이유는 기준선(baseline)이 다르기 때문**이다. 방향의 균일τ 기준선은 0.345°(≈0.006 rad)로 극히 작아 배율이 폭발적으로 보이고, 각도는 90°에서 포화한다.

> **→ 그러므로 방향과 속도의 취약성은 배율이 아니라 절대오차로 비교해야 한다.** (강령 §A-3의 형식적 근거.)

**분모의 함의:** |∇T| = 1/s 이므로, **전선이 빠를수록(s 큼) |∇T|가 작아져 두 오차가 모두 커진다.** 빠른 화재가 추정에 불리하다는 것이 식에서 직접 나온다.

---

## 7. 센서 지연 τ의 형식적 효과

센서는 공기온도를 1차 지연(first-order lag)으로 따라간다.

```
dT_sensor/dt = ( T_air − T_sensor ) / τ
```

죽음은 T_sensor가 임계 T_th를 넘을 때 기록되므로, 실제 공기가 임계를 넘은 시각보다 **dᵢ만큼 늦게** 찍힌다. 관측식은 §1의

```
tᵢ = T(xᵢ, yᵢ) + dᵢ + εᵢ
```

이다. 여기서 dᵢ의 성질에 따라 세 경우로 갈린다.

**(1) 균일 지연 (dᵢ = d, 모든 i에 동일).**
평면 적합에서 상수항은 ĉ에 흡수된다.

```
â, b̂ 불변  →  방향·속도 불변
ĉ → ĉ + d   →  ETA가 d만큼 편향
```

**→ 방향·속도는 균일 지연에 원리적으로 면역이고, ETA만 보정이 필요하다.** (§5에서 예고한 비대칭의 증명.)

**(2) 노드별 편차 (dᵢ가 제각각).**
편차는 상수로 흡수되지 않고 **잔차에 그대로 남아 εᵢ와 같은 역할**을 한다. 따라서 방향·속도·ETA가 **모두** 열화한다. σ_d가 커질수록 §6의 δ⊥, δ∥가 커진다.

**(3) 균일 τ인데도 dᵢ가 불균일해지는 경우 (2차 효과).**
dᵢ는 τ만이 아니라 **그 노드에서의 온도 상승률**에도 의존한다. 임계 근처에서 공기온도가 빠르게 오르면 지연이 짧고, 느리게 오르면 길다. 곡선 전선에서는 노드마다 전선과의 기하 관계가 달라 상승률이 다르므로, **τ가 완전히 균일해도 dᵢ가 불균일해진다.**

> **→ 이것이 (1)의 면역이 실제로는 부분적인 이유이고, 실험에서 곡선 전선의 균일τ 오차가 직선보다 컸던 현상의 형식적 설명이다.**

## 8. 탐지·판별 게이트

죽음 이벤트가 곧바로 적합에 들어가지는 않는다. 두 개의 문턱이 직렬로 작동한다.

```
① 탐지 임계 T_th   : 센서 온도가 이 값을 넘으면 사망 후보
② 판별 게이트      : 사망 후보 중 화재로 인정되는 것만 적합에 채택
```

**중요한 구조적 사실:** 단일 스칼라 임계 T_th는 **방아쇠(trigger)와 판별자(discriminator)를 겸할 수 없다.** T_th를 낮추면 ①은 개선되지만 ②의 변별력이 무너진다 — 실험에서 임계를 40~50℃로 낮췄을 때 (게이트를 고정하면) 채택률이 0이 되고, (게이트를 함께 낮추면) 비화재 오염이 폭증한 것이 이 사실의 발현이다.

**→ 임계 하향으로 τ를 구제할 수 없다는 결론의 형식적 근거.** 구제하려면 온도 이외의 판별 축(상승률, 공간 상관 등)이 필요하다.

## 9. 알려진 한계 — 각각 어느 가정에서 나오는가

**9-1. 곡률 한계 (A1 위배).**
강하게 굽은 전선에서는 창 안에서 T가 1차 함수로 근사되지 않는다. τ=0에서도 방향오차가 남는 것이 이 때문이며, **τ 문제와 독립적인 별개 한계**다.

**9-2. 적합 창 요건 (A6).**
창 폭 W 안에 이웃의 사망이 들어와야 적합이 성립한다. 노드 간격 h, 전선 속도 s일 때 이웃 사망 간격은 대략 `h/s`이므로, 최소 K개의 이웃을 확보하려면

```
W  ≳  K · h / s
```

가 필요하다. **s가 작으면(느린 화재) 우변이 커져 고정된 W로는 이웃이 창에 들어오지 않는다.** 이때 방향 추정은 오차가 커지는 게 아니라 **아예 불가능**해진다. (평면 3파라미터이므로 K ≥ 3이 하한이고, 실용적으로는 여유가 더 필요하다.)

**9-3. 속도의 역수 편향 (§4).**
s = 1/|∇T|의 볼록성에 의한 상방 편향. 방향에는 없고 속도·ETA에만 있다.

**9-4. 공통 시계 요건 (A4).**
서로 다른 노드의 시각을 같은 축에서 빼는 연산이므로, 보드마다 기준이 다른 시계(예: 부팅 기준 `millis()`)를 쓰면 ∇T가 **원리적으로** 무의미해진다. 노드 각인 동기 시각을 써야 한다.

**9-5. 사망 원인 판별 (A5).**
침묵의 원인은 화재 외에도 통신두절·전원소진·크래시가 있다. 가짜 사망은 도착시각장에 잘못된 표본을 주입해 적합 전체를 오염시킨다. 이 가정은 §8의 판별 게이트와 별도의 방어를 요구한다.

**9-6. 표본화 한계(Nyquist).**
노드의 죽음은 도착시각장의 **표본**이다. 표본 간격이 대략 h/s이므로, 그보다 빠른 시간 규모의 전선 변동(돌풍에 의한 방향 요동 등)은 원리적으로 복원할 수 없다.

## 10. 요약

```
입력 : {(xᵢ, yᵢ, tᵢ)}  — 노드 좌표와 노드 각인 죽음시각
적합 : θ̂ = (MᵀM)⁻¹Mᵀt,  T(x,y) ≈ âx + b̂y + ĉ
출력 : n̂ = (â,b̂)/|(â,b̂)|        (방향)
       s  = 1/|(â,b̂)|            (속도, 상방편향 존재)
       ETA(x*) = âx* + b̂y* + ĉ   (절편 사용 → 균일지연에 취약)
```

**구조적 성질 세 줄:**
1. 방향·속도는 **기울기만** 쓰므로 균일 지연에 면역, ETA는 **절편**을 써서 취약하다.
2. 방향·속도의 오차는 둘 다 `1/|∇T|`에 비례 — **절대오차로 비교해야** 하고, 빠른 전선일수록 불리하다.
3. 자유도 N−3, 창 요건 `W ≳ K·h/s`, 국소 평면성 — 이 셋이 적합이 성립하기 위한 최소 조건이다.
