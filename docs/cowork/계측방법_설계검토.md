# 계측 방법 설계 검토
### 2026-08-16. 200℃ 검증 진행 중에 작성.

---

## 1. 먼저 — 아직 없는 데이터가 무엇인가

| 항목 | 상태 | 이것이 정하는 것 |
|---|---|---|
| 축방향 감쇠 f(x) | ✅ 확보 (R²=0.991) | 설정온도 × 거리 → 공기온도 |
| 설정온도 선형성 | ⏳ 200℃ 검증 중 | 위 표를 400℃까지 믿을 수 있는가 |
| **반경 프로파일 f(r)** | ❌ **없음** | **격자 간격 · 조준 허용오차** |
| 데모 조건 절대 τ | ❌ 없음 (1~2회면 됨) | 사망 시각 |
| σ_τ (개체차) | ❌ 실패 | → 리허설 잔차로 대체 |

**★ 반경 프로파일이 지금 최대 공백입니다.**

"노즐을 노드에서 몇 cm까지 빗나가도 죽는가"를 모르면
- 격자 간격을 정할 수 없고 (이웃이 같이 죽는지)
- 데모에서 손으로 조준할 때 허용오차를 모릅니다

이게 D1 리허설(8/19)보다 앞서야 하는 유일한 계측입니다.

## 2. 수직 배치 검토

### 유리한 점

**① 제트가 프로브를 홈에 눌러준다**
지금 수평 배치에서는 제트가 프로브를 옆으로 밀어냅니다. 수직 하향이면 **공기 힘이 중력과 같은 방향**이라 고정을 도와줍니다. 우리가 겪은 고정 문제의 근본 원인이 사라집니다.

**② 반경 프로파일이 그냥 나온다**
프로브를 홈에서 **좌우로 밀기만 하면** 축방향 거리는 그대로 둔 채 반경만 바뀝니다.
```
     [노즐]
        ║
        ▼
  ──●───────────  r = 0     (팁이 축 위)
  ────●─────────  r = 1cm
  ──────●───────  r = 2cm
```
수평 배치에서는 이걸 하려면 열풍기나 받침을 통째로 옆으로 옮겨야 합니다.

**③ 거리 변경이 눈금이 아니라 개수로 바뀐다**
받침 아래에 같은 두께 판을 넣고 빼면 거리가 정해집니다. "대충 8cm"가 아니라 "3장"이 되어 재현성이 올라갑니다.

**④ 뜨거운 공기가 위로 빠진다**
제트가 프로브를 지나 아래로 갔다가 옆으로 퍼지며 상승합니다. 프로브 쪽으로 되돌아오는 양이 수평보다 적습니다.

**⑤ 받침을 타일로 바꾸기 쉽다**
평평한 타일 한 장이면 끝. 지금처럼 높이를 쌓아 맞출 필요가 없습니다.

### 불리한 점

**① 열풍기를 세워 고정해야 한다** — 이게 유일한 진짜 비용입니다.
- 책 두 더미 사이에 총열을 세로로 끼우고 테이프
- 의자 등받이·선반 모서리에 묶기
- **노즐이 아래를 향하고 손을 떼도 안 흔들려야** 함

**② 지금까지의 τ와 조건이 다르다** — 축방향 관통 → 수직 충돌(crossflow)로 바뀌므로 h가 달라지고 τ도 달라집니다.
> 다만 **이건 오히려 장점이 될 수 있습니다.** 원통 crossflow는 Nu-Re 상관식이 교과서적으로 정립된 조건이라, τ ∝ u^(−1/2) 논증의 근거가 더 단단해집니다.

**③ 프로브 팁이 제트 축에 오도록 맞추는 문제는 그대로** — 홈에 눈금을 그어 해결

## 3. 그래서 어떻게 할 것인가 — 세 가지 안

### 안 A. 지금 수평 그대로, 열풍기를 옆으로 옮겨 반경 측정
```
비용   0 (추가 제작 없음)
방법   판에 열풍기 좌우 위치를 1cm 간격으로 표시 → 열풍기만 옮김
약점   열풍기를 옮길 때마다 축방향 거리도 흔들린다 (지금 겪은 문제 그대로)
```

### 안 B. ★ 수직 하향으로 재구성
```
비용   열풍기 세울 거치대 만들기 (30분) + 타일 한 장
이득   반경 프로파일이 쉽게 나옴 · 고정 문제가 구조적으로 해소 · 400℃ 가능
약점   기존 τ 데이터와 조건 단절 (어차피 재측정 예정이라 손실 작음)
```

### 안 C. 반경 프로파일을 포기하고 리허설에서 확인
```
비용   0
방법   D1 리허설에서 노드 하나를 겨누고, 옆 노드가 같이 죽는지 본다
약점   정량값이 안 나옴. 격자 간격을 보수적으로(넓게) 잡아야 함
```

## 4. 권고

**안 B(수직) → 반경 프로파일 → 데모 조건 τ → D1 리허설**

이유:
1. **반경 프로파일은 D1 전에 필요**하고, 수직이 그걸 가장 싸게 줍니다
2. 고정 문제로 오늘 하루를 썼는데, 수직은 그 문제의 **원인 자체**를 없앱니다 (제트가 누르는 방향)
3. 데모를 400℃로 갈 가능성이 있고, 그러려면 어차피 타일 받침이 필요합니다
4. 기존 τ 데이터는 σ_τ 용도로는 이미 폐기했으므로 조건 단절의 손실이 없습니다

**단, 거치대가 30분 안에 안정적으로 안 만들어지면 안 C로 후퇴하세요.** 반경 프로파일은 있으면 좋은 것이지 D1을 막는 것은 아닙니다 — 없으면 격자를 25cm로 넓게 잡고 가면 됩니다.

## 5. 수직 배치 설계 (안 B 채택 시)

```
          ┌───┐
          │열 │  ← 책 두 더미 사이에 세로로 끼워 테이프
          │풍 │     노즐이 정확히 아래를 향할 것
          │기 │
          └─╥─┘
            ║  h = 축방향 거리
            ▼
   ─────────●─────────────   ← 프로브. 홈에 눕히고 좌우로 밀어 r 조절
   ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓   ← 받침 (타일). 두께 판을 넣고 빼서 h 조절
   ═══════════════════════   ← 바닥판
```

**만들기**
1. 열풍기를 책 두 더미 사이에 세로로 끼우고 테이프로 고정 — 노즐이 아래
2. 노즐 바로 아래에 타일을 놓고, 그 위에 젓가락 2개로 홈을 만든다 (제트와 **직각** 방향)
3. 홈 옆에 **0, ±0.5, ±1, ±1.5, ±2, ±3 cm** 눈금 (0 = 노즐 정중앙 아래)
4. 프로브를 홈에 눕히고 팁이 눈금 0에 오게
5. 높이 조절용 판(같은 두께 여러 장)을 타일 아래에 준비

**측정 1 — 반경 프로파일** (데모 예정 거리 하나에서)
```
r = 0 → 0.5 → 1 → 1.5 → 2 → 3 cm 로 밀며 각 평탄값 기록
→ 살상 반경 = 공기가 60℃ 이상인 최대 r
→ 격자 간격 ≥ 2 × 살상 반경
→ 조준 허용오차 = 살상 반경
```

**측정 2 — 축방향 재확인** (수평에서 얻은 f(x)가 수직에서도 맞는지)
```
h = 3, 5, 8, 12 cm 에서 r=0 평탄값
→ 수평 f(x)와 비교. 비슷하면 기존 표를 그대로 씀
```

**측정 3 — 데모 조건 τ** (1~2회)
```
확정된 (설정, h, r=0)에서 τ 측정
→ 사망 시각 계산의 근거
```
