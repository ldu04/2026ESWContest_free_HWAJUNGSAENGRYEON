## 2.I-a · ★ 대τ 감쇠 → 검출 실패 시험 (최우선 — 구멍 점검)

**동기.** τ가 온도 펄스 폭(~20s)에 근접·초과하면 센서 최고값이 감쇠돼 80℃에 못 미치고 → **노드가 죽음을 놓친다.** 이건 −6.4초 지연보다 날카로운 실패다: **검출 자체가 안 됨.** 실물 DS18B20이 공기 중에서 τ 수십 초일 수 있으니(B2), 우리 τ/재구성 이야기가 이 지점에서 무너지는지 지금 확인한다.

**시험 설계 (estimator 불변, 환경 모델만):**
1. **t_max 연장**(예: 120→300s) — 느린 센서가 펄스 상승을 끝까지 겪게. 단, 펄스가 지나가 식으면 t_max 늘려도 못 살아나니, **"지연 사망"과 "검출 실패"를 분리해서** 집계.
2. **τ 스윕:** {0, 2, 5, 10, 20, 30, 45, 60}s, 균일·변동 모드, S1·S2a·S6·S7 이상.
3. **지표:**
   - **검출 실패율:** 센서 최고값이 80℃에 못 미친 노드 비율(진짜 화재 노출인데 죽음 신호 없음).
   - **최고값 감쇠:** 참 최고온도 vs 센서 최고온도(τ 함수).
   - **사망 지연**(죽는 노드): 기존대로.
   - **재구성 회복:** 2.H 역보상(T_air=T_sensor+τ·dT/dt)이 감쇠된 최고값·사망시각을 얼마나 되살리나. (감쇠가 심하면 미분 신호가 약해 회복 한계 — 그 한계를 측정.)
   - **파단점:** 검출 실패율이 임계(예: 5~10%)를 넘는 τ.
4. **속도 상호작용(가능하면):** 화선이 빠를수록 펄스가 짧아 같은 τ에서 더 나쁨 → 검출 실패는 대략 **τ/펄스폭**의 함수. 두어 속도로 확인하거나 의존성만 기록.

**안전 방향 주의:** 검출 실패 = 그 지점에 "불이 왔는지 모른다" = 그 구역을 미연소로 오인 → **위험측 실패**다. 도착시각장에 구멍 = 추정 해상도·정확도 저하.

**산출·결론:** "임계 검출 기제는 **τ ≤ __s(1.5m/s 기준)**에서 유효, 그 이상은 감쇠로 검출 실패. → 실물 τ를 반드시 실측(H1)하고, 한계 초과 시 **더 빠른 센서(맨몸) / 낮은 임계 / 상승기반 트리거**가 필요." **완화 후보(제안만, 이번엔 미구현):** ★**상승 기반(dT/dt) 트리거** — 지연된 최고값 대신 **빠른 온도 상승 자체**를 감지하면 감쇠와 무관하게 펄스 도중 트리거 가능(펌웨어 설계 지렛대). / 낮은 임계(단 오탐 위험) / 적응형 하트비트(2.I-c, 펄스 포착 도움).

## 2.I-b · A2 온도 형태 미스매치 게이트 (깊은 tautology 한 겹)

**동기.** −6.4초·warm_scale·E3 편향 전부가 `T(d)=T_amb+ΔT·exp(−d/warm_scale)`의 **지수 형태**에서 나온다. 2.F는 warm_scale **크기**(±50%)만 흔들었지 **형태**는 고정이었다. 현실 예열이 비지수면 크기 ±50%로 못 잡는다.

**시험 설계 (2.F/2.G 게이트 형식, E3x2 편향항 고정=재적합 금지):**
1. `_temp_from_d`에 **`temp_form` config 분기** 추가(D#3대로 단일 메서드라 쉬움).
2. 정답 온도를 **질적으로 다른 형태 여럿**으로 생성: 지수(기준) / 선형 감쇠 / 거듭제곱 / **화선 앞 급-뒤 완만(바람 기운 예열 모사, 긴 꼬리)**. 형태들은 **물리·타당성에서 선택**(점수 보고 고르기 금지).
3. **배포 estimator + E3x2 밴드는 지수에서 도출한 값 그대로 고정**(현실 형태는 모른다는 게 핵심 — 형태마다 재적합하면 tautology).
4. 각 형태에서 S2~S11 **커버리지 + breach_early(위험측)** 측정.
5. **판정:** (A) E3x2가 형태 전반에서 유지 → 형태 불확실성에 강건. (B) 추가 팽창 필요 → E3x3 배율·폭. (C) 형태 미스매치가 무너뜨림 → **"형태를 실측해야"** — H1 warm_scale 시험이 단순 지수 적합이 아니라 **실제 T(d) 모양을 기록**해야 한다는 하드웨어 요구로 연결.

## 2.I-c · 적응형 하트비트 (재구성 천장 올리기 + 2.I-a 완화)

**동기.** D#9 — heartbeat 1s 고정이 2.H 1b 매치드 천장(강풍 63~76%)의 직접 원인(1s라 수치 미분 거침). 온도 적응형 보고가 가장 직접적 완화 수단이고, 2.I-a의 펄스 포착에도 도움.

**시험 설계:**
1. **온도/dT-dt 적응형 보고:** 노드가 **뜨겁거나 dT/dt가 빠를 때** 보고 주기를 단축(예: 평상 1s → 상승 감지 시 100~250ms). 트리거 문턱은 **S1 baseline 노이즈/물리에서 도출**(테스트 점수 금지).
2. **측정:** ①2.H 1b 재구성 천장 개선(강풍 63~76% → ?) ②사망시각 정밀도 개선 ③**2.I-a 검출 실패 완화**(빠른 표집이 감쇠 펄스를 더 잘 잡나) ④비용(뜨거울 때 메시지 증가 — 단 뜨거운 노드는 곧 죽으니 대개 허용, 대역/전력 영향만 기록).
3. **예측(착수 전 docstring):** 적응형이 재구성 천장을 올리고 사망시각 정밀↑ 예상. 측정으로 확정.
4. **펌웨어 정합:** H0 펌웨어에 이미 넣은 9비트 고속 모드가 이것의 하드웨어 짝 — 시뮬·펌웨어 로직을 일관되게.
