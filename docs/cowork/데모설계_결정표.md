## ★ 핵심 발견 — 열풍기의 이동 경로가 곧 "전선(front)"이다

노드를 하나씩 순차로 죽일 때, **어떤 순서로 죽이느냐가 알고리즘이 보는 화재 방향을 결정한다.** 이건 연출의 문제가 아니라 물리 입력의 문제다.

4×4 격자(간격 h), 각 노드에 균일 체류 d초로 계산한 결과:

| 경로 | 사망시각이 이루는 평면 | 방향 | 속도 | 평면적합 최대잔차 | n_eff |
|---|---|---|---|---|---|
| **행 우선** (n01→n16 순서대로) | **완전한 평면** | **75.96°** | h/(d√17) | **0.00 s** | 16.0 |
| **열 우선** (열 단위로) | **완전한 평면** | **14.04°** | h/(d√17) | **0.00 s** | 16.0 |
| 뱀형(지그재그) | **평면 아님** | 90.00° | 0.833 | **9.00 s** | 12.5 |

> 잡음 σ=0.28s를 넣고 50회 반복해도 행 우선 **75.98° ± 0.17°**, 속도 **0.809 ± 0.002 cm/s**.

### 결론 1 — 실행이 가장 쉬운 방법이 이미 정답이다
```
n01부터 n16까지 번호 순서대로, 각 노드에 같은 시간씩.
그것이 정확히 75.96° 방향, 속도 h/(d√17) 의 전선이다.
```
복잡한 스윕 궤적을 만들 필요가 없다. **순서대로 지지면 된다.**

이유: 행 우선 순서에서 사망시각은 `t = (d/h)·x + (4d/h)·y`가 되고, 이는 정의상 평면이다.
방향 = atan2(4, 1) = 75.96°. 체류시간 d를 바꿔도 **방향은 불변, 속도만 변한다.**

### 결론 2 — 뱀형은 절대 쓰지 말 것
지그재그로 돌아오면 x성분이 상쇄되어 평면이 깨진다(잔차 9초). 그런데도 추정기는 **90.00°를 자신 있게 출력한다.** 구조적으로 틀린 답이 자신 있게 나오는 경우다.

### 결론 3 — 뱀형을 **일부러** 한 번 찍으면 그게 시연 소재다
잔차 9초는 정상 시행(0.00초)과 비교 불가능하게 크다. **잔차 기반 이상탐지가 이걸 잡아내는지** 보여주면, §4-③「모르면 모른다고 말하는 시스템」의 **실물 하드웨어 버전**이 된다. 시뮬에서만 보여주던 기능을 실물로 시연하는 것.

## 4. ★ A3 측정 계획 — 수정됨

당초 "설정 150/200/250℃ × 거리 2/3/5/8/12cm"만 계획했으나, **노즐 선택도 변수로 넣어야 한다.**

```
측정 대상:  노즐 {7.5mm, 1cm, 없음}  ×  설정 {200, 300, 400℃}  ×  거리 {2,3,5,8,12,16cm}
```

**왜 노즐을 변수로 넣나:** 노즐이 좁으면 뜨겁지만 살상 반경이 작아 격자를 촘촘히 해야 하고, 넓으면 반경이 커지는 대신 온도가 떨어진다. 두 요구가 반대 방향이라 **실측 없이는 못 정한다.**

각 조합에서 기록할 것:
```
① 평탄 공기 온도 (열전대, 대기 120~150초)
② 공기가 60℃ 이상인 최대 거리  → R_lethal
```

### ⚠ 노즐을 바꾸면 τ를 다시 재야 한다
```
τ ∝ u^(−1/2)   →  출구 면적이 커지면 유속↓ → τ↑

  면적 1.0배 (7.5mm)  → τ 21.5 s   ← 현재 측정값
  면적 1.8배 (1cm)    → τ 약 29 s
  면적 4배  (15mm)    → τ 약 43 s
```
**절대 τ는 데모 조건(설정 400·풍량 10·4cm)에서 1~2회 재측정 필요.** 예측 20~25 s.

> ⛔ **2026-08-16 정정.** 이 자리에 있던 "σ_τ = 5.7%는 개체차라 노즐과 무관하게 유효하다"는 문장은 **삭제한다.**
> σ_τ 측정 자체가 측정 순서와 교란되어 철회됐다(상관 −0.903, 같은 센서 재측정 −26.3%).
> 개체차 지표는 **D1/D2 평면적합 잔차**로 대체한다.
>
> **안전한 τ 재측정법:** 설정 200·4cm는 공기 110℃로 DS18B20 파손 한계(125℃) 아래라 **반복 시험이 가능하다.**
> 데모 조건(400·4cm, 공기 190℃) 확인은 **1회, 15초 뒤 반드시 빼낼 것.**

## 5. 실행 대본 (h=20cm, **d=8초**, 행 우선)

> **2026-08-16 개정.** 체류 6초 → 8초. 방향 예측 75.96°는 **불변**(체류시간과 무관),
> 속도만 `h/(d·√17)` = 20/(8·4.123) = **0.606 cm/s**로 바뀐다. 총 소요 90초 → **120초**.

## 부록 — 다른 방식을 검토했으나 기각한 이유

| 방식 | 기각 사유 |
|---|---|
| 왕복 스윕(오실레이션)으로 넓은 전선 만들기 | **듀티비 = 제트폭/왕복거리**로 기하학적으로 고정된다. 60cm 열을 3cm 제트로 훑으면 듀티 5%, 500℃여도 유효 도달 온도가 48℃라 죽지 않는다. 속도를 올려도 듀티는 그대로. |
| 45° 대각 전선 | 투영거리가 겹쳐(최소간격 0cm) 여러 노드가 **동시에** 죽어야 하는데, 점 열원으로는 불가능. |
| 축정렬(0°/90°) 전선 | 같은 이유로 한 열 4개가 동시 사망해야 함. 불가능. |
| 광폭 노즐로 열 전체 덮기 | 60cm 폭을 덮으려면 노즐이 그만큼 커야 함. 보유 장비로 불가. |

**→ 남는 것이 "순차 점원 + 투영 순서" 방식이고, 다행히 그 중 가장 실행하기 쉬운 행/열 우선 순서가 정확한 평면을 만든다.**
