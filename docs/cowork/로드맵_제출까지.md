## A. 계측 마무리

### A1. τ 잔여 2회 ★ 최우선
```
n05_r1     센서 5개째 → σ_τ 확정
n01_r4     드리프트 + 펌웨어 변경 검정 (bracket)
```
n04_r2 위치 그대로. 평탄값 75~78℃면 정렬 재현.
**끝나면 σ_τ가 확정되고 §5-② 한계선 표의 🟡 한 줄이 채워진다.**

### A2. 열전대 배선 + 펌웨어
DS18B20은 125℃에서 죽으므로 **데모 온도의 공기 온도를 잴 수단이 없다.**
- 먼저 확인: 노출 비드형(τ≈0, 기준기로 적합) vs 스테인리스 봉형(자체 τ 보정 필요)
- MAX6675/31855는 4~5Hz면 충분 (열전대 자체가 빠르므로)

### A3. ★ 데모 온도·거리 확정
열전대로 **설정 온도 × 거리**의 2차원 지도를 만든다.
```
설정 150 / 200 / 250℃  ×  거리 2 / 3 / 5 / 8 / 12 cm
→ 각 칸의 실제 공기 온도
```
여기서 두 가지가 나온다:
- **데모 설정값** — 노드가 5~8초에 60℃ 도달하는 조합
- **살상 반경** — "몇 cm 안에 들어와야 노드가 죽는가" = 데모에서 화재의 공간 범위

> 설정 100℃에서 3cm 실측이 73~77℃였다. 감쇠가 크므로 설정값은 목표 공기온도보다 훨씬 높아야 한다.

### A4. (여유 시) τ(u) 곡선 — 우선순위 3
풍량 1 / 5 / 10에서 각 3회. 시뮬 논증 보강용.
풍속계 3점 측정을 얹어 `u₂/u₁ = (τ₁/τ₂)²` 교차검증.
맞으면 "τ를 유속계로 쓸 수 있다"가 실측으로 증명 — §4에 들어갈 값어치.

### A5. (여유 시) 진짜 무풍 τ — 우선순위 4
에어컨·환기 전부 정지 후. 현재 88~108초는 "에어컨 가동 실내"이지 무풍이 아니다.

## B. 데모 설계 (책상 위 작업, 하드웨어 불필요)

A3 결과가 나오면 바로 정할 것:

| 결정 | 근거 |
|---|---|
| **격자 간격** | 살상 반경보다 넓게. 겹치면 동시 사망 → 방향 안 나옴 |
| **체류 시간** | 노드당 60℃ 도달 시간 (5~8초) |
| **이동 방식** | 직선 스윕 / 곡선 / 타원 head — §5-② 한계선 표와 대응 |
| **사망 임계** | 60℃ 유지? 실물 파이프라인의 판정 함수와 일치해야 함 |

### ★ 사전등록 예측
데모를 돌리기 **전에** 예상 사망 시각 시퀀스와 예상 방향·속도를 문서에 기록한다.
맞든 틀리든 남긴다 — 이미 기각된 예측 5건이 문서에 남아 있는 것과 같은 규율.

## D. ★★ 데모 리허설 — 최대 미지수

**"열풍기를 쏘면 대시보드에 화살표가 뜬다"는 아직 한 번도 검증된 적이 없다.**
σ_τ가 작다는 건 *물리적으로 가능하다*는 뜻이지 *파이프라인이 동작한다*는 뜻이 아니다.

### D1. ★ 4노드 축소 리허설 — 16개 조립 **전에** 할 것
```
왜: 16개를 다 조립한 뒤 안 되면 되돌리는 비용이 크다.
    4개면 반나절이고, 파이프라인 전 구간을 똑같이 통과한다.
```
확인할 것:
- 노드가 60℃에서 실제로 사망 판정을 받는가
- 임종신호가 게이트웨이까지 도달하는가
- 사망 시각이 메시 동기 시각으로 정확히 각인되는가
- 게이트웨이가 방향·속도를 산출하는가 (4점이면 최소 표본)
- 대시보드에 뜨는가

**여기서 막히면 그게 진짜 일정이다.** C단계로 넘어가지 말 것.
