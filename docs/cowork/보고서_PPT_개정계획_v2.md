## §3 개발 프로그램 설명 (5P) — 여기가 최대 개정 구역

### 3-① 4대 모듈 — 유지 (문구만)
④번 모듈 이름을 "도착시각 추정"에서 **"도착시각장(場) 추정"**으로. §3-②와 용어 통일.

### 3-② ★핵심 알고리즘 — **전면 개정** (구판은 틀린 구조를 그림)

구판은 "죽은 (좌표,시각) → 평면 적합 → ∇T" **단일 적합** 그림이다. **실제 코드는 2단이고, 이 2단 구조가 §4-②의 발견을 가능하게 한 주인공**이므로 그림을 실물과 맞춘다.

```
[그림 개정안 — 3열 플로우]

 1단 (노드별 N회)                2단 (집계)                 출력
┌──────────────────┐   ┌──────────────────────┐   ┌──────────────┐
│ 노드 j 주변의     │   │ 방향: 신뢰도 가중     │   │ 방향 n̂       │
│ 이웃 사망들로     │ → │       벡터 합         │ → │ 속도 s        │
│ 국소 평면 적합    │   │ 속도: 중앙값(강건)    │   │ ETA           │
│ → ∇T_j (N개)     │   │ + 유효표본 진단 n_eff │   │ + 신뢰도 등급 │
└──────────────────┘   └──────────────────────┘   └──────────────┘
```

수식 카드(기존 유지): `∇T = n̂/s → 방향 = ∇T/|∇T|, 속도 = 1/|∇T|` + **"균일한 센서 지연은 기울기에서 상쇄된다(절편에만 흡수) — 방향·속도가 지연에 원리적으로 면역인 이유"** 한 줄. 이건 우리 최강 이론 카드라 반드시 남긴다.

**라벨:** "기술적 완성도 — 실코드와 1:1 일치하는 알고리즘 기술" (실제로 명세↔코드 대조를 했으므로 쓸 수 있는 말이다.)

### 3-③ 오탐 방어 — **개정: 비화재 사망 방어를 여기로 흡수**

구판 4-③(비화재 사망)의 내용을 이 슬라이드로 합친다. 구성:

- 한 줄 강조: **"판별은 정보가 가장 많은 곳(게이트웨이)에서, 말단 게이트는 의도적으로 느슨하게"**

## §4 개발 중 장애요인·해결 (3P → **4P**) — 전면 재구성

> 초안 문서 `보고서_4장_장애요인과해결_초안.md`의 6절을 4P로 압축 배치.

### 4-① 시뮬 선개발 + 측정 정직화 — **개정** (구 4-① 계승)
- 좌: "실패해야 데이터가 나오는 시스템 → 태울 수 없으니 시뮬로 먼저" (구판 유지)
- 우: 측정 정직화(에러바 수선) 유지 + **사전등록 예측 제도** 한 줄 예고: "물리 예측을 미리 등록하고 맞든 틀리든 기록 — 기각된 예측 5건도 문서에 남아 있다" (상세는 4-②로)

### 4-② ★★ 「82°의 3중 오진」 — **신설. 이 장의 중심**
초안 4-B를 그대로. 핵심 비주얼은 **오진 4행 표**:

| 가설 | 검정 | 결과 |
|---|---|---|
| ① 곡률 탓 | 창 확대 실험 | 기각 (81.8°→5.6°) |
| ② 채점 방식 탓 | 채점 코드 확인 | 기각 (이미 국소 법선) |
| ③ 표본 부족 탓 | 표본·조건수 진단 | 부분 기각 (13개인데도 실패) |
| ④ **집계 가중치** | 가중치 분포 분해 | **확정** |

증거 statBox 3개: **corr +0.986** / **한 노드 가중 86.4%** / **개별 오차 중앙값 1.35° vs 출력 85.21°**
결론 배너: **"정답은 표본 안에 있었다. 집계가 그것을 버렸다."** + 수정: `w = 1/|∇T| → |∇T|²` (부호가 반대였다)
우연한 통제군 한 줄: "같은 입력에서 강건 집계(속도)는 살고 비강건 집계(방향)만 죽었다 — 원인을 집계로 특정한 결정적 증거"

### 4-③ ★ 「모르면 모른다고 말하는 시스템」 — **신설**
초안 4-C를 그대로. 핵심 비주얼은 **4행 비교표** (legacy 85.05° / uniform 84.90° / median 84.90° / **invvar: 값 없음**) + 실제 로그 3줄 캡처 ("냈다면 틀렸을 것: True"). n_eff 진단 소개.
**이 슬라이드는 독창성 점수에도 걸린다** — "자기 한계를 아는 시스템"은 기능이다.

### 4-④ 하드웨어 괴리 선점 — **개정** (구 4-② 계승 + τ 실측 + 파이프라인 공백)
3단 구성:
- **시계 동기**: millis() 원리적 파탄 발견 → 메시 동기 시각 + 당사자 각인 시각으로 교체 (구판 유지)
- **τ 실측** 🟡: "시뮬 시험 범위 {0~10s} vs 실측 11~78s — 검증 범위 밖에 실제가 있었다. τ는 온도가 아니라 유속의 함수" + H1 결과 표 (풍속별 τ, σ_τ)
- **실물 파이프라인 공백**: "시뮬에는 있는 판별이 실물 경로에 없었다 → 판정 함수 일원화로 해소"

> 구 4-③(비화재 사망)은 3-③에 흡수됐으므로 페이지 수지 맞음: 3P → 4P (+1).
