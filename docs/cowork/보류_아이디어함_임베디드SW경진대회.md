# 보류 아이디어함 (Parking Lot)
### 임베디드SW경진대회 브레인스토밍 — "6주라서" 접은 것만

> 여기 담긴 건 **독창성·규정(상용화 금지)은 통과했는데, 오직 6주 일정 / 장비 / 난이도 때문에 이번엔 무리**인 것들.
> 물리적으로 불가능한 것, 상용품과 정면충돌하는 것, 유사과학은 여기 안 넣음 (나중에도 부활 안 하니까).
> 팀 광맥: **"비접촉으로 겉만 보고 속을 SW로 알아내기(속보기)" + RF/전파.**

---

## 보관 이유별 목록

### 1. 백스캐터 무전원 센서
- **왜 좋은가:** 신박도 최상("전원이 없는데 동작한다"), 상용 완제품 없음(RFID 제외, 앰비언트 백스캐터는 연구단계), 규정상 제일 안전.
- **지금 안 되는 이유:** 저전력 회로 + 백스캐터 변조 설계 난이도가 6주 밖. HW 비중이 커서 완성 리스크 큼.
- **부활 조건:** 기간이 길거나, 전자회로 강한 멤버 합류 시.

### 2. 매몰자 생체신호 탐지 (raw 레이더 + 자체 ML, 잔해 투과)
- **왜 좋은가:** 재난 서사 강력, 활용성·독창성 둘 다.
- **지금 안 되는 이유:** raw 레이더 신호처리(range/doppler FFT → 위상 추출) + ML 학습곡선이 6주 초과. (턴키 모듈로 쉽게 하면 우리 SW 기여가 얇아져서 점수 손해 → 딜레마.)
- **부활 조건:** 레이더 DSP 경험 쌓은 뒤, 또는 장기 프로젝트로.

### 3. RF 단층촬영 — 전파로 공간을 스캔해 형체를 이미지화 (진짜 "투시")
- **왜 좋은가:** 신박도 최상. "전파로 방 안 형체를 그림으로 본다"는 시각적 임팩트가 압도적.
- **지금 안 되는 이유:** 다중 안테나 어레이 + 해상도 + 연산량이 6주 밖.
- **부활 조건:** 안테나 어레이/연산 자원 확보 시. 데모를 "저해상 1~2 물체 위치"로 극단 축소하면 일부는 가능할 수도.

### 4. RF 분광 성분 분석기 ("속보기"의 정밀 버전)
- **왜 좋은가:** 팀 광맥의 상위호환. 액체/기체/물질 성분 정량 분석.
- **지금 안 되는 이유:** 정밀 계측 장비 필요, 정량화가 6주 무리. (정성 "종류 구분"까지 낮추면 이번 후보인 요리·내용물 판별로 내려옴.)
- **부활 조건:** 계측 장비 접근 가능 시.

### 5. 통신탐지 딥러닝 — 풀버전 (드론 기종 식별 / 범용 기기 지문)
- **왜 좋은가:** SW가 100% 주인공(하드웨어는 멍청한 SDR), 상용 완제품 없음, 규정 안전, 연구 핫함(RF fingerprinting).
- **지금 안 되는 이유:** 범용 식별은 데이터셋 수집 + 일반화가 큰 프로젝트. (기기 3~5개만 구분하는 축소판은 6주 가능 → 필요하면 이번에 소환 가능.)
- **부활 조건:** 데이터 수집 시간 확보 시 풀스케일로.

### 6. 자가치유 초저가 다수 릴레이망 — 풀비전 (전쟁·미개척지, 수백~수천 노드)
- **왜 좋은가:** SW(라우팅 프로토콜)가 주인공, "부서져도 수로 압도해 지속 연결"이라는 강한 컨셉.
- **지금 안 되는 이유:** 대규모 실전 비전은 장기 과제. (노드 몇 개로 "잘라도 경로 재구성" 보이는 축소 데모는 6주 가능 → 이번 후보 ③으로 살아있음.)
- **부활 조건:** 노드 대량 확보 + 장기 실증.

### 7. RF 수화 인식 / 비접촉 손 정밀 인식
- **왜 좋은가:** 접근성(청각장애인) 의미 큼, 카메라 없이 프라이버시 보호.
- **지금 안 되는 이유:** 손가락 단위 정밀도 + 데이터셋이 6주 부족.
- **부활 조건:** 인식 범위를 몇 개 동작으로 좁히고 데이터 확보 시.

### 8. 마이크로웨이브 간이 충치·의료 스캔
- **왜 좋은가:** "속보기"의 의료 응용, 비접촉·무방사선.
- **지금 안 되는 이유:** 정밀도 + 의료 검증 + 규제가 6주 밖.
- **부활 조건:** 의료 자문/검증 파트너 확보 시.

## 참고: 이번(6주) 살아있는 후보 — 여기 보류함과 헷갈리지 말 것
- **① 요리 — 안 자르고 고기 속 익힘/신선도 판별** (top pick)
- **② 전신주·전력선 부분방전 RF 검출** (활용성 강)
- **③ 자가치유 릴레이망 축소 데모** (SW 순도 최고)
