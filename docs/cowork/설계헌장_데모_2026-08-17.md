### 2026-08-17 확정. 이 문서 이후로 데모 설계값은 "새 측정이 나왔다"는 이유로 바꾸지 않는다.
### 바꿀 수 있는 건 §4의 손잡이 하나뿐이고, 바꾸는 절차도 여기 적힌 대로만.

## 0. 왜 지금까지 숫자가 계속 바뀌었나 — 정직한 진단

체류시간이 6 → 8 → 12 → 18초로 네 번 바뀌었다. 각각 이유는 있었다
(임계 60→80℃ 발견, τ 실측, 제트폭 실측, 점근값 실측). 그러나 근본 원인은 하나다:

> **직접 잴 수 있는 것을 숨은 변수들의 사슬로 추정하고 있었다.**
>
> 설정온도 → (진위 불명) → 출구온도 → (감쇠모델) → 공기온도 → (조준·제트폭) → 센서온도 → (τ) → 사망시각
>
> 사슬의 고리 하나가 실측될 때마다 끝값이 흔들렸다. 고리가 5개면 5번 흔들린다.

**해결: 사슬을 버리고 끝값을 직접 잰다.** 알고리즘이 소비하는 것은 공기온도가 아니라
**사망시각 t80** 하나다. 그건 이미 3회 실측했고, 앞으로도 그것만 잰다.

이 관점에서 "설정 400이 진짜 400인가"라는 질문은 **답할 필요가 없어진다.**
설정값·거리·공기온도는 전부 라벨이다. 재현만 되면 참값은 몰라도 된다.

## 1. 동결 (FROZEN) — 어떤 측정이 나와도 안 바꾼다

| 항목 | 값 | 근거 |
|---|---|---|
| 사망 임계 | **80 ℃** | 펌웨어 설계값. 데모 편의로 시스템을 바꾸지 않는다 |
| 격자 간격 | **20 cm** | 살상반경 1.75cm 대비 5.7배 여유 |
| 배치 | 4×4, 원점 십자 | 격자판 완성됨 |
| 대본 구조 | A 행우선 / B 반경순서 / C 희소 / (D 뱀형) | 데모설계_결정표 |
| 방향 참값 | A: 75.96° / B: 55.67° | 기하학. 체류시간과 무관 |
| 물리 배치 | **현 배치 그대로** (열풍기·받침·표시) | 사진＋자 실측으로 고정. 공칭값 아닌 실물 기준 |
| 촬영 장소 | 실내 (집) | 대역 열원이 옆바람 2m/s에 조준 이탈 |

## 2. 측정 앵커 (ANCHOR) — 설계가 의존하는 유일한 실측값

```
t80 = 계단 입력 후 센서가 80℃를 넘는 시각

실측  R2 10.31 s / R3 11.25 s / R6-2 10.35 s / (R6-1 12.33 s, 최악 조준)
중앙값 10.8 s
```

이 값만이 설계에 들어간다. τ·공기온도·점근값은 **보고서 서술용**이지 설계 입력이 아니다.

## 3. 파생 규칙 (RULE) — 앵커에서 자동으로 나온다. 계수는 동결.

```
체류시간 = round(1.7 × t80중앙값)        상한 22초
```

- **계수 1.7의 근거**: 관측 최악치(12.33s, 조준 0.76cm 이탈) 대비 1.46배 여유.
  몬테카를로(σ=0.4cm)에서 노드 미사망 <2%.
- **상한 22초의 근거**: 제트 안 19초에서 센서 108℃ 실측 → 파손점 125℃까지 17℃.
  외삽이 아니라 관측 구간이다.
- **현행 값 대입 (2026-08-31 재측정): 1.7 × 12.49 = 21.2 → 체류 21초.**
  t80 3회 교정 12.41 / 12.49 / 17.39 초, 중앙값 **12.49 초**(온도상승 기준).
  손잡이(§4) 조건 확인: `1.7 × 12.49 = 21.2 ≤ 22` 이므로 **거리는 건드리지 않는다.**
  근거: `docs/DECISIONS.md` D-074 · 곡선 `results/hw/t80_calib_curve.csv`

**앞으로 t80이 다시 측정되면 이 규칙에 넣어 체류가 나온다. 규칙 자체는 안 바뀐다.**
"새 측정 → 새 설계"가 아니라 "새 측정 → 같은 규칙의 새 입력"이다.

## 4. 손잡이 (KNOB) — 조정 가능한 것은 이것 하나

```
거리 (노즐~노드).  조정 조건도 하나:

   1.7 × t80 > 22초  (= t80 > 13초)  →  거리를 1cm 줄이고 t80 재측정
   그 외                              →  건드리지 않는다
```

온도 설정·풍량·격자·임계·대본으로는 조정하지 않는다. 변수 하나만 움직여야
무엇이 결과를 바꿨는지 알 수 있다 — σ_τ를 철회하게 만든 교란이 정확히 이걸 어겨서 생겼다.

## 5. 당일 교정 (CALIBRATION) — 데모 절차의 일부다. 연구가 아니다.

촬영 직전, 실제 노드 1개로:

```
① 3펄스: 계단 입력 → t80 기록 → 부채질 냉각 → 반복 (총 ~10분)
② 판정:
   중앙값 6 ~ 13초 & 산포 3초 미만   →  체류 = round(1.7×중앙값). 촬영 시작
   중앙값 > 13초                      →  거리 1cm 줄이고 ①로 (1회만)
   산포 ≥ 3초                        →  열풍기 고정 상태 점검 후 ①로 (1회만)
   재시도 후에도 실패                 →  촬영 중단. 그날 찍지 않는다
```

**교정값이 그날의 값이다.** 오늘 잰 10.8초는 설계 근거일 뿐, 촬영일에는 그날의 교정이 우선한다.
방 온도·열풍기 상태·조준이 그날그날 다르다는 사실을 **모델로 보정하지 않고 절차로 흡수한다.**

## 6. 촬영 중 중단 조건

| 상황 | 조치 |
|---|---|
| 노드가 체류시간 안에 안 죽음 | 그 시행 폐기. 조준 재확인 후 처음부터. **이어붙이기 금지** |
| 시리얼/대시보드에서 센서 115℃ 목격 | 즉시 열풍기 이탈 (파손 예방) |
| 같은 시행 2연속 실패 | 당일 교정(§5)부터 다시 |
| 연기·그을음 | 전원 차단. 그날 종료 |
