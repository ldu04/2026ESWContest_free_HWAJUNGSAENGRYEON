## 3. ★ 놓치기 쉬운 고가치 항목 (네가 "더 중요한 게 있을 수도"라 한 부분)

1. **연구노트가 이미 자산이다.** DECISIONS·PROGRESS 로그 = "measure-first로 재고 → 약점 찾고 → 고친" **정직한 연구 여정 그 자체.** 결선 연구노트로 그대로 강력. → 지금부터 **의식적으로 살려서 쌓기**(이미 하고 있음).
2. **하드웨어 괴리·시계동기 인식 = 공학 성숙도 신호.** "자기 시스템의 실물 한계를 아는 팀"은 드물어서 **차별화 포인트.**
3. **오탐 방어를 헤드라인으로.** 묻히기 쉬운데 이게 기존 메시와의 **진짜 차별점.** 보고서·발표에서 앞세우기.
4. **정직성 서사 자체가 점수다.** 0.1% 안 우기고 "방향 신뢰·속도 보수적"으로 가는 것 → 심사위원은 과대포장을 싫어함. 신뢰가 곧 점수.
5. **데모 영상 서사(드라마형).** 실제 수상작들이 완성도 높은 시연영상으로 갈렸음. 미리 스토리보드.

## 4. 레버리지 순위 (효율 좋은 순 = 여기부터 힘 싣기)

1. **실물 동작 데모 + 정량지표** — 기술성 30의 심장 (부품 후).
