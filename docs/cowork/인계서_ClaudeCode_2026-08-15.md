## 2. 현재 하드웨어 상태

### 열풍기 (리워크 스테이션)
| 항목 | 값 |
|---|---|
| 전원 | 변압기 220V→110V, 2KVA 경유 |
| 노즐 | **7.5 mm** (1cm도 보유하나 미채택) |
| 온도 | 설정 범위 100~500℃. **현재 측정은 100℃** |
| 풍량 | 1~10단. **현재 10단** |
| 냉각(팬만) 모드 | **없음** → 풍속계 삽입 창이 없다 |
| 100℃ 도달 | 디스플레이 기준 4.7초 (금속통 안정화는 별개, 60초 대기) |

**운용:** 세션 내내 켜둔 채 **센서만 넣었다 뺐다** 하여 계단 입력을 만든다.

### 센서
- DS18B20 방수 프로브, **9비트(0.5℃), 약 10.0 Hz**
- 거리 **3 cm** (노즐 끝 → 센서 팁), 테이프로 위치 고정
- 팁이 노즐을 향하는 **축방향** 정렬
- 젓가락 끝에 캡톤테이프로 고정 (이탈 사고 1회 있었음 → 십자 감기 권장)

### ESP32
- 센서↔보드 **페어링 영구 고정** (프로브를 뽑지 않는다)
- 보드 바닥에 번호 스티커 부착 완료. 윗면은 데모 조립 시
- 스티커 금지 구역: **안테나 끝단**(삼각형·손 표시 있는 쪽), 금속 라벨

### 실내 조건 (전 시행 공통 — 기록 필수)
```
에어컨 24℃ 가동, 창문 개방, 4평, 상온 22.5~24.0℃
```

## 3. ★ 로거 펌웨어 — 이번 세션에서 수정함

### 발견된 결함 (TauLog.ino 원본)
```cpp
if (n == 0) { Serial.println("# ERROR..."); return; }   // ready = false
void loop() { if (!ready) { delay(1000); return; } }     // ← 영구 침묵
```
부팅 시 센서를 못 찾으면 **에러 한 줄 뒤 완전 무출력.** 배선을 고쳐도 재부팅 전엔 피드백이 없어 원인 추적 불가.
**두 번째 함정:** `setup()`에서 1-Wire 주소를 캐시 → 실행 중 교체하면 −127.

### 적용된 수정
| 전 | 후 |
|---|---|
| 미검출 시 영구 침묵 | 1초마다 재탐색 + `# devices=N` 계속 출력 |
| 재부팅해야 재인식 | 발견 즉시 `beginSensor()` 자동 시작 |
| −127도 그대로 기록 | 경고 후 재탐색 모드 복귀 |

- 원본 백업: **`TauLog.ino.bak`**
- 플래시 277,692 B (21%)
- **결과: 측정 중 센서 교체 시 리셋 불필요**
- 검증됨: 신 펌웨어에서도 **10.01 Hz / 0.5℃ 유지** (구 펌웨어와 비교 가능)

### 증상별 진단표
| 증상 | 원인 |
|---|---|
| 출력 완전 없음 (샘플 0개) | 미검출 상태로 부팅 → 보드가 조용히 멈춤 |
| −127.0℃ | 버스 무응답 — 배선 또는 4.7kΩ 풀업 |
| 85.0℃ 고정 | 전원 투입 기본값 — 변환 미완료, 전원 불안정 |
| 샘플레이트 1.3Hz | 12비트로 돌고 있음 → 리셋 필요 |

## 4. 측정 결과 (2026-08-13 밤, 6회)

| 시행 | 상온 | 평탄 T∞ | **τ_jet** | R² | τ_room | 판정 |
|---|---|---|---|---|---|---|
| n01_r2 | 23.5 | 69.0 | 22.34 ±1.33 | 0.99673 | 92.4 | 유효(거리 멀었음) |
| n01_r3 | 24.0 | 73.5 | 23.29 ±1.02 | 0.99672 | 96.1 | 유효 |
| n02_r1 | 22.5 | 71.5 | 21.87 ±0.43 | 0.99920 | 88.0 | 유효 |
| n03_r1 | 22.5 | 73.0 | 20.97 ±0.32 | 0.99941 | 90.8 | 유효 |
| n04_r1 | 23.0 | 61.0 | 21.69 ±1.60 | 0.99431 | — | **폐기**(젓가락 이탈) |
| n04_r2 | 22.5 | 77.5 | 20.02 ±0.43 | 0.99873 | 107.9 | 유효, 진짜 3cm 최근접 |

### 도출된 값

```
τ 평균 (제트, 설정100·3cm·풍량10)  =  21.54 s
측정 반복오차 σ                     =  0.67 s
```

> ### ⛔ 2026-08-16 정정 — σ_τ = 5.7%는 **철회됨**
>
> 이 세션에서 σ_τ = 1.22 s (5.7%)를 도출했으나 **교란된 설계에서 나온 값이라 폐기했다.**
> 센서를 한 개씩 순서대로 갈아 끼우며 측정해서 **센서 번호 · 측정 순서 · 조준 품질이 완전히 겹쳤다.**
>
> | 검정 | 결과 |
> |---|---|
> | τ와 측정 순서의 상관 | **−0.903** (같은 날 안에서 −0.994) |
> | n01 3일 뒤 재측정 | 23.29 → **17.16 s (−26.3%)** |
> | 같은 세션 반복오차 | 0.94 s → **재측정 차이가 6.5배 크다** |
>
> **같은 센서의 재측정 폭이 보고된 개체차보다 컸다.** 그러므로 잰 것은 개체차가 아니다.
> 손으로 프로브를 고정하는 방식으로는 위치 산포(32%)가 τ 산포(36%)와 맞먹어 **원리적으로 분리 불가.**
>
> **대체:** σ_τ를 측정 대상에서 제외하고, **D1/D2 평면적합 잔차**(개체차·시계편차·조준편차·라우팅지연이 합쳐진 실운용 지터)로 대신한다.
>
> **이 숫자를 어떤 문서에도 다시 넣지 말 것.** §4·PPT에서 이미 철회 서술로 교체 완료.

### 핵심 발견 3개 (보고서 §4 소재)
1. **τ는 온도가 아니라 유속의 함수** — 같은 시행 안에서 제트 22초 vs 실내 88~108초, **4.1배**. 시뮬 시험 범위 {0~10s} 밖에 실제가 있었다.
2. **조준·거리 오차는 절편에 흡수되고 시상수는 면역** — 평탄값이 61~77.5℃(16.5℃) 흔들려도 τ는 3.3초만 변동. corr = −0.30, 기울기 **−0.061 s/℃**. 이론 카드(`∇T = n̂/s`, 균일 지연 면역)의 계측 재현.
3. **DS18B20은 순수 1차계가 아니다** — 1차 지수 잔차가 덩어리로 뭉침, 도달률별 τ가 63%→21.6s / 86%→18.4s / 95%→15.0s로 흘러내림. 스테인리스 외피+충진재+다이의 복합 열구조. → τ를 물리 상수가 아니라 **운용 기술자**로 제시하고 모델 무관 값(60℃ 도달 30초 등)을 병기.

### 데모 설계 결론
τ=21.5s, 시작 24℃ 기준:

| 공기 온도 | 60℃ 도달(사망) | 125℃ 도달(파손) | 안전 여유 | 사망 지터 σ |
|---|---|---|---|---|
| 73.5℃ (현재) | 30.3 s | 불가 | ∞ | 1.7 s |
| **150℃** | **7.4 s** | 37.7 s | 30 s | **0.32 s** |
| **200℃** | **5.0 s** | 19.9 s | 15 s | **0.22 s** |
| 250℃ | 4.0 s | 13.8 s | 9.8 s | 0.17 s |

**데모 공기 온도는 150~200℃ 구간.** 250℃ 이상은 사망~파손 여유가 10초 아래로 위험.
**τ는 온도 무관이므로 100℃에서 측정한 σ_τ는 데모 온도에 그대로 유효.**

## 5. 즉시 할 일

### 5-1. τ 잔여 2회 (30분)
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
cd C:\Users\Public\esp32

.\log_tau.ps1 -Seconds 180 -Label tau_jet_d03_T100_s10_n05_r1
.\log_tau.ps1 -Seconds 180 -Label tau_jet_d03_T100_s10_n01_r4
```
- 각 시행: 시작 전 센서 23~24℃ 확인 → 10초 대기 → 투입 → **90초 이상** → 이탈
- 유효 판정: **평탄값 75~78℃** (n04_r2 위치 기준)
- `n01_r4`는 **bracket 검정** — n01_r3(73.5℃, τ=23.29)와 비교하여
  - 일치 → 열풍기 드리프트 없음 + 펌웨어 변경 영향 없음 → 데이터 전량 유효
  - 크게 다름 → 드리프트 보정 필요

> 미해결 항목: 평탄값이 61→69→73.5→71.5→73.0→77.5로 움직였다. 가설 ① 조준 편차 ② 열풍기 단조 드리프트 ③ 시행 간 가동/휴지 시간 불규칙. 단조성이 깨졌으므로 ②는 약해졌으나 확정 아님. **로그 파일명의 타임스탬프로 시행 간격 대 평탄값을 사후 분석 가능.**

### 5-2. 열전대 (MAX6675/31855) 배선 + 펌웨어
**보유 물품: 나사(볼트) 고정형 시스 K형 열전대** — 스테인리스 편조 케이블, 압착 단자 2개(빨강/파랑). 비드형 아님.

- 자체 τ가 있으나 **우리 용도 4개 중 3개는 τ와 무관**(평탄값만 필요)하므로 문제없음
- 대기 시간만 길게: **120~150초**
- 극성 확인: 연결 후 몸체를 손으로 쥐어 온도가 **올라가면 정상**, 내려가면 두 선 교체
- MAX6675는 변환 220ms(≈4Hz), 분해능 0.25℃ — 충분

### 5-3. ★ 데모 온도×거리 지도
```
설정 150 / 200 / 250℃   ×   거리 2 / 3 / 5 / 8 / 12 cm
→ 각 칸의 실제 공기 온도 (열전대 평탄값)
```
여기서 두 가지가 확정된다:
- **데모 설정값** — 노드가 5~8초에 60℃ 도달하는 조합
- **살상 반경** — "몇 cm 안이면 노드가 죽는가" = 데모 격자 간격의 근거

> 설정 100℃일 때 3cm 실측이 73~77℃였다. 감쇠가 크므로 설정값은 목표보다 훨씬 높아야 한다.

### 5-4. 우선순위 3~4 (임계 경로 밖, 시간 남을 때만)
- **τ(u) 곡선**: 풍량 1/5/10에서 각 3회. 풍속계 3점 측정을 얹어 `u₂/u₁ = (τ₁/τ₂)²` 교차검증. 맞으면 "τ를 유속계로 쓸 수 있다"가 실측 증명 → §4 소재
- **진짜 무풍 τ**: 에어컨·환기 정지 후. 현재 88~108초는 "에어컨 가동 실내"이지 무풍 아님
