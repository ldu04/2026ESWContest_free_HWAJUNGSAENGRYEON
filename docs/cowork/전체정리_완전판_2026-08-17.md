# 제3장. 시뮬레이터 아크 (지시서 #1 ~ 2j) — 제품을 만든 구간

## 3-1. 구조 (#1)

Python. `fire.py`(직선 전선 ground-truth) · `node.py`(ALIVE/DYING/DEAD, LG) ·
`verification.py`(사망 확정 3조건: 다수결 K=3 + 온도 교차검증 + 지속 침묵) ·
`estimator.py`(국소 평면적합 → ∇T → 방향·속도) · `engine.py`(틱 → 스냅샷 스트림).
난수 시드 고정 — 데모는 재현, 실험은 시드 스윕.

**첫 성적**: 방향 2.12° · 속도 0.10% · 오탐 0% (쉬운 조건). 이 숫자는 이후
**회귀 지문**(코드 안 깨졌나 확인용)으로만 쓰이고, 성능 숫자로는 은퇴한다.

## 3-2. 스트레스 (S1~S11)

S1 기준 / S2a 바람 각도 요동 / S2b 돌풍 / S3 방사형 / S4 배치 불균일 / S5 통신 dropout /
S6 저밀도(9~25노드) / S7 복합 최악 / S8 시계 지터 / S9 온도 지터 / S10 비화(spot fire) / S11 비화재 사망.
규칙: **측정 먼저, 개선은 나중. 파라미터 튜닝 금지, 기록만.**

발견된 한계선: 오탐 방어는 dropout 0.20에서 처음 뚫림 / 속도는 9노드에서 붕괴(34.5%)
→ **"12노드 이상 운용" 권고의 출처** / 방향은 바람에, 속도는 저밀도·돌풍에 약함.

## 3-3. 비화재 사망 방어 (2c→2d→2e2) — 3막극

① S11에서 화선 오염 93~98% 발견 (원인: "이웃 고온 OR 자기 고온"의 OR 게이트)
② 3분기 분할로 고침 → 그런데 COOL(차가운 비화재 사망) 통과율이 여전히 **86.4%**
③ 누수의 98.9%가 "이웃 표본<3이면 관대 채택"(D-030) 규칙에서 발생 —
   판정 기준은 옳았고 **표본이 없어서 그냥 통과시킨 설계 구멍**
④ Fix A(표본 부족 시 제외) 채택 → **86.4% → 0%**, 새 파라미터 0개

교훈으로 남은 것: **단일 스칼라 임계는 방아쇠와 판별자를 겸할 수 없다** —
임계를 40~50℃로 낮추면 채택률 0 또는 비화재 오염 89~100%. (임계 하향으로 τ 문제를
구제할 수 없다는 §4 논거의 출처)

## 3-4. 속도·ETA (2e3 시리즈) — 정직한 후퇴전

- 속도 = 1/|∇T| 는 역수라 **+방향으로만 편향**(Jensen 부등식). 바람 20°에서 +29.8%, 9노드 +34.5%
- 역수를 없앤 대안(A)은 편향의 15~26%만 줄임 → **기본값 승격 안 함**, "점 추정의 한계 확정"이 수확
- 9노드 붕괴의 정체 = **자유도 0** (평면 3모수에 이웃 3개 → 잔차 0이 가짜 완벽)
- **해법은 정밀도가 아니라 정직한 폭**: E3 밴드(외부 보정) → E3x 팽창 1.43배
  → "ETA 4:12" 금지, **"ETA 0.7~1.7분(90% 구간)"** 형식. 단측 신뢰 ≥91.3%
- 부수 발견: **시스템은 자기가 얼마나 틀렸는지 내부 신호로 모른다**
  (오차 최대인 9노드가 산포는 최소) — 자기진단 축을 만들게 된 계기
- ETA의 −6.44초 상수 선행(노드가 80℃ 닿을 때 화선은 9.66m 앞) — 이르게 = 안전한 쪽

## 3-5. τ의 침입 (2g~2j) — 시뮬이 실측을 부른 이유

- τ(센서 열관성)가 검증 울타리 {0~10s} 밖일 수 있음이 제기됨 → 게이트 시험 → 판정 (C):
  **"τ 실측 없이는 실물 ETA 밴드 주장 불가"** ← 이게 열풍기 실측 캠페인의 출발점
- 죽음의 "곡선" 재구성(T_air = T_sensor + τ·dT/dt) 채택, 방법 C 기각.
  매치드 검증은 tautology라 성과 계상 금지(자기채점 방지)
- **파단 기준: τ/펄스폭 비율 1.2배부터 미탐지 시작, 3.5배에서 100%**
- 실측 1차(H0): 강제대류 11.07s / "자연대류" 78.48s(에어컨 ON이라 라벨 부정확)
- τ=78.5s는 피크 500℃에서도 미탐지 87.9% → **전 피크 실패.**
  시스템 신뢰성이 "실배치 τ가 11s대냐 78.5s대냐" 하나로 수렴 → 무풍 탐지는 현 설계로 어려움
- 지터 τ(노드별 ±30%)는 방향을 66.7°까지 붕괴시킴 — σ_τ 실측 시도의 동기
  (그 실측이 교란으로 철회된 것이 이번 세션의 이야기)
- 이 과정에서 시뮬 전제결함(화선 통과 후 영구 300℃, 냉각 없음)을 Claude Code가
  실행 중 스스로 발견·수정 (D-044)

## 4-2. ETA의 정체 발견 (2O~2Q)

- ETA 앵커 게이트: 쌍대 비교에서 오히려 head +30.5초 악화 → **기각** (기각 목록 5번)
- ★ **corr(|ETA 오차|, 앵커거리) = 0.99~1.00** — ETA는 사실상 "최근접 사망 이벤트 조회
  + 작은 선형 보정"이다. 신뢰도 지표는 **anchor_dist_m 단독으로 확정**
- |P1−P2| 일치도 지표 실격(AGREE인데 MAE 1,714s) — 셋 중 둘을 공유해서 생긴 허상
- ETA는 적합 절편 ĉ를 쓰지 않는다(D-064) — v1·v2 명세가 두 판 연속 같은 오류
- 2Q = 마지막 시뮬 회차 선언. 이후 시뮬은 **하드웨어 결과 반영 외 동결.**

# 제8장. 무엇이 무쓸모가 되었나 — 정직한 결산

**폐기된 것**: 슈퍼커패시터 Last-Gasp(배터리로 대체), 작품명 후보 3개, 플랫폼 3사례 나열(v2에서 제동),
재난종류 추정(도식에서 소멸), 바람 융합 2e-3 원계획(실행 기록 없음), ETA 게이트, |P1−P2| 지표,
σ_τ 측정 설계, 풍속계(잘못 산 것 인정), 15cm 격자, 연속 이송 데모, 레거시 가중치.

**폐기가 아니라 재산이 된 것**: 기각·철회 기록 전부 (§4-E 기각 목록 14건),
82° 3중 오진 서사, "확신에 찬 오답"의 해부, 강령 자체.
**이 프로젝트가 파는 것이 "어디까지 되고 어디부터 안 되는지 스스로 아는 시스템"이므로,
기각 기록은 부산물이 아니라 제출물의 일부다.** (마스터플랜: "정직성 서사 자체가 점수")

**시뮬레이터는 무쓸모가 된 게 아니라 제품 그 자체다.** 하드웨어 데모는 "그 제품이 실물에서도
돈다"는 증거 한 조각이고, 바람·곡률·규모·희소 시나리오는 물리적으로 재현 불가라 전부 시뮬 담당이다.
