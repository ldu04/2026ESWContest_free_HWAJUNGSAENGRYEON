# 현장 카드 — 데모 조건 확정
### 2026-08-16.  설정 400℃ · 풍량 10 · 열전대(MAX6675)
### 목표: 오늘 밤 안에 **데모 거리 하나를 못 박는다.** 되묻지 않고 끝까지 간다.

---

## 0. 원칙 — 이번엔 이것만 지킨다

```
① 열풍기는 한 번 고정하면 끝까지 안 건드린다.
② 열전대는 열풍기를 끈 뒤에만 옮긴다.
③ 45초 고정 기록. "평탄해 보이면 끊기"를 하지 않는다.
④ 아래 판단표는 재기 전에 정한 것이다. 값을 보고 옮기지 않는다.
```

## 1. 배치 — 만들 것 없음

```
          [책·무거운 것]        ← 손잡이(플라스틱)를 눌러 고정. 여긴 안 뜨겁다
               │
           ┌───┴────┐
           │  손잡이 │
           └────┬───┘
            금속통 ╲            ← ★ 금속통은 아무것에도 닿지 않게. 공중에.
                   ╲
                    ╲ 노즐
                     ▼   x = 4 cm  (노즐 끝 → 열전대 구슬)
        ─────────────●──────────
        ▓▓▓▓▓▓▓ 타일 ▓▓▓▓▓▓▓     ← 제트가 닿는 자리. 합판 위에 타일을 깐다
        ═════ 격자판 ══════
```

**핵심 세 가지**

| | |
|---|---|
| **금속통 아래는 비운다** | 책상·상자 모서리 밖으로 총열을 내밀면 됨. 금속통에 종이·나무가 닿으면 안 된다 |
| **손잡이만 눌러 고정** | 플라스틱이라 안 뜨겁다. 여긴 책으로 눌러도 무방 |
| **노즐 아래는 타일** | 190℃ 공기를 반복해서 맞으면 합판이 그을린다 |

고정 확인: **손을 떼고 30초.** 안 움직이면 통과. 움직이면 다시.

## 2. 준비 (10분)

1. 위 배치대로 놓는다
2. 제트가 타일에 닿을 지점을 연필로 찍는다 → **P점** (총열을 따라 눈으로 겨누면 됨)
3. **자로 노즐 끝 ~ P점을 재서 4.0cm로 맞춘다.** 받침을 넣고 빼서 조절
4. P점 양쪽에 **1cm 눈금**을 긋는다 (왼쪽 1, 오른쪽 1)
5. 열전대 구슬을 P점에 놓고, **구슬에서 5cm 뒤 선 위에 동전이나 집게**를 올려 고정
   - 구슬 근처에 테이프 금지 (탄다)
   - 구슬은 타일에 닿아도 되고 살짝 떠도 된다. 매번 같기만 하면 됨

## 5. 판단표 — 값을 보고 여기서 찾는다. 새로 정하지 않는다.

### ▶ 1번(r=0) 값으로 데모 거리를 정한다

| 1번 실측 | 조치 |
|---|---|
| **170 ~ 220 ℃** | ✅ **거리 4cm 확정.** 끝. |
| 140 ℃ | 2.2cm 로 옮기고 1번 재측정 |
| 150 ℃ | 2.5cm |
| 160 ℃ | 2.9cm |
| 230 ℃ | 6.2cm |
| 240 ℃ | 6.9cm |
| 250 ℃ | 7.7cm |
| 260 ℃ | 8.6cm |

> 왜 170~220이 통과인가 — 데모 성립 구간은 공기 **150~250℃**다.
> 그 아래는 사망이 8초 넘어 데모가 늘어지고, 그 위는 사망~파손 여유가 9초 아래로 떨어져 센서가 탄다.
> 170~220은 그 구간 안쪽에 여유를 두고 잡은 것이다.

| 공기온도 | 사망(60℃) | 파손(125℃) | 여유 |
|---|---|---|---|
| 150 ℃ | 6.80 s | 34.34 s | 27.5 s |
| 170 ℃ | 5.72 s | 24.93 s | 19.2 s |
| **190 ℃** | **4.93 s** | **19.83 s** | **14.9 s** |
| 210 ℃ | 4.33 s | 16.55 s | 12.2 s |
| 250 ℃ | 3.49 s | 12.49 s | 9.0 s |

### ▶ 2·3번(±1cm)으로 조준 허용오차를 정한다

| ②와 ③의 차이 | 뜻 | 조치 |
|---|---|---|
| 20℃ 안 | P점이 제대로 찍혔다 | 그대로 진행 |
| 20℃ 넘음 | P점이 한쪽으로 치우쳤다 | 뜨거운 쪽으로 P를 0.5cm 옮기고 1번부터 다시 |

| ②③ 평균값 | 뜻 |
|---|---|
| **60℃ 미만** | 1cm만 빗나가도 노드가 안 죽는다 → **스탠드오프 필수**, 데모에서 손으로 조준 금지 |
| 60 ~ 120℃ | 1cm 빗나가도 죽되 느려진다 → 스탠드오프 권장 |
| **120℃ 이상** | 제트가 예상보다 넓다 → 격자 20cm가 좁을 수 있음. **재검토 필요** (이 경우만 연락) |

### ▶ 4번으로 신뢰도를 판정한다

| 1번과 4번의 차이 | 뜻 |
|---|---|
| 5℃ 안 | ✅ 재현됨. 오늘 데이터 전부 유효 |
| 5 ~ 15℃ | 방이 데워졌다. 창문 열고 30분 쉰 뒤 1번만 다시 |
| 15℃ 넘음 | 열풍기가 움직였다. 고정부터 다시 |

## 6. 안전 — 넘기지 말 것

- **노즐 아래 30cm 안에 종이·비닐·천 없을 것.** 타일 위에서만
- **금속통에 아무것도 닿지 않게.** 종이는 230℃에서 불붙는다
- 손잡이 누르는 책은 **플라스틱 손잡이 쪽에만**
- 열전대 구슬은 절대 맨손으로 만지지 말 것. **선을 잡는다.** 목장갑 착용
- **이 기기는 쿨링 기능이 없다.** 끈 뒤에도 노즐이 한동안 뜨겁다
  → 다 끝나면 **노즐을 옆이나 위로 향하게 두고 타일 위에서 10분 식힌다.** 종이·천 위에 놓지 말 것
- 방 환기. 400℃ 연속 가동이다
