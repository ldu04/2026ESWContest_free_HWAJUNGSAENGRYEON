# 현장 카드 — τ 측정 (데모 조건)
### 2026-08-17.  DS18B20 · 보드에 올라가 있는 TauLog.ino 그대로 사용.
### ★ 이 측정이 끝나기 전에는 node.ino 로 재플래시하지 않는다.

---

## 이 측정이 정하는 것

```
데모 체류시간을 12초로 할지 15초로 할지.
```

임계가 60℃가 아니라 **80℃**(config.h:21)로 밝혀지면서 체류 8초가 무너졌다.
τ를 알아야 위(센서 파손 125℃)와 아래(조준 허용오차) 사이의 창을 정할 수 있다.

| τ 결과 | 체류 확정 | 조준 허용오차 |
|---|---|---|
| **≤ 20 초** | **12 초** | ±0.79 cm 이상 |
| 21 ~ 23 초 | 13 초 | ±0.70 cm |
| **≥ 24 초** | **15 초** | ±0.82 cm |

> 15초를 넘기면 안 되는 이유: τ가 16초로 빠르면 15초에 센서가 **126℃**에 닿아 파손된다.
> 위아래가 다 막혀 있어서 **τ를 모르면 못 정한다.**

---

## 배치

어제 그대로. **열전대를 치우고 그 자리에 DS18B20 팁을 놓는다.**

```
노즐 끝 ~ DS18B20 팁  =  4 cm        ← 자로 확인
위치                   어제 찾은 그 지점 (열전대가 190.5℃ 읽던 자리)
열전대                 옆으로 치울 것 (제트 흐름을 방해한다)
센서 케이블            팁에서 5cm 뒤를 고정. 팁 근처 테이프 금지
```

**주의: DS18B20 방수 프로브의 PVC 피복은 105℃ 정도가 한계다.** 설정 400 회차에서 피복이
약간 냄새를 낼 수 있다. 정상이며, 12초를 넘기지만 않으면 프로브는 산다.

---

## 4회 순서 — 브래킷 설계

```
R1  설정 200        ← 기준 (전)
R2  설정 400
R3  설정 400        ← 반복. R2와의 차이가 반복오차
R4  설정 200        ← 기준 (후).  R1과 비교해 드리프트 검출
```

**R4가 R1과 다르면 방 온도가 흘렀다는 뜻이다.** 어제 σ_τ를 철회한 이유가 바로 이걸 안 해서였다.
순서와 조건이 겹치면 무엇이 원인인지 영원히 모른다.

---

## 각 회차 타임라인 — 초 단위

### 설정 200 회차 (R1, R4) — 총 120초

```
준비    설정 200 · 풍량 10 · 3분 예열 (처음 한 번만. 이후엔 켜둔 채 유지)
        센서는 제트 밖, 상온에 놓여 있을 것

.\tclog.ps1 -Seconds 120 -Col 2 -Label tau_jet_d04_T200_s10_n01_r1

  t = 0 ~ 10 초    아무것도 하지 않는다.  ← 이 10초가 상온 기준선이다
  t = 10 초        화면의 [ 10s] 를 보고 센서를 제트에 넣는다
  t = 10 ~ 120 초  그대로 둔다. 화면 온도가 110℃ 근처에서 멈추는 것을 본다
  t = 120 초       기록 종료. 센서를 빼낸다
```

**설정 200 · 4cm의 공기는 110℃라 DS18B20 파손점(125℃)에 절대 도달하지 않는다.**
120초를 다 채워도 안전하다. 시계 볼 필요 없다.

### 설정 400 회차 (R2, R3) — 총 30초 · ★ 제트 안 12초

```
준비    설정을 400으로 올리고 3분 예열

.\tclog.ps1 -Seconds 30 -Col 2 -Label tau_jet_d04_T400_s10_n01_r1

  t = 0 ~ 10 초    상온 기준선
  t = 10 초        센서를 제트에 넣는다
  t = 22 초        ★ 반드시 빼낸다.  제트 안 12초.
  t = 22 ~ 30 초   빼낸 채로 그대로 둔다  ← 하강 곡선도 데이터다
  t = 30 초        종료
```

**t=22 는 협상 대상이 아니다.** τ가 16초로 빠르면 12초 시점에 센서가 113℃다.
화면 숫자가 **120을 넘으면 22초 전이라도 즉시** 빼낼 것.

> **하강 구간을 버리지 말 것.** 제트 밖 정지 공기의 τ가 여기서 같이 나온다.
> 제트 τ ≈ 16초 vs 실내 τ ≈ 90초 = **약 5배.** §4의 "τ는 온도가 아니라 유속의 함수"
> 논거를 **같은 시행 안에서** 다시 확인하는 자리다. 별도 실험이 필요 없다.

## 회차 사이에 할 일

### ① 센서 냉각 — 이게 제일 중요하다

다음 회차의 기준선이 상온이어야 한다. 안 그러면 지수 적합의 출발점이 틀린다.

| 시작 온도 | 가만히 두면 | **부채질하면** |
|---|---|---|
| 110 ℃ | 5.1 분 | **83 초** |
| 113 ℃ | 5.2 분 | **84 초** |

**부채질하세요.** 손으로 부치든 책받침으로 부치든, 공기가 움직이면 τ가 92초 → 25초로 떨어져
5분이 90초가 된다. (이 자체가 τ가 유속의 함수라는 것의 실용적 증거다.)

**90초 부채질 → 30초 가만히 두기.**

### ② 확인 — 추측하지 말고 잰다

```
.\tclog.ps1 -Seconds 20 -Col 2 -Label chk
```

```
AVG 가 상온 +3℃ 이내  그리고  SPREAD < 1.0   →  다음 회차 진행
아니면 → 60초 더 부채질하고 다시 확인
```

### ③ 열풍기 처리

```
설정을 안 바꾸는 경우 (R2 → R3)
   끄지 말 것. 켜둔 채 노즐을 창밖·문밖으로 돌린다.
   끄면 금속통이 식어 온도가 다시 안 맞는다.

설정을 바꾸는 경우 (R1 → R2, R3 → R4)
   새 설정으로 바꾸고 3분 예열.
```

## 사전등록 예측 — 재기 전에 봉인

```
설정 200 · 4cm     평탄 110 ℃      τ = 20 초
설정 400 · 4cm     평탄 190 ℃      τ = 16 초
제트 밖(하강)                      τ = 90 초
```

**통과 범위: τ가 13 ~ 27 초.**

> **뜨거울수록 τ가 줄어든다는 예측에 주목할 것.** 공기가 팽창해 유속이 빨라지기 때문이다.
> 이게 맞으면 "τ는 온도가 아니라 유속의 함수"의 **두 번째 독립 증거**가 된다.
> 틀리면 그 주장을 다시 봐야 한다. 어느 쪽이든 쓸 수 있다.

## 중단 조건 — 하나라도 걸리면 멈추고 알린다

| | 상황 | 왜 |
|---|---|---|
| 1 | 기준선이 상온보다 **5℃ 이상 높다** | 냉각 부족. 적합 출발점이 틀린다 |
| 2 | 설정 200 평탄값이 **95~125℃ 밖** | 조준이나 거리가 어제와 다르다 |
| 3 | 설정 400에서 12초 전에 **120℃ 도달** | 즉시 빼기. τ가 예상보다 훨씬 빠르다 |
| 4 | **R4가 R1과 τ 15% 이상 차이** | 방이 데워졌다. 브래킷이 잡아낸 것 |
| 5 | 프로브 피복에서 **연기** | 즉시 중단 |
