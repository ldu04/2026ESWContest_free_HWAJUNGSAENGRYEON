# 현장 카드 — 열풍기 첫 가동 & τ 측정 순서
### 작업대에 띄워놓고 보는 용도. 순서대로만 하면 된다.

---

## ⚠️ 시작 전 — 반드시 알아야 할 것 두 개

### ① DS18B20은 **125℃가 절대 한계**다

우리 온도센서(DS18B20)의 사양상 최대 사용 온도는 **+125℃**이고, 방수형 케이블 피복은 그보다 더 낮은 경우가 많다(대략 105℃).

**그런데 τ 측정은 센서를 열풍 속에 넣고 온도가 평평해질 때까지 기다리는 작업이다.** 공기를 150℃로 맞추면 센서는 결국 150℃에 수렴하려 하고, **센서가 죽는다.**

```
★ 공기 온도를 70~90℃로 설정한다. 150℃로 하지 말 것.
```

**괜찮은 이유:** τ는 **온도가 아니라 공기 유속에 의존한다**(이건 이미 실측으로 확인된 사실이다). 그러니 80℃로 재도 300℃로 잰 것과 같은 τ가 나온다. 낮게 쓸 이유만 있고 높게 쓸 이유가 없다.

- 상온 25℃ → 80℃면 진폭 55℃, 9비트(0.5℃ 눈금)로 **110칸**. 곡선 그리기에 차고 넘친다.
- 4평 방에서 80℃ 공기가 300℃보다 압도적으로 안전하다.

> **데모 때는 다르다.** 데모에서는 노드가 60℃ 부근에서 "사망 판정"을 받고 끝나므로, 센서가 125℃에 도달하기 전에 상황이 종료된다. 하지만 **τ 측정은 센서를 계속 담가두는 작업**이라 완전히 다르다.

### ② 손 보호

- **면장갑 또는 오븐장갑만.** 코팅 장갑은 녹아서 피부에 붙는다.
- 노즐은 **끄고 나서도 몇 분간 뜨겁다.**
- 창문 열고, 노즐 방향 50cm 안에 종이·비닐·커튼 치울 것.

## 단계 0 — 열풍기 첫 가동 (측정 아님. 기계를 아는 게 목적)

**여기서는 데이터를 남기지 않는다.** 기계가 어떻게 동작하는지만 파악한다. 30분 정도.

### 0-1. 변압기 먼저

1. 명판 확인 — `입력 220V / 출력 110V / 2KVA`
2. **변압기만 콘센트에 꽂고 아무것도 연결하지 않은 채 1~2분** — 탄내·과열·심한 진동 없는지. 약한 웅웅거림은 정상.
3. 이상 없으면 **열풍기를 변압기의 110V 출구에** 연결.

### 0-2. 최저 설정으로 켜본다

**온도 최저·풍량 최저**로 시작. 노즐 방향은 빈 곳으로.

### 0-3. ★ 다음 5가지를 확인하고 적어둔다

| 확인 항목 | 왜 필요한가 |
|---|---|
| **온도 조절이 숫자로 되나, 다이얼인가** | 재현 가능한 설정값을 기록할 수 있는지 결정 |
| **풍량이 몇 단인가 (또는 연속 다이얼인가)** | τ(u) 곡선의 x축이 몇 점 나오는지 결정 |
| **찬바람(팬만) 모드가 따로 있나** | 없으면 냉각모드를 대신 쓴다 (아래) |
| **끄면 냉각모드로 팬이 계속 도나. 몇 초쯤 도나** | **풍속계 측정 창이 이만큼이다** |
| **설정 온도에 도달하는 데 몇 초 걸리나** | 시행마다 예열 대기 시간이 정해진다 |

> **냉각모드가 중요한 이유:** 리워크 스테이션은 보통 전원을 꺼도 발열체를 식히려고 팬이 잠시 더 돈다. **그 구간이 "히터 OFF, 팬만"** 상태이고, **풍속계를 넣을 수 있는 유일한 시간**이다(풍속계 날개는 45℃까지만 견딘다).

### 0-4. 손으로 대충 감 잡기

노즐에서 **10cm쯤 떨어진 곳에** 손을 잠깐 스쳐본다(대고 있지 말 것). 최저 설정에서 "따뜻한 정도"면 정상.

**여기까지가 오늘 밤 첫 30분이다.** 이 결과를 알려주면 다음 단계 설정값을 같이 정한다.

## 측정 우선순위 — ★순서가 바뀌었다

Claude Code는 **τ(u) 곡선(풍속별 τ)**을 1순위로 잡았는데, 그건 D-045 기준이고 **어제 검토에서 우선순위가 바뀌었다.**

```
1순위 ★★  데모에서 실제로 쓸 설정에서의 τ        ← 데모 성립 여부가 여기 달림
2순위 ★★  센서 개체별 τ 편차 σ_τ                 ← 데모 성립 여부가 여기 달림
3순위  ★   풍량 단수별 τ(u) 곡선                  ← 시뮬 논증 보강용. 시간 남으면
4순위  ★   진짜 무풍 τ                            ← 시간 남으면
```

**왜 바뀌었나:** 데모에서 노드 간 사망 간격이 약 5초인데, 센서 지연 편차 σ_τ가 그 정도 크기면 방향 추정이 무너진다. **"열풍기를 쏘면 대시보드에 화살표가 뜬다"는 아직 한 번도 검증된 적 없는 가정이고**, 1·2순위가 바로 그걸 검증한다. τ(u) 곡선은 시뮬 논증을 보강하는 것이라 급하지 않다.

## 단계 1 — 데모 설정에서 τ (1순위)

**세팅을 정하고 테이프로 위치를 표시한 뒤 세션 내내 바꾸지 않는다.**

| 고정할 것 | 값 |
|---|---|
| 노즐 | 어느 것을 끼웠는지 |
| 거리 | 노즐 끝 ~ 센서, 몇 cm |
| 정렬 | 제트 중심축에 센서를 맞춤 |
| 공기 온도 | **70~90℃** (125℃ 금지) |
| 풍량 | 데모에서 쓸 설정 |

**센서는 나무젓가락 끝에 캡톤테이프로 고정**한다 — 손을 열풍에 넣지 않고 넣었다 뺄 수 있다. **이게 계단 입력(step input)을 만드는 방법이다.**

### 한 시행 절차

```
1) 열풍기 켜고 1~2분 예열 대기      ← 예열 중엔 출력이 변해서 곡선이 지저분해진다
2) 로깅 시작
3) 그냥 10~15초 둔다                ← ★이 구간이 상온과 센서 잡음을 자동 기록한다
4) 젓가락을 열풍 안으로 빠르게 진입 → 고정
5) 온도가 평평해질 때까지 대기       ← 대략 τ의 4~5배 시간
6) 빠르게 이탈
7) 10초 더 두고 로깅 정지
```

```
명령: powershell -ExecutionPolicy Bypass -File C:\Users\Public\esp32\log_tau.ps1 -Seconds 120 -Label tau_jet_d05_T80_n01_r1
```

**최소 3회 반복.** 매번 센서가 상온으로 돌아온 뒤에 다음 시행(선풍기 있으면 훨씬 빠름).

> **③번이 중요한 이유:** 상온을 손으로 적으면 빠뜨리기 쉽고, 빠뜨리면 그 파일은 못 쓴다. 로깅을 먼저 시작해두면 **모든 파일이 자기 상온을 안에 갖게 되고**, 덤으로 그 10초가 **센서 잡음 크기**까지 재준다.

### ★ 가열 곡선과 냉각 곡선은 같은 τ가 아니다

| 곡선 | 실제로 재는 것 | 쓸모 |
|---|---|---|
| **제트 진입(가열)** | **그 유속에서의 τ** | ★ 주 측정. τ(u)는 이것만으로 만든다 |
| 제트 이탈(냉각) | **실내 공기의 τ** (유속이 다르다!) | 무풍 τ의 공짜 반복측정으로 재활용 |
| 제자리에서 히터만 OFF | 노즐 냉각 + 센서 지연의 **직렬** | 오염됨 — 아래 참조 |

τ = mc/(hA)이고 **h는 센서 주변 유속에 의존**한다. 진입은 제트 속(유속 큼), 이탈은 실내(유속 작음) — **다른 조건의 다른 τ다.** 섞으면 τ(u) 곡선이 통째로 오염된다.

> **히터만 끄는 방식(Claude Code 제안):** 히터를 꺼도 노즐 금속이 계속 열을 뱉으므로 공기 온도가 계단이 아니라 서서히 내려간다. 그러면 "노즐 냉각 + 센서 지연"의 직렬이 측정되고, 직렬 지연은 **겉보기 시간을 항상 늘린다**(τ 과대평가).
> **→ 한 번만 대조용으로 찍어보자.** 진입 τ와 비슷하면 오염이 무시할 만하다는 뜻이고, 히터-OFF 쪽이 뚜렷이 길면 진입 방식만 쓴다. 판단은 측정으로.

## 단계 2 — 센서별 τ 편차 σ_τ (2순위)

**단계 1과 완전히 동일한 조건**(같은 풍량·거리·정렬·온도)에서 **센서만 바꿔가며** 반복.

- **최소 5개, 가능하면 8개 이상**
- 각 센서에 마스킹테이프로 **번호를 붙여둘 것**
- 산출: τ의 평균과 표준편차 → **σ_τ 실측치**

**이게 시뮬이 가정한 σ=30%를 실측으로 대체한다.** 실측이 더 작으면 지터 문제가 완화되고, 데모 전망이 밝아진다.

---

## 단계 3~4 — 시간 남으면

**3. 풍량 단수별 τ** — 단수를 바꿔가며 단계 1을 반복. 각 단수에서 냉각모드 때 풍속계로 m/s를 읽어둔다.

> **풍속계 주의:** 리워크 스테이션 노즐은 지름이 작아서(≈5~10mm), 날개 지름 3~4cm짜리 풍속계로는 **제트가 날개를 다 덮지 못해 실제보다 낮게 읽힌다.** 그러니 이 값은 **절대 m/s가 아니라 단수의 순서를 나타내는 상대 지표**로만 기록한다. τ의 단조성 확인에는 그걸로 충분하다.

**4. 진짜 무풍 τ** — 에어컨·선풍기·환기 전부 정지, 문 닫고 공기가 가라앉기를 몇 분 기다린 뒤, 센서를 데운 다음 **열원을 완전히 치우고 자연 냉각 곡선만** 기록. τ가 80초 이상이면 완전히 식는 데 7분 넘게 걸리니 끊지 말 것. **열풍기는 미리 끄고 충분히 식힌 뒤** 진행(창문을 닫으므로).

## 흔한 함정

- **예열 부족** — 켜자마자 재면 출력이 변하는 중이라 곡선이 지저분하다. 1~2분 기다릴 것.
- **센서 위치가 조금씩 달라짐** — 제트는 좁아서 1cm만 어긋나도 유속이 크게 달라진다. **테이프로 위치 표시 필수.**
- **냉각 대기 부족** — 안 식은 상태에서 다음 시행을 하면 초기값이 틀어진다.
- **풍속계를 뜨거운 바람에** — 날개가 변형된다. 히터 OFF(냉각모드)에서만.
- **85.0℃가 계속 나옴** — DS18B20의 전원투입 기본값. 변환이 한 번도 안 끝났다는 뜻(전원·배선 문제). 즉시 중단.
- **−127.0℃** — 버스 무응답. 배선 확인.
