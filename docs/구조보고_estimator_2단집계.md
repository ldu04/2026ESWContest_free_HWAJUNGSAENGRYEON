# 구조 보고 — `estimator`의 실제 2단 구조와 집계 [2.N 추가-H]

> **목적:** Cowork 명세가 "전역 평면 적합 하나"를 기술하고 있어 실제 구조가 빠져 있다.
> 명세에 "2단 구조와 집계" 절을 신설할 수 있도록 **코드 기준으로 정확히** 기술한다.
> **추측으로 쓰지 않았다** — 아래 모든 항목은 `sim/estimator.py` 현행 코드에서 직접 읽은 것이다.
> (파일은 프로젝트 강령상 **불변**이므로 이 문서는 기술만 하고 변경을 제안하지 않는다.)

---

## 1. 전체 구조 — 전역 적합이 **아니다**

```
사망 이벤트 D = {(x_i, y_i, t_i)}
        │
        ├─[1단] _fit_local()   각 사망 노드 i마다 **독립적인 국소 평면 적합**  →  per_node[i]
        │
        └─[2단] _fit_global()  per_node 의 결과들을 **집계**                  →  dir_global, speed_global
```

**전역 평면 적합은 존재하지 않는다.** 평면 적합은 1단에서 **노드 수만큼** 수행되고,
2단은 그 결과 벡터들을 합칠 뿐 **재적합하지 않는다.**

---

## 2. 1단 — `_fit_local()`

### 2-1. 지역집합 `S_i`
```
S_i = {i} ∪ { j ∈ neighbors(i) : j 가 사망했고 |t_j − t_i| ≤ dt_window }
```
- `neighbors(i)`는 **무선 그래프**(`Network`가 `radio_range_m`으로 만든 것)다. 격자 인접이 아니다.
- `dt_window` 기본 **8.0 s**. **시간 창이 공간 이웃을 걸러낸다** — 이웃이라도 사망 시각이 멀면 빠진다.
- `i` 자신이 항상 포함된다.

### 2-2. 게이트 2개
| 게이트 | 조건 | 동작 |
|---|---|---|
| 표본 수 | `len(S_i) < min_samples`(기본 3) | `continue` — per_node에 **넣지 않음** |
| 퇴화 | `|∇T| ≤ eps`(기본 **1e-6**) | `continue` — per_node에 넣지 않음 |

> ⚠ **퇴화 게이트가 사실상 작동하지 않는다.** `eps=1e-6`은 부동소수 하한 수준이라,
> `|∇T| = 0.0247`(속도 40.4 m/s) 같은 **거의 퇴화한** 적합도 그대로 통과한다.
> 2.N §1에서 그 노드가 전역 가중의 86.4 %를 차지했다. [D-059]

### 2-3. 적합
```
A = [[x_k, y_k, 1] for k in S_i]   (n×3)
b = [t_k for k in S_i]
(a, b, c) = lstsq(A, b)            # 최소제곱, rcond=None
∇T_i = (a, b)
per_node[i] = { dir: ∇T_i/|∇T_i|,  speed: 1/|∇T_i|,  grad: ∇T_i,  c, pos: (x_i,y_i),  t: t_i }
```

### 2-4. ★ 국소 적합들은 **독립이 아니다**
노드 i는 자기 적합에도 들어가고 **이웃들의 적합에도** 들어간다. 격자에서 한 관측이
여러 `S_j`에 중복 등장하므로 **per_node 추정치들은 상관돼 있다.**
⇒ 2단에서 이들을 독립 표본처럼 평균하면 **불확실성이 과소평가**된다.
(2.M §1의 `δφ̂_global`이 `/√n`으로 나눈 것도 같은 이유로 낙관적이다 — 이번에 드러난 사항.)

---

## 3. ★ 2단 — `_fit_global()` : 여기가 명세에서 빠진 부분

```python
acc = zeros(2); speeds = []
for v in per_node.values():
    w = v["speed"]                     # = 1/|∇T_i|
    acc += w * array(v["dir"])         # 단위벡터를 speed로 가중해 **벡터합**
    speeds.append(v["speed"])
dir_global   = acc/|acc|  if |acc| > eps else None
speed_global = median(speeds)          # ← 방향과 **다른 집계**
```

### 3-1. 방향 집계
- **가중치 `w_i = speed_i = 1/|∇T_i|`**
- 단위 방향벡터의 **가중 벡터합**을 정규화. 각도 평균이 아니라 벡터 평균이다.
- ⇒ 서로 반대 방향이 섞이면 상쇄되어 `|acc|`가 작아지고, `eps` 미만이면 `None`.

### 3-2. 속도 집계
- **`median(speeds)`** — 방향과 달리 **중앙값**이다.
- ⇒ **한 추정기 안에서 방향은 가중평균, 속도는 중앙값**이라는 **비대칭 집계**를 쓴다.
  퇴화 적합이 속도 중앙값에는 거의 영향을 못 주지만 **방향에는 지배적 영향**을 준다.
  (2.N §1의 flank d30: 속도 중앙값 0.8599로 정상인데 방향은 77.89° 틀렸다.)

### 3-3. 퇴화 처리
- 2단에는 **퇴화 배제가 없다.** 1단의 `|∇T| ≤ 1e-6` 게이트를 통과한 것은 전부 들어간다.
- `|∇T|`가 작을수록 `w_i`가 커지므로, **퇴화에 가까울수록 더 큰 가중**을 받는다.

## 4. 명세에 추가돼야 할 사항 (요약)

| # | 항목 | 현행 코드 |
|---|---|---|
| 1 | 평면 적합은 **전역 1회가 아니라 노드별 N회** | `_fit_local` 루프 |
| 2 | 지역집합은 **무선 이웃 ∩ 시간창** | `neighbors` + `dt_window` |
| 3 | 방향 = per-node 단위벡터의 **1/\|∇T\| 가중 벡터합** | `_fit_global` |
| 4 | 속도 = per-node 속도의 **중앙값** (방향과 다른 집계) | `_fit_global` |
| 5 | 퇴화 배제는 `\|∇T\| ≤ 1e-6` **하나뿐**이고 2단엔 없다 | `_fit_local` |
| 6 | per-node 추정치는 **표본 중복으로 상관**돼 있다 | `S_i` 중복 |

> **관찰/해석 분리:** 위는 전부 **관찰**(코드에 그렇게 쓰여 있다)이다.
> "이 구조가 [D-059]의 가중 폭주를 숨겼다"는 것은 **해석이며 미검증**이다 —
> 다만 명세에 2단 구조가 없으면 3·5번 항목이 검토 대상에 오르지 않는다는 점은 지적해 둔다.
