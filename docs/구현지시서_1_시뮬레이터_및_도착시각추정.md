## 2. 데이터 모델

### 2.1 좌표·시간
- 2D 평면, 단위 = 미터. 시간 단위 = 초. 틱 간격 `dt`(기본 0.1s).
- 노드 위치: 격자(`grid_rows × grid_cols`, 간격 `spacing_m`) 기본, config로 임의 좌표도 허용.
- **Sink(게이트웨이):** 격자 한쪽 모서리에 1개 고정(불이 마지막에 도달하는 쪽). id = 0.

### 2.2 Node 상태 (`node.py`)
```
enum NodeState: ALIVE, DYING, DEAD
Node:
  id: int
  pos: (x, y)
  state: NodeState = ALIVE
  temp: float = ambient(기본 25℃)
  last_heartbeat_t: float
  death_t: float | None          # 실제 사망 시각(ground truth 기록용)
  is_sink: bool = False
```
행동:
- 매 틱 `temp` 갱신(화재 모델이 부여, §3).
- ALIVE & `temp ≥ temp_threshold`(기본 80℃) → **DYING** 진입, `t_die = now + last_gasp_delay`(기본 0.3s) 예약.
- DYING 중 즉시 **Last-Gasp 패킷** 1회 생성: `{id, pos, last_temp, t=now, type="LAST_GASP"}` → 라우팅에 투입.
- `now ≥ t_die` → **DEAD**. 이후 하트비트·릴레이 중단.
- ALIVE는 `heartbeat_period`(기본 1.0s)마다 하트비트 방출.

## 3. 화재 확산 Ground-Truth 모델 (`fire.py`)

추정기가 "정답"과 비교해 오차를 낼 수 있도록, 화재의 참값을 명시적으로 생성한다.

- **1차 모델(기본): 직선 전선(line front).**
  - 파라미터: 진행 방향 단위벡터 `n=(cosθ, sinθ)`, 전선 속도 `speed_true`(기본 1.5 m/s), 시작 오프셋.
  - 전선의 현재 위치: `front_pos(t) = start + n * speed_true * t`.
  - 한 점 `p`가 전선을 통과하는 시각(참 도착시각): `T_true(p) = ((p - start)·n) / speed_true`.
- **노드 온도 부여:** 전선까지의 부호거리 `d = (p - front_pos(t))·n`.
  - `d > 0`(아직 안 옴): `temp = ambient + (peak-ambient) * exp(-d / warm_scale)` (다가올수록 상승).
  - `d ≤ 0`(전선 통과): `temp = peak`(기본 300℃) → 임계 초과로 사망 유발.
- **확장(옵션, config 플래그):** 점화원 방사형 확산(원형 전선), 바람 노이즈(θ에 작은 요동). 1차 검증 후.

> 이 모델 덕분에 추정기 출력(방향·속도·도달시각)을 `n, speed_true, T_true`와 직접 비교 → **정량 오차** 산출 가능.

## 4. 네트워크·자가치유 라우팅 (`network.py`)

### 4.1 그래프
- 두 노드가 서로 `radio_range_m`(기본 = spacing×1.8) 이내면 링크 존재(무향).
- Sink까지 **멀티홉**으로 패킷 전달(직통 아님 — 최전선 노드는 sink와 멀다).

### 4.2 라우팅 = 자가치유
- 각 노드는 sink로 가는 **다음 홉**을 최단 홉 트리로 계산(BFS/Dijkstra, 홉 수 기준).
- **토폴로지 변화(노드 DEAD 확정) 시 경로 재계산** = 자가치유. 재계산에 걸린 (사망확정 → 경로복구) 틱 수를 **재라우팅 지연**으로 기록.
- 패킷 전달: DYING/ALIVE 노드가 만든 패킷을 다음 홉으로 릴레이. 경로 상에 살아있는 노드가 있으면 sink 도달(성공), 완전 단절 시 실패(전달률에 반영).

### 4.3 stock vs ours 스위치 (`config.mode`)
- `mode="stock"`: 자가치유 라우팅만. 노드 죽으면 우회, **죽음은 단순 손실**(이벤트·추정 없음). 출력 = 연결성/전달률뿐.
- `mode="ours"`: stock 위에 **죽음=1급 이벤트 승격 → verification → estimator**까지. 출력 = 화선 벡터·도달예측 추가.
- 두 모드를 같은 화재 시나리오로 돌려 **비교표**(보고서용) 생성.

## 5. 통신두절 vs 사망 판정 — 오탐 방어 (`verification.py`)

목적: "조용해진 노드"가 진짜 파괴인지, 일시적 링크 끊김인지 구분. 오탐이 화선 지도를 오염시키므로 핵심.

- **일시적 링크 끊김 모델:** 매 틱 각 링크가 확률 `p_dropout`(기본 0.02)로 잠깐 두절 후 복구(오탐 유발원 = 테스트용).
- **사망 확정 규칙(모두 만족해야 DEAD로 승격):**
  1. **다수결:** 침묵 노드를 이웃 중 `K_confirm`(기본 3)개 이상이 독립적으로 "미수신"으로 관측.
  2. **온도 교차검증:** 그 노드의 마지막 관측 온도가 `warn_temp`(기본 60℃) 이상이었거나, 이웃들이 고온 상승을 관측.
  3. **지속성:** 침묵이 `silence_timeout`(기본 3×heartbeat_period) 이상 지속.
- 위 조건 미달 → 일시 두절로 간주(무시). 노드가 다시 하트비트 보내면 ALIVE 유지.
- **판정 출력:** 확정 사망 이벤트 `{id, pos, death_t_est, last_temp}` → estimator로 전달.
- **측정:** 오탐률(살아있는데 DEAD 판정), 미탐/지연(실제 사망~확정까지 시간). §7에서 K·timeout 스윕으로 트레이드오프 곡선 생성.

## 6. ★ Failure-Pattern 추정 (`estimator.py`) — 이 프로젝트의 심장

**입력:** verification이 확정한 사망 이벤트들의 집합 `D = {(x_i, y_i, t_i)}` (t_i = 추정 사망시각).
**출력:** ① 전선 진행 방향 단위벡터 ② 전선 속도(m/s) ③ 임의 지점 도달예측시각·ETA ④ 각 생존노드 잔여시간.

### 6.1 핵심 원리 (부호 주의 — 이게 맞는 버전)
도착시각 함수 `T(x,y)`(그 지점에 불이 도달한 시각)를 사망표본으로 국소 복원한다.
- 전선이 방향 `n`으로 속도 `s`로 움직이면 `T`는 `n` 방향으로 **증가** → `∇T = n / s`.
- 따라서 **진행 방향 = ∇T / |∇T|**, **속도 = 1 / |∇T|**. (※ v3 헌장의 −∇T는 오기, 이 문서가 정본)

### 6.2 국소 평면 최소제곱
각 사망노드 i와 그 **사망한 이웃들**에 대해 `t ≈ a·x + b·y + c`를 최소제곱으로 적합:
```
지역집합 S_i = {i} ∪ {j : j는 i의 이웃이고 DEAD, |t_j - t_i| ≤ dt_window}
[x_j, y_j, 1] 행렬 A, 벡터 t_j → 최소제곱 해 (a,b,c)
grad_i = (a, b)
if |grad_i| > eps:
    dir_i   = grad_i / |grad_i|
    speed_i = 1 / |grad_i|
```
- 표본 3개 미만이면 그 지점은 추정 보류(성긴 구간).

### 6.3 전역 추정
- `dir_global` = 지역 dir_i들의 (속도 가중) 평균 후 정규화. `speed_global` = median(speed_i) (이상치에 강함).
- **강건성:** 이웃 4개 미만 표본, 각도 이상치는 median/robust 평균으로 완화.

### 6.4 도달예측 / 생존시간
- 임의 지점 `p`(생존노드 또는 대원 위치): 가장 가까운 사망노드 `k` 기준
  `T_pred(p) = t_k + grad_k · (p - p_k)` → `ETA(p) = T_pred(p) - now` (= 생존/대피 시간).
- `ETA ≤ alert_horizon`(기본 30s)인 생존노드·대원 → **대피 경보 Flag**.

### 6.5 정확도(테스트)
- `tests/test_estimator.py`: 알려진 `n, speed_true`로 사망표본 합성 → 추정 방향오차(deg)·속도오차(%)가 허용치 내인지 검증. 노이즈 유무 두 케이스.

## 7. 정량 지표 (`metrics.py`) — 보고서·발표 수치

매 실행마다 아래를 수집·요약(CSV):
- **전달률:** sink 도달 패킷 / 생성 패킷 (노드 N개 사망 시점별).
- **재라우팅 지연:** 사망확정 → 경로복구까지 평균/최대(ms 환산).
- **방향 오차(deg), 속도 오차(%):** 추정 vs ground-truth, 시간에 따른 수렴 곡선.
- **도달예측 오차:** ETA 예측 vs 실제 사망시각(초).
- **오탐률 / 미탐지연:** verification 파라미터별.
- **stock vs ours:** 같은 시나리오에서 "stock=연결성만 / ours=벡터·ETA 추가" 대비표.
- **노드 밀도 스윕:** 노드 수 9/12/16/20/…에서 추정오차 → "밀도↑ 시 정밀도↑" 그래프(성김 방어 논리 근거).

## 8. 메인 루프 (`engine.py`) — 의사코드

```
def run(config) -> Iterator[Snapshot]:
    rng = default_rng(config.seed)
    nodes = build_grid(config); fire = Fire(config); net = Network(nodes, config)
    verifier = Verifier(config); estimator = Estimator(config); metrics = Metrics()
    t = 0.0
    while t < config.t_max and not all_dead_or_isolated(nodes):
        fire.update(t)                                  # 전선 전진
        for n in nodes: n.update_temp(fire, t)          # 온도 부여
        for n in nodes: n.step(t)                       # 임계→DYING→Last-Gasp→DEAD
        net.apply_dropouts(rng)                         # 일시 링크 두절(오탐원)
        packets = net.collect_and_relay(t)              # 릴레이 → sink 전달률
        silent = net.detect_silence(t)                  # 침묵 관측
        deaths = verifier.confirm(silent, nodes, t)     # 오탐 방어 → 확정 사망
        if config.mode == "ours":
            net.rebuild_routes_if_changed(deaths)       # 자가치유
            est = estimator.update(deaths, t)           # ★ 화선 벡터·ETA·경보
        else:
            net.rebuild_routes_if_changed(deaths); est = None
        metrics.record(t, nodes, packets, deaths, est, fire)
        yield Snapshot(t, nodes, net.topology(), est, fire.front_pos(t))
        t += config.dt
    metrics.summarize()   # CSV
```

## 9. 시각화 (`viz/animate.py`) — 1차(matplotlib)
스냅샷 스트림을 받아 프레임마다 렌더:
- 노드: ALIVE=초록, DYING=주황, DEAD=검정, Sink=파랑 사각.

- 상단 HUD: t, 전달률, 재라우팅 지연, 방향/속도 추정오차.
