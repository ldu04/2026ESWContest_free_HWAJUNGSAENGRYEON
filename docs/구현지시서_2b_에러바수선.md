# 구현 지시서 #2b — 에러바 신뢰도 수선 (바람 위상 무작위화 + 방사-바람 결합)
### 화중생련 「불사」 / 스트레스 테스트의 유일한 방법론적 구멍만 좁게 메우고 시뮬은 종료

> **범위 원칙:** 이건 **작은 수선(patch)**이다. STRESS_REPORT §4의 한계 #1·#2·#3만 고친다.
> **끝나면 시뮬레이터 다듬기는 종료** — 알고리즘은 이미 검증·특성화 끝났고, 이후는 대시보드(#2)·펌웨어(#3)로 간다.

## 0. 왜 이것만 하나 (배경)

지시서 #2는 잘 됐지만, STRESS_REPORT §4에 방법론적 구멍이 하나 있다:
**바람·돌풍·방사·밀도 축에서 시드를 20개 돌려도 추정오차가 거의 안 변해 에러바(±불확실성)가 ≈0**으로 나온다.
원인은 추정 성능이 좋아서가 아니라 — **그 축에 실제 무작위성이 안 들어가서**다:
① 불이 결정론적이고 ② 바람이 **고정 위상 사인파 하나(단일 실현)**라, 시드가 정작 측정 대상을 안 흔든다.
부작용으로 S2a에서 θ=5°일 때 오차가 baseline보다 낮아지는 **비단조(non-monotonic)** 이상 곡선까지 생겼다.

→ 이걸 고치면 에러바가 **진짜 통계**가 되고, 슬라이드의 이상 곡선도 사라진다. 이게 발표 신뢰도에 직접 걸리는 유일한 지점.

## 1. 할 일 (딱 두 가지)

### 수선 1 · 바람 실현을 시드에 의존시키기 (한계 #1·#2 해결)
- **현재:** 바람 섭동(θ 요동, 속도 변동)이 고정 위상 사인파 1개 → 모든 시드가 동일한 바람을 봄.
- **바꿀 것:** 바람 섭동의 **위상(및 무작위 성분)을 rng(seed)에서 뽑아**, 시드마다 **통계적으로 같은 세기·다른 실현**의 바람을 갖게 한다.
  - 구현 권장: θ 요동과 속도 변동을 **소수의 무작위 푸리에 성분**(랜덤 위상·랜덤 성분 진폭, 합은 정규화)으로 생성하거나, 필터드 노이즈(간단한 OU 과정)로 생성. 위상·성분은 `rng = default_rng(seed)`에서 draw.
  - **스윕 knob은 그대로 유지:** θ 표준편차·속도변동% = "세기". 세기를 고정한 채 실현만 시드별로 달라져야 함(스윕 의미 불변).
- **회귀 안전(필수):** 세기 0이면 **정확히 S1(직선 전선) baseline과 동일**해야 한다. 기존 pytest 10/10 유지, S1 수치 완전 동일.
- **기대 효과:** S2a·S2b에서 시드 20~30개가 **진짜로 다른 오차**를 내어 에러바가 유의미해지고, 비단조 5° 딥이 사라지거나(또는 통계적으로 설명됨).

### 수선 2 · 방사형에 바람 결합 (한계 #3 해결)
- **현재:** 방사형이 바람을 무시(`radial_wind10 == radial`) → S3 복합이 사실상 미결합.
- **바꿀 것:** 바람이 방사 확산을 **비등방(anisotropic)**으로 만든다 — **바람 방향으로 빠르게(다운윈드 신장), 역풍으로 느리게.** (현실의 바람 부는 산불이 타원형으로 늘어나는 것과 일치.)
  - 모델(간단·명확): 노드 각도 φ(점화원 기준)에 대해 **참 국소 확산속도 = base_speed × (1 + wind_bias × cos(φ − wind_dir))**. `wind_bias`는 세기 knob.
  - **참값 정의(평가용):** 각 노드의 참 국소 방향 = (점화원→노드) 방사 방향(불변). 참 국소 속도 = 위 비등방 식.
- **평가:** D-013 유지(국소 방향오차 분포). 추가로 **국소 속도오차**를 참 비등방 속도와 비교. 이제 S3+바람이 **진짜 복합 케이스**가 됨.

## 2. 명시적 제외 (하지 말 것)

- ❌ **저밀도(9노드) 속도 붕괴 "보정" 안 함.** 대신 STRESS_REPORT에 **"9노드 붕괴 → 12노드+ 안정 = 12노드 이상 운용의 데이터 근거(재료비·헌장 12노드와 정합)"**로 **설계 근거로 기록만.** 이건 약점이 아니라 우리 노드 수 선택의 정당화다.
- ❌ estimator 알고리즘·verification 규칙·방어 파라미터(K_confirm·silence_timeout·dt_window) **일절 불변** (여전히 measure-honest, §2 규율).
- ❌ 웹 대시보드·펌웨어 손대지 않음.
- ❌ 영향 없는 시나리오(S4 배치·S5 dropout·S6 밀도) **재실행 불필요** — 바람 변경과 무관하므로 기존 결과 유지. **재실행은 바람/방사가 관여하는 S2a·S2b·S3·S7만.**

## 4. 완료 기준 (Definition of Done)

1. 바람 실현이 seed 의존 → S2a·S2b·S3·S7에서 **에러바(±std)가 0이 아님**. 비단조 5° 딥 해소/설명.
2. **회귀 안전:** pytest 10/10, 세기 0 → S1 = 지시서 #1 수치 완전 동일.
3. 방사-바람 결합 구현 → S3+바람이 `radial`과 다른 진짜 복합 결과.
4. STRESS_REPORT 갱신(에러바·한계 #1~3 해결 표시·저밀도 재서술).
5. `docs/DECISIONS.md`(D-016~)·`docs/PROGRESS.md`(새 블록) 갱신.
