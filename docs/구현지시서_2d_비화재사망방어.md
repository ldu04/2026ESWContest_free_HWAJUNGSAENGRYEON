# 구현 지시서 #2d — 비화재 사망 방어 강화 (오탐 방어의 새 구멍 메우기)
### 화중생련 「불사」 / #2c에서 발굴한 약점(S11: 화선 오염률 93~98%)을 원칙적으로 방어

> 배경: #2c가 새 한계를 발굴함 — **비화재 사망**(배터리·고장 등 불이 아닌 죽음)이 화재-활성 구역에서
> 온도 교차검증을 통과해 화선 신호로 오분류(오염률 93~98%, 방향오차 2°→16°).
> 원인: 규칙2가 "**이웃 고온 OR 자신 고온**"의 OR 게이트 → 불이 근처면 비화재 사망도 이웃 고온으로 통과.
> ★ 주의: 기존 헤드라인 오탐 방어("통신두절 vs 파괴", fp_rate)는 **여전히 0%로 멀쩡**. 이번은 **다른 축**.

---

## 목표
비화재 사망이 **도착시각 추정(화선 방향·속도)에 오염을 주입하는 걸** 줄인다.
헤드라인 지표(살아있는데 확정하는 fp_rate=0%)는 유지하면서, **화선 오염률(nonfire_pollution_rate)**을 낮춘다.

## 설계 — 물리에서 도출 (OR 게이트를 3분기로 분할)

핵심 물리: **불에 타 죽으려면 그 노드의 자기 온도가 반드시 warn_temp를 향해 올랐어야 한다(그게 죽음 조건).**
따라서 침묵/사망 노드를 세 갈래로 분류한다:

1. **자기 온도 이력이 상승(≈warn_temp 접근/도달)** → **화재사망**: 도착시각 추정에 **채택**.
2. **자기 온도 이력이 존재하는데 상승 없음(주변온도 근처 유지)** → **비화재사망**: 도착시각 추정에서 **제외**
   (단 노드 손실로는 처리 → 자가치유 라우팅은 정상 우회). = "안 뜨거웠음을 우리가 안다".
3. **자기 온도 데이터 유실**(Last-Gasp 손실 등) → 보강 판정: **이웃 고온 AND 시공간 정합**
   (이 죽음의 시각이 국소 도착시각 평면에 residual 임계 내로 맞나). 맞으면 잠정 화재사망, 이상치면 **suspect→제외**.

> 3번의 **시공간 정합(도착시각 평면 residual 검사)**은 덤으로 **비화(S10)**의 튀는 죽음도 이상치로 걸러
> 방향 오염을 줄인다(부수 효과, 완전한 다중소스 대응은 아님).

## 임계값 설정 — measure-first (테스트 점수로 튜닝 금지)
- 온도 상승 판정 임계: **기존 warn_temp 체계에서 도출**(예: 사망 직전 창에서 온도가 주변대비 유의미 상승했는가). 새 magic number를 테스트에 맞춰 스윕하지 말 것.
- residual 임계: **baseline(S1) 화재사망들의 도착시각 평면 residual 분포에서** 정한다(예: 평균+kσ). 테스트 S10/S11 점수 보고 고르지 말 것.
- 파라미터는 **물리·baseline 통계에서 먼저 확정 → 그 다음 측정**. 순서 반대로 하면 overfitting.

## 반드시 지킬 규율 (anti-overfit)
1. **S1~S11 전체 재실행.** baseline **S1~S7이 #2d 전 대비 안 망가짐**을 증명(방향·속도 오차가 노이즈 범위 내). 세기0 **회귀 10/10 유지**.
2. **정직 보고:** 오염률이 93~98% → 몇 %로 줄었는지 그대로. 완전 해소가 아니면 잔여치 명시.
3. **트레이드오프 정량화:** 3번 분기에서 **실 화재사망을 잘못 제외**하는 손해가 생기면(자기온도 유실 케이스) 그 비율·방향오차 영향도 측정해 보고.
4. estimator의 **추정 수학(최소제곱 평면적합) 자체는 불변** — 바뀌는 건 "어떤 죽음을 추정에 넣을지"의 **선별(gating) 로직**뿐.

## 완료 기준 (DoD)
1. 교차검증에 3분기 선별 로직 추가(verification 계층). estimator 평면적합 수학 불변.
2. S11 재측정: 화선 오염률·방향오차 **개선 전/후 나란히** CSV·곡선. S10도 부수효과 확인.
3. S1~S7 baseline 비열화 + 세기0 회귀 유지 증명(수치로).
4. 트레이드오프(온도유실 시 실화재 제외율) 측정·서술.
5. STRESS_REPORT §1c에 **#2d 전/후 비교 블록** 추가, §4 한계표의 항목5(비화재) 상태를 "⚠️신규발견"→"부분방어(잔여 X%)"로 갱신.
6. DECISIONS(D-029~)·PROGRESS 갱신. 커밋.

## 하지 말 것
- 테스트 점수 보고 임계값 스윕(측정 후 튜닝 금지, 기록만).
- 추정기 평면적합 수학 변경(개선은 선별 로직에서만).
- 실물/펌웨어 손대기(전부 시뮬 계층).
- 다중소스 추정 완성 시도(범위 밖 = #2e 후보).
