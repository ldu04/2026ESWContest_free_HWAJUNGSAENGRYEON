# 구현 지시서 #2e-3 **Step 2.H** — "죽음의 시각이 아니라 죽음의 곡선을 쓴다"
### dT/dt 기반 사망시각 재구성(센서 열관성 τ 보상) + 방법 C 독립 속도 융합 · 고점 도전

> **왜 이 단계인가(고점 도전).** 지금까지는 노드가 임계(80℃) 도달 **시각 하나**만 쓰고 죽어가는 **온도 곡선**은 버렸다. 2.G에서 그 버려진 정보 때문에 τ(센서 열관성)가 **방향 헤드라인까지 위협**하고 결합 최악(warm_scale×τ)이 어떤 팽창으로도 안 잡혀 **판정 (C)**(τ 실측 없인 실물 주장 불가)로 끝났다. 이 단계는 **곡선을 되살려** ① τ 지연을 역보상으로 제거하고 ② 방법 C(노드 단독 dT/dt 속도)를 융합한다. **목표: 2.G의 (C)를 (B)로 완화**하고, 가능하면 밴드를 좁힌다.
>
> **★ 이 단계의 정직성 핵심(먼저 읽을 것).** 시뮬에서 **같은 1차 저역통과 모델·같은 τ로 역산하면 당연히 완벽 복원 = tautology(*시뮬이 뭉갠 걸 같은 식으로 되돌리니 자동으로 맞는 순환논증*)**다. **매치드(matched) 결과는 개선으로 계상 금지.** 이 단계의 **모든 가치는 "얼마나 어긋나도 버티나"(강건성)에서만** 나온다.

**용어(이 지시서):**
- **역보상 / 디컨볼루션(deconvolution):** 센서가 시상수 τ로 뭉갠 신호에서 **원래 공기 온도 T_air를 되돌려 복원**하는 것. 1차 저역통과 `dT_sensor/dt=(T_air−T_sensor)/τ` 의 역식은 `T_air = T_sensor + τ·(dT_sensor/dt)`.
- **방법 C (dT/dt 물리 역산):** 노드 하나가 자기 온도 곡선만으로 속도를 추정. `T(d)=T_amb+ΔT·exp(−d/L)` + `d(t)=d₀−v·t` 에서 `v = L·(dT/dt)/(T−T_amb)` (L=warm_scale). 기하·역수·이웃 불필요 → 기하 추정과 **독립**.
- **도함수 노이즈 증폭:** dT/dt는 미분이라 **온도 측정 노이즈를 키운다** — 재구성·방법 C 공통의 진짜 비용.

## 1. 공통 규율 (measure-first — 이 단계에서 특히 엄격)

1. **매치드 결과 성과 계상 절대 금지.** 정확한 τ·정확한 모델로 복원되는 건 tautology. 보고서/헤드라인에 못 씀. **오직 미스매치·노이즈 강건성 결과만** 성과.
2. **god-view 금지.** 재구성·dT/dt는 **노드가 실제 수신한(노이즈 실린) 보고 온도 계열**에서만. 시뮬 정답 온도 쓰지 말 것(#2d rep 원칙).
3. **재구성에 쓰는 τ는 "실측 전제".** 지금 시뮬 τ로 최종 보정을 확정하지 않는다 — **상한선과 강건성만** 측정. 실제 채택은 Part B(하드웨어 τ 실측) 이후.
4. **방향 비열화가 통과 조건.** 재구성이 방향을 나쁘게 하면 그 설정 불채택.
5. **원 estimator·기존 밴드(E3x2) 병행 보존**, 항상 나란히 비교.
6. 파라미터는 물리/S1에서 도출, 평가 S2~S11 분리. **null 결과 그대로 보고.**
7. estimator.py는 되도록 불변(재구성은 사망시각 산출 앞단에서). 각 Step 끝나면 멈추고 보고.

## 2. Step 1 · 진단 (estimator 불변, 측정만) — 반드시 먼저

**1a. base 방향-vs-τ 확정.**
- **S1(무풍·직선) 및 저풍 시나리오의 방향 오차 vs τ 곡선**을 표로. (2.G 산출물에 S1이 없으므로 이번에 측정.)
- **확인 질문:** 우리 헤드라인 2.1°(무풍·직선 화선)가 τ=2/5/10s에서도 유지되나?
- (전략 담당 예측, 확인용: *무풍·직선에서는 모든 노드의 임계 통과 상승률이 같아 τ 지연이 진짜 균일 → 방향 불변일 것.* **단정 아님 — 측정으로 확정.** 맞으면 "헤드라인은 τ에 강건, τ의 방향 위협은 바람 굽힘 조건 한정"이라는 중요한 방어선이 생긴다.)

**1b. 매치드 재구성 상한 (성과 아님, 상한 파악용).**
- 노드 보고 계열에 역식 `T_air_hat = T_sensor + τ_true·(dT_sensor/dt)` 적용(노이즈 없는 이상 조건) → 재구성 사망시각(T_air_hat이 80℃ 통과)이 τ=0 참값을 얼마나 회복하나. **"완벽에 가까움" 예상 — 이건 tautology라 기록만 하고 성과 아님을 명시.**

**1c. ★ 강건성 3축 (이 단계의 진짜 실험).**
- **τ 미스매치:** 재구성에 쓰는 τ_used를 τ_true의 ±20/30/50%로 틀리게. 방향/ETA/위험측이 무보정 대비 순이득인가 순손실인가.
- **모델 미스매치:** 실제 센서를 2차 지연 또는 약비선형으로 두고 1차 역식으로 재구성 → 열화.
- **★ 도함수 노이즈:** S9 온도지터(및 양자화)에서 dT/dt 미분이 노이즈를 얼마나 키우나. **재구성이 오히려 해가 되는 노이즈 임계**를 찾아라(평활 없이/간단 평활 시 각각).
- 결론 한 줄: "재구성은 [τ 미스매치 ≤__% AND 노이즈 ≤__] 조건에서 순이득, 그 밖에선 순손실."

**Step 1 DoD:** 1a 표(헤드라인 생사) + 1b 상한(tautology 명시) + 1c 강건성 3축 표 + "계속/중단" 권고. estimator 불변. 여기서 멈추고 보고.

## 3. Step 2 · 구현 (Step 1이 "계속"일 때만, baseline 병행)

**2a. 재구성 사망시각 → 기존 파이프라인 투입 → 2.G τ 게이트 재실행.**
- 강건 조건(1c에서 순이득 판명된 범위) 안에서 재구성 사망시각을 estimator에 먹여 방향/속도/ETA 재측정.
- **핵심 질문:** 2.G의 결합 최악(warm_scale×0.5 ∧ τ=10s, E3x2에서 위험측 19.3%)이 **재구성으로 팽창 흡수 가능(≤10%)해지나?** 그렇다면 **판정 (C)→(B) 완화** = 이 단계의 헤드라인 성과.
- 단 재구성 τ는 "실측 전제"라, 결과는 "**τ를 ±__% 이내로 실측하면 결합 위험이 팽창으로 흡수됨**" 형태로 서술.

**2b. 방법 C 독립 속도 + 융합 (밴드 좁히기 시도).**
- 예열 밴드(T_amb+10 ~ warn_temp 60℃)에서만 `v = L·(dT/dt)/(T−T_amb)` 계산, 점화 근방 제외(포화·비선형). 노드별 v 중앙값(로버스트).
- **warm_scale tautology 게이트 필수:** L을 참값 ±20/30/50%로 틀리게 줘도 유효해야 채택. 아니면 "캘리브레이션 전제 발전방향"으로만.
- 기하 속도와 **역분산 가중 융합** → 밴드 폭이 유의하게 좁아지나(커버리지 유지하며)? 가중치는 S1 잔차 분산에서 도출(테스트 점수 금지).
- 보너스: 방법 C 속도가 서면 #2e-2 Fix B(dT/dt 게이트)의 "저속서 무효" 한계가 풀려 2차 FP 방어선 승격 가능 — 별건으로만 측정.

## 4. 완료 기준(DoD) & 산출물

1. **1a 헤드라인 표:** 방향 vs τ (base/저풍). 2.1°가 τ에 강건한지 예/아니오.
2. **1c 강건성 3축 표:** τ 미스매치·모델 미스매치·도함수 노이즈 각각 순이득/순손실 경계.
3. **2a:** 재구성 투입 후 2.G τ 게이트 재실행 표 → (C)→(B) 완화 여부 + "τ ±__% 실측 조건" 서술.
4. **2b:** 방법 C 융합 밴드 폭·커버리지, L 미스매치 게이트 결과.
5. **방향 비열화 증명**, S1~S11 전체, fp 0% 유지, 세기0 회귀 동일성, pytest.
6. **매치드(1b)는 tautology로 명시, 성과에서 제외**했음을 문서에 못박기.
7. 서술 자격 갱신(재구성이 서면 τ 조건이 어떻게 완화되는지). DECISIONS **D-043**, STRESS_REPORT §1g, PROGRESS.

**하지 말 것:** 매치드 재구성을 개선으로 계상 · god-view 온도로 dT/dt · 시뮬 τ로 최종 보정 확정(실측 전) · 도함수 노이즈 손실 은폐 · 방향 열화 은폐 · L/τ 미스매치 시험 없이 방법 C·재구성 채택 · 밴드 커버리지 깨고 폭만 좁히기.

_Step 2.H = "실패를 데이터로"의 심화 끝판 — 죽은 **시각**뿐 아니라 죽어가는 **곡선**까지 쓴다._
_핵심: **매치드는 tautology라 버리고, 오직 미스매치·노이즈 강건성에서만 성과를 센다.** 잘 되면 2.G의 (C)가 (B)로 완화되고 밴드가 좁아진다 — 안 되면 "곡선 재구성은 도함수 노이즈에 약해 발전방향"이라는 정직한 null._
