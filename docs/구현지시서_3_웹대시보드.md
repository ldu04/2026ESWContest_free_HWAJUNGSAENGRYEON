# 구현 지시서 #3 — 웹 관제 대시보드 (발표·시연영상용)
### 화중생련 「불사」 / 검증된 시뮬을 "심사장에서 보여줄 화면"으로

> 지시서 번호 정리: **#1 시뮬 · #2 스트레스 · #2b 에러바수선 · #3 웹 대시보드(이번) · #4 펌웨어 포팅.**
> **이 문서 사용법:** `docs/`에 넣고 Claude Code에 "지시서 #3대로 대시보드 만들어줘".
> **핵심 원칙:** 코어(engine/estimator) **불변**. 대시보드는 **기존 Snapshot(dict)만 소비**한다(D-003 준수).

---

## 0. 목적 (무엇에 쓰나)

이 대시보드는 **심사 발표·3분 시연영상·보고서 스크린샷**에 나갈 "관제 화면"이다. matplotlib 뷰(개발용)와 별개로,
**시각적으로 깔끔하고, 브라우저에서 바로 열리며, 화면녹화가 잘 되는** 결과물이 목표.

---

## 1. 접근 방식 (권장 스택)

**권장: "JSON 내보내기 → 자체 완결형 HTML+JS 플레이어".** 서버 불필요, 파일 하나로 브라우저에서 열림.
- 이유: (a) 3분 영상 **화면녹화가 깔끔**, (b) GitHub Public 레포에 넣으면 **누구나 열어봄**(제출 가점), (c) 서버·설치 없이 포터블, (d) 라즈베리파이에서도 브라우저로 띄우면 실물 데모 관제 화면으로 재사용 가능.
- 흐름: `engine.run()`으로 좋은 시드의 시나리오를 돌려 **snapshots.json**으로 내보냄 → HTML+JS가 그 JSON을 읽어 **재생(replay)**.
- 재생(replay) 우선(재현성·무대 안정). 실시간 구동은 선택(있으면 좋고, 무대에선 녹화/재생이 안전).

> 대안(더 빠르지만 덜 폴리시): **Streamlit**(파이썬 단독). 빨리 만들지만 "데이터앱" 느낌·애니메이션 거침. 시간 없으면 이걸로,
> 발표 임팩트 원하면 권장안(HTML+JS)으로. 기본은 **권장안**.

---

## 2. 폴더·산출물

```
dashboard/
├── export_snapshots.py     # engine 시나리오 → results/dashboard/snapshots.json (+ 메타)
├── index.html              # 자체 완결형 플레이어(브라우저에서 열기)
├── app.js                  # 렌더·애니메이션·컨트롤
└── style.css               # (또는 index.html에 인라인)
```
- `snapshots.json` 스키마 = 기존 Snapshot(dict) 배열 그대로 + 메타(노드좌표·sink·config 요약·ground-truth 전선).
- **코어 변경 금지**: export는 engine이 이미 yield하는 스냅샷을 직렬화만. estimator·network 손대지 않음.

---

## 3. 화면 구성 (패널)

1. **메인 맵(중앙):**
   - 노드: ALIVE 초록 / DYING 주황 / DEAD 검정 / Sink 파랑. 상태 전환 애니메이션.
   - **라우팅 경로**(현재 sink로 가는 트리) 선으로, 노드 죽을 때 **경로가 우회로 재구성되는 게 보이게**(자가치유).
   - **참 전선(점선) + 추정 전선/방향 화살표(실선)** 겹쳐 표시 → 추정이 참을 추종.
   - **대피경보** 뜬 노드 빨강 테두리 + 라벨(예: "구역3 대피 3분 전").
2. **지표 HUD(상단/측면):** 현재 t, 전달률, 방향·속도 추정치(+오차), 오탐 카운트, 죽은 노드 수.
3. **타임라인 컨트롤(하단):** ▶︎재생 / ⏸일시정지 / 슬라이더 seek / 속도(0.5×·1×·2×).
4. **(선택) stock vs ours 토글:** 같은 시나리오에서 stock은 "노드만 사라짐", ours는 "화살표·ETA 추가" 대비 → 차별점 시각화.

## 4. 서사 규율 반영 (§ 발표)

- 속도 관련 표시엔 **오차 밴드/보수적 문구** 병기("속도 추정 ±, 안전마진 적용"). 방향·위치를 주역으로.
- 재라우팅은 "시뮬상 즉시 복구" 라벨(HW 지연은 #4에서). 무조건적 수치 금지(#2b 규율 계승).

---

## 5. 시각 품질 기준 (영상에 나갈 수준)

- 배경·격자·범례(legend)·색약 배려 팔레트, 읽히는 폰트, 부드러운 프레임 전환.
- 화면녹화(1080p) 시 깨짐 없이 3분 시연 흐름(순차사망→자가치유→추정추종→대피경보)이 **한 번에 읽히게**.

## 6. 완료 기준 (DoD)

1. `export_snapshots.py`로 좋은 시드 시나리오 → `snapshots.json` 생성.
2. `index.html`을 브라우저로 열면 그 시나리오가 **재생/일시정지/seek** 되며, 맵·경로·추정 화살표·대피경보·HUD가 모두 표시.
3. stock vs ours 대비를 (토글이든 나란히든) 한 번 보여줌.
4. 화면녹화로 3분 데모 흐름이 깔끔하게 나옴(육안 확인).
5. `docs/DECISIONS.md`(D-019~)·`docs/PROGRESS.md` 갱신. README에 "대시보드 여는 법" 추가.
