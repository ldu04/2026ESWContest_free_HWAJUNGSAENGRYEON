# Failure Pattern 알고리즘 — 수학적 명세 **v2.1**
### 「불사」· 죽음시각 집합에서 화재 전선의 방향·속도·ETA를 추정하는 절차의 형식적 기술

> **v1 대비 무엇이 바뀌었나 (읽기 전에 이것부터).**
> v1은 추정기를 **"전역 평면 적합 하나"**로 기술했다. **그것은 코드와 다르다.** 실제 코드는 **2단 구조**다 — ①노드마다 국소 평면 적합을 N번 돌리고 ②그 N개의 국소 추정치를 하나로 합친다. v1에는 ②가 통째로 없었다.
>
> 이 누락이 사소하지 않은 이유: **flank 조건에서 82~86°의 방향오차가 나온 원인이 정확히 ②에 있었다.** 명세에 ②가 없었기 때문에 우리는 두 달 동안 그 오차를 ①의 문제(곡률·표본부족·채점방식)로 오진했다. 명세의 공백이 진단의 공백을 만든 사례다.
>
> **v2에서 신설·개정된 곳:** §3(2단 구조 전면 개편) · §4-1~4-3(집계 연산자) · §4-4(가중치 결함과 역분산 보정) · §4-6(n_eff 진단) · §6-3(표본 중복에 의한 상관 — 역분산의 독립 가정이 낙관적이라는 명시) · §11(v1의 오류 목록).
>
> **v2.1에서 추가로 확정된 것 (D-064, 코드 추적으로 확인):**
> **§5 전면 교체.** ETA는 적합 절편 ĉ를 **쓰지 않는다.** ĉ는 계산되어 저장되지만 저장소 전체에서 **읽히는 곳이 0곳**이고, 대신 최근접 노드의 **관측 사망시각을 앵커로** 쓴다. v1과 v2 초안이 **둘 다** `ETA = âx*+b̂y*+ĉ`로 적었으므로 **같은 오류를 두 판 연속 반복한 것**이다. 여기서 나온 즉시 조치 사항이 §12-A(ETA가 INSUFFICIENT 게이트를 우회한다)이다.
>
> **표기 규약:** 벡터는 굵게 쓰지 않고 성분으로 적는다. 용어는 처음 나올 때 괄호로 뜻을 푼다.

## 1. 문제 정의

**도착시각장(arrival-time field) T(x, y):** 위치 (x, y)에 화재 전선이 도달하는 시각. 공간 위에 정의된 스칼라 함수다.

**관측:** 노드 i가 위치 (xᵢ, yᵢ)에 있고, 그 노드가 죽은 시각 tᵢ를 보고한다. 이때

```
tᵢ = T(xᵢ, yᵢ) + dᵢ + εᵢ
```

- `dᵢ` : 노드 i의 **체계적 지연**(센서 열시상수 τ에 의한 임계 교차 지연 등)
- `εᵢ` : 랜덤 오차(양자화, 통신, 위치 오차 등)

**추정 목표:** 관측 집합 {(xᵢ, yᵢ, tᵢ)}로부터 전선의 **진행 방향 n̂**, **속도 s**, 그리고 특정 지점의 **도착예상시각 ETA**를 얻는다.

## 3. ★ 2단 구조 — 실제 추정 절차

### 3-1. 전체 흐름

```
입력: 사망 이벤트 집합 {(xᵢ, yᵢ, tᵢ)}
  │
  ├─ [1단] 노드 j마다 독립적으로:
  │        국소 표본 S_j 선택  →  평면 최소자승  →  ∇T_j
  │                                              →  n̂_j = ∇T_j/|∇T_j|
  │                                              →  s_j  = 1/|∇T_j|
  │        (노드 수만큼 반복 = 적합을 N번 돈다)
  │
  └─ [2단] {(n̂_j, s_j)}_j 를 하나로 집계:
           방향: 가중 벡터합 후 정규화
           속도: 중앙값
           (★두 출력이 서로 다른 집계 연산자를 쓴다)
```

**v1의 오류를 다시 명시한다.** v1 §3~§4는 위 그림의 [1단]을 **전체 노드에 대해 한 번만** 도는 것으로 기술했고 [2단]을 아예 언급하지 않았다. 실제로는 [1단]이 N번 돌고 [2단]이 존재한다.

### 3-2. 국소 표본 S_j 의 정의 ✅**대조 완료 — 2건 정정** (2026-08-13)

노드 j의 국소 표본은 **격자 인접**이 아니라 다음과 같다.

```
S_j = {j} ∪ { i :  i ∈ 이웃(j)  ∧  i 가 사망함  ∧  |tᵢ − t_j| ≤ dt_window }
```

> **★정정 ① — 앵커 노드 j가 빠져 있었다.** 초안은 `S_j = { i : … }`로 적어 j 자신을 포함하지 않았다.
> 코드(`estimator._fit_local`)는 `ids = [i]`로 **자기 자신을 무조건 먼저 넣고** 이웃을 더한다.
> ⇒ `n_j = 1 + (적격 이웃 수)`. DOF = n_j − 3 계산에 직접 영향이 있으므로 사소한 표기 문제가 아니다.
> (예: 적격 이웃이 3이면 n_j=4로 DOF=1이 되어 `residual_min_samples=4`(D-061) 요건을 갓 충족한다.)

- **이웃(neighbor)** — `Network._build_links()`가 만든 **정적 기하 원판 그래프**다:
  `math.dist(a, b) ≤ radio_range_m` 이면 이웃. 격자 대각선이어도 거리가 반경 안이면 포함된다.
- **dt_window** — 시간 창. 현재 8초(v=1.5 m/s 기준으로 조정된 값).

> **★정정 ② — "메시에서 실제로 링크가 성립한 노드"가 아니다.** 초안은 이웃 집합이 **실제 링크 상태**를
> 반영한다고 적었으나, 코드에서 `self.neighbors`는 초기화 때 좌표로 한 번 만들어지고 **그 뒤 바뀌지 않는다.**
> `apply_dropouts()`는 `self._active`(링크별 일시 두절 플래그)만 갱신하고 `self.neighbors`는 건드리지 않는다.
> ⇒ **따라서 다음 서술은 현 구현에서 성립하지 않는다:**
> *"링크가 끊기면 A6이 조용히 깨진다 / 통신 품질이 추정 정확도의 입력 변수다"* — **거짓.**
> dropout이 아무리 심해도 `S_j`의 이웃 후보 집합은 그대로다.
>
> **다만 통신 품질이 무관한 것은 아니다 — 경로가 다르다.** dropout은 `last_heard`를 통해
> **어떤 노드가 사망으로 확정되는지**(침묵 감지 → `Verifier`)에 영향을 준다. 즉 통신은
> **이웃 집합이 아니라 `deaths` 집합을 통해** 추정에 들어온다. 이 구분이 §10-2·§10-5의 원인 귀속을 가른다.
>
> ⚠ **실물에서의 추가 주의(D-049):** 벤치 배치(0.15 m 격자)에서는 실제 WiFi 도달거리가 격자보다
> 훨씬 커서 전 노드가 서로 도달한다. 그래서 `deploy_config.json`의 `radio_range_m`은
> **무선 도달거리가 아니라 추정기의 공간 이웃 반경**으로 쓰인다(시뮬 규약과 같은 spacing×1.8).

> **이 정의가 중요한 이유 (정정 반영).**
> **(a) 표본 수는 배치 기하로 결정된다** — 통신 상태가 아니라. 통신은 `deaths` 집합을 통해 간접적으로만 들어온다.
> **(b) 시간 창이 공간 창을 겸한다.** 전선이 느리면 이웃의 사망이 창 밖으로 밀려나 표본이 굶고(§10-2), 전선이 빠르면 창 안에 너무 넓은 공간이 들어와 국소 평면성 A1이 깨진다. **dt_window 하나가 A1과 A6을 반대 방향으로 동시에 조인다.** 최적값이 존재하고 조건 의존적이라는 뜻이다.

### 3-3. 국소 평면 최소자승 (1단)

A1에 따라 S_j 안에서

```
T(x, y) ≈ a·x + b·y + c
```

로 두고 잔차 제곱합을 최소화한다.

```
(â_j, b̂_j, ĉ_j) = argmin  Σ_{i∈S_j} [ tᵢ − (a·xᵢ + b·yᵢ + c) ]²
```

**행렬 형태.** 설계행렬(design matrix) M_j 와 관측벡터 t_j 를

```
M_j = ⎡ x₁  y₁  1 ⎤        t_j = ( t₁, …, t_{n_j} )ᵀ ,   n_j = |S_j|
      ⎢ x₂  y₂  1 ⎥
      ⎢  ⋮   ⋮  ⋮ ⎥
      ⎣ x_{n_j} y_{n_j} 1 ⎦
```

로 두면

```
θ̂_j = (M_jᵀ M_j)⁻¹ M_jᵀ t_j ,      ∇T_j = (â_j, b̂_j)
```

**자유도(DOF) = n_j − 3.** ★**여기가 v1과 결정적으로 다르다.** v1은 DOF를 전체 노드 수 N에서 뺀 것으로 서술했지만, 실제 자유도는 **국소 표본 수 n_j**에서 뺀 것이다. n_j는 이웃 수라 훨씬 작다 — 3이면 DOF=0이 되어 잔차가 항상 0, 즉 **잔차 기반 이상탐지가 그 노드에서 무력화된다.** (D-061에서 `residual_min_samples`를 3→4로 올린 이유가 이것이다: DOF ≥ 1을 강제한다.)

**퇴화(degenerate) 배제 ✅대조 완료 — 일치, 단 단서 1건.** 1단에서 `|∇T_j| ≤ cfg.eps`(=**1e-6**)인 경우만 배제한다(`estimator.py:74`). **레거시 2단에는 배제 장치가 없다.**

> **★단서(D-063 이후 변경):** 기본 집계가 `invvar`로 바뀌면서 2단에도 사실상의 배제가 생겼다 —
> `δφ̂`를 산출할 수 없는 적합(DOF<1)은 가중치가 **0**이 되어 합산에서 빠진다.
> 즉 "2단에 배제 장치가 없다"는 **`mode="legacy"`에서만 참**이다. 이 문턱은 사실상 "완전한 0"만 거른다. 실제로 문제를 일으킨 노드의 |∇T| = 0.0247 은 이 문턱을 **2만 배 이상 여유로 통과**했다. → §4-4.

## 4. ★ 집계 (2단)

### 4-1. 방향의 집계

노드별 단위벡터 n̂_j 를 가중 벡터합한 뒤 정규화한다.

```
n̂_global = ( Σ_j w_j n̂_j ) / | Σ_j w_j n̂_j |
```

**이것은 재적합이 아니다.** 원자료를 다시 모아 평면을 다시 맞추는 게 아니라, 이미 나온 방향들을 벡터로 더한다. 따라서 **원자료의 정보 일부가 이 단계에서 이미 소실된 상태**다(각 n̂_j는 단위벡터로 정규화되면서 자기 신뢰도를 잃는다 — 신뢰도는 오직 w_j로만 되돌아온다). **그래서 w_j가 무엇이냐가 결정적이다.**

**구조적 성질:** 가중 벡터합은 **강건하지 않다(non-robust)**. 가중치 하나가 지배하면 결과는 그 노드의 답이 된다. 붕괴점(breakdown point)이 0이다.

### 4-2. 속도의 집계 — ★방향과 다른 연산자

```
s_global = median_j ( s_j )
```

**중앙값은 강건하다.** 붕괴점 50%. 즉 표본의 절반 미만이 오염돼도 결과가 무너지지 않는다.

> **★이 비대칭이 우연히 통제실험이 되었다.** 같은 입력·같은 퇴화 상황에서
> - 방향(비강건 집계) → **78° 이상 틀림**
> - 속도(강건 집계) → **오차 0.86 수준으로 생존**
>
> 입력이 동일하므로 차이의 원인은 **집계 연산자뿐**이다. 이것이 "원인은 곡률도 채점도 표본부족도 아니고 집계다"를 확정한 증거다. 설계 의도가 아니라 우연이었지만, 사후적으로는 가장 강한 증거였다.
>
> **→ 따라서 속도의 중앙값 집계는 건드리지 않는다.** 두 축을 동시에 바꾸면 이 통제군이 사라진다. (D-기록 대상)

### 4-3. ★ 가중치 결함 — w_j = 1/|∇T_j| 는 부호가 반대다

**레거시 구현:**

```
w_j  =  1 / |∇T_j|   =  s_j          ← 속도가 클수록 크게 가중
```

**§6의 오차 전파에서 나오는 사실:** 노드 j의 각도 오차는

```
δφ_j  ≈  δ⊥_j / |∇T_j|
```

즉 **|∇T_j|가 작을수록 그 노드의 방향 추정은 부정확하다.** 그런데 레거시 가중치는 바로 그 부정확한 노드에 **가장 큰 가중치를 준다.** 불확실성으로 가중한 셈이고, 역분산 가중과 정확히 반대 방향이다.

**측정된 증거 (2.J 추가-G):**

| 항목 | 측정값 |
|---|---|
| corr(노드별 속도, 노드별 방향오차) | **+0.986** |
| 한 노드가 가진 가중치 비중 | **86.4%** |
| 그 노드의 개별 방향오차 | **85.21°** |
| 같은 케이스의 개별 오차 중앙값 | **1.35°** |

읽는 법: **정답은 표본 안에 있었다**(중앙값 1.35°). 집계가 그 정답을 버리고 최악의 노드 하나를 골랐다. corr = +0.986은 "속도가 큰 노드가 곧 틀린 노드"라는 §6의 예측이 자료에서 거의 결정론적으로 성립함을 뜻한다.

### 4-4. 역분산(inverse-variance) 보정 — 유도

정확한 가중치는 **분산의 역수**다. 각도 φ = atan2(b, a)에 대해 1차 전파를 하면

```
∇_{(a,b)} φ  =  (−b, a) / (a² + b²)  =  ê⊥ / |∇T|
```

이므로

```
Var(φ_j)  =  ( ê⊥ᵀ C_j ê⊥ ) / |∇T_j|²        ,   C_j = σ² [ (M_jᵀM_j)⁻¹ ]_{ab 블록}
```

따라서 **엄밀한** 역분산 가중치는

```
w_j*  =  |∇T_j|²  /  ( ê⊥ᵀ C_j ê⊥ )
```

**현재 구현하는 근사:** 분자만 취한다.

```
w_j  =  |∇T_j|²
```

이는 `ê⊥ᵀ C_j ê⊥`(국소 배치 기하가 만드는 분산)가 노드 간에 비슷하다고 가정한 것이다. 배치가 균일한 격자에서는 무리 없지만, **가장자리 노드나 링크가 빠진 노드는 이 항이 커진다** — 즉 근사가 가장 안 맞는 곳이 바로 위험한 곳이다.

> **향후 과제 (구현 가능·미구현):** `C_j`는 이미 1단에서 `(M_jᵀM_j)⁻¹`로 계산되므로 **추가 비용 없이** 엄밀식을 쓸 수 있다. 지금 넣지 않는 이유는 마감 일정과 회귀 위험이며, 성능상의 근거가 아니다. 이 문장을 남기는 것이 정직하다.

**결함의 크기.** 레거시와 올바른 가중치의 비는

```
w_j(정정) / w_j(레거시)  =  |∇T_j|² / |∇T_j|⁻¹  =  |∇T_j|³
```

**3제곱**이다. 그래서 |∇T|가 한 자릿수만 작아도 가중치가 세 자릿수 어긋난다. 퇴화 문턱 1e-6이 무력했던 이유가 이것이다 — 문턱은 "0인가"만 물었고, 실제 위험은 "작은가"에서 발생했다.

### 4-5. ★ 값을 내지 않는다는 선택 (INSUFFICIENT)

정정 후 일부 조건(flank d60/d120)에서 역분산 집계는 **아무 값도 내지 못한다.** 이것을 **한계가 아니라 올바른 자기 차단**으로 기록한다.

같은 조건에서 다른 집계들은 값을 낸다 — 그리고 **84.90° 틀린 값**을 자신 있게 낸다. 산불 대응 맥락에서 "모른다"와 "정반대를 확신한다"의 비용 차이는 대칭이 아니다. **따라서 폴백(fallback)을 넣지 않는다.** 값이 없으면 없는 채로 상위에 올린다.

### 4-6. ★ n_eff — 두 실패 모드를 가르는 진단량

**유효표본수(effective sample size, Kish):**

```
n_eff  =  ( Σ_j w_j )²  /  Σ_j w_j²
```

가중치가 모두 같으면 n_eff = n(표본 수), 하나가 지배하면 n_eff → 1.

**측정값 (추가-G):**

| 조건 | n_eff | 해석 |
|---|---|---|
| flank W10 d30 τ=0 | 1.33 | 가중치 폭주 |
| flank W10 d30 τ=78.5 | 1.74 | 가중치 폭주 |
| flank W10 d60 τ=0 | 1.04 | 진짜 표본 굶주림 |
| head W10 d60 | 12.99 | 정상 |
| straight_S1 | 12.69 | 정상 |

**핵심: n_eff 하나만으로는 위 두 실패가 구분되지 않는다**(둘 다 1 근처다). **원표본수 n과 함께 봐야 갈라진다.**

```
n 크고  n_eff ≈ 1   →  가중치 폭주  (표본은 있는데 하나가 삼킴)   → 가중치를 고쳐야 함
n 자체가 작음        →  표본 굶주림 (애초에 정보가 없음)          → 창·배치를 고쳐야 함
```

**→ 대시보드·보고서에는 n_eff를 반드시 n과 짝지어 표기한다.** 단독 표기는 오진을 유도한다. 현재 출력 형식: `n_local=13, n_used=13, n_eff=3.537 (원표본 대비 0.2721)`.

> **★n_eff는 크게 만들 대상이 아니다 — 가중치 방식이 다르면 비교 자체가 무의미하다.**
> 정상 조건에서도 invvar의 n_eff는 원표본의 0.27 수준까지 내려간다. 이건 고장이 아니라 **불확실한 노드를 의도적으로 죽인 대가**다. 반면 uniform은 정의상 n_eff = n이 나오지만, 그 13은 **나쁜 노드까지 전부 세어준 13**이라 명목값일 뿐이다.
>
> **따라서 n_eff는 "같은 가중치 방식 안에서 조건끼리" 비교할 때만 진단력이 있다.** 서로 다른 가중치의 n_eff를 비교해 "uniform이 정보를 더 쓴다"고 읽으면 정확히 거꾸로 해석한 것이다.

### 4-7. 집계 방식별 측정 결과 — 전부 기록 (유리·불리 모두)

방향오차[°], 값이 작을수록 좋음. `—` = 값 없음(자기 차단).

| 조건 | legacy | uniform | median | **invvar** | n_eff |

**자기 차단의 실제 작동 (flank W10 d60):**

**"낼 수 있었지만 내지 않았고, 냈다면 틀렸을 것"**이 로그에 함께 남는다. 이 세 줄이 §4-5 설계 의도의 증거다.

## 5. ★ ETA — 절편을 쓰지 않는다 (D-064로 확정) ✅**대조 완료 — 코드와 일치**

### 5-1. 실제 구현

```python
def predict_arrival(self, p):
    best = argmin_over_per_node( |p − pos_j| )      # 유클리드 최근접
    return best["t"] + best["grad"] @ (p − best["pos"])
```

식으로 쓰면, j\* = 목표점 p에 가장 가까운 노드일 때

```
ETA(p)  =  t_{j*}  +  ∇T_{j*} · ( p − pos_{j*} )
```

**★적합 절편 ĉ_j는 계산되어 저장되지만 저장소 전체에서 읽히는 곳이 0곳이다.** 대신 그 노드의 **관측 사망시각 t_{j\*}**를 앵커(anchor, 평면을 붙들어 매는 점)로 쓴다.

**기하학적 의미:** 적합 평면을 **그 노드의 실제 사망시각을 지나도록 평행이동**한 것이다. 결과적으로 **그 노드의 잔차가 강제로 0**이 된다.

> **v1과 v2 초안이 둘 다 틀렸다.** 두 문서 모두 `ETA = âx* + b̂y* + ĉ`로 적었는데, 코드는 ĉ를 쓰지 않는다. 명세가 코드를 두 번 연속 잘못 기술한 것이고, 이번엔 코드 추적으로 잡혔다.

### 5-2. 앵커 선택의 대가 — 분산과 편향의 맞바꿈

`ĉ_j`(적합 절편) 대신 `t_{j*}`(단일 관측)를 쓰는 것은 **통계적으로 공짜가 아니다.**

| | 적합 절편 ĉ_j | **앵커 t_{j\*} (현행)** |
|---|---|---|
| 잡음 평균화 | n_j개 관측에 걸쳐 평균 | **없음 — 관측 1개의 오차를 그대로** |
| 오프셋 분산 | ≈ σ²·h (레버리지, 3모수·n=13이면 대략 0.2σ² 수준) | **σ² (관측 분산 전체)** |
| 모델 오설정(곡률)에 대한 편향 | 잔차만큼 어긋남 | **앵커 노드에서 정확히 0** |

**즉 앵커는 분산을 키우고 편향을 줄인다.** 곡률이 심한 전선(타원 모델에서 확인된 상황)에서는 이 맞바꿈이 유리할 수 있다. **문제는 이것이 판단이 아니라 사고였다는 점이다** — 어디에도 이 맞바꿈을 선택했다는 기록이 없다.

> **★사전등록 예측 [식 유도] — 지터 τ에서 ETA는 방향·속도보다 더 나빠진다.**
>
> **결합 진술을 먼저 쓴다(강령 §B-2).** 앵커는 관측 하나이므로 **그 노드의 개별 지연 d_{j\*}가 평균화 없이 1:1로 ETA에 실린다.** 반면 방향·속도는 국소 적합 n_j개에 걸친 평균화를 받아 σ_d의 영향이 대략 1/√n_j로 감쇠한다. 두 경로가 같은 σ_d를 받지만 감쇠 계수가 다르다.
>
> **예측:** 지터 τ를 켰을 때 (ETA 오차 증가분) / (방향 오차 증가분)의 비는 τ=0 대비 **커진다.** 대략적 크기는 √n_j 규모(n=13이면 3~4배)를 넘지 않는 선에서 나타날 것.
>
> **반증 조건:** 이 비가 오히려 줄거나 변하지 않으면 예측은 기각이고, 그 경우 앵커의 노이즈가 다른 항에 묻힌다는 뜻이므로 그것대로 기록한다.

### 5-3. ★ 최근접 선택 규칙의 구멍 — 즉시 조치 필요

앵커 노드는 **유클리드 최근접 하나로만** 고른다. 시간 근접도·가중치·등급을 보지 않는다. 여기서 세 가지 문제가 나온다.

**(1) INSUFFICIENT 게이트를 우회한다. ★가장 시급**
§4-5에서 도입한 자기 차단은 `dir_global` 경로에만 걸려 있다. `predict_arrival`은 per_node를 직접 뒤지므로, **DOF<1이라 방향 집계에서 배제된 바로 그 노드가 최근접이면 ETA는 그 노드의 ∇T를 그대로 쓴다.** 방향은 "모른다"고 하는데 ETA는 같은 근거로 숫자를 내는 상태다. **모순이고, 위험한 쪽으로 모순이다.**

**(2) 시간적으로 낡은 앵커.** 최근접 노드가 화재 초기에 죽었다면 그 ∇T는 그때의 전선 상태다. 전선이 그 사이에 방향을 틀었으면 ETA는 낡은 기울기로 외삽한다. 공간 거리만 보면 이 상황이 걸러지지 않는다.

**(3) 보로노이 불연속.** ETA(p)는 노드별 보로노이 영역마다 다른 식을 쓰므로 **경계에서 불연속**이다. 대시보드에 ETA 지도를 그리면 타일 경계에서 값이 튀는 것으로 보인다. 인접 두 노드의 추정이 어긋날수록 튐이 크다 — **그래서 이 불연속의 크기 자체가 국소 일관성의 무료 진단량이 된다.**

### 5-4. ETA 경로가 두 개다

| 경로 | 앵커 | 속도원 | 방향원 |
|---|---|---|---|
| `estimator.predict_arrival` | 최근접 노드 t_j | **그 노드의 \|∇T_j\|** | 그 노드 |
| stepE 밴드 ETA | 최근접 노드 t_j | **per-node 속도 중앙값** | 그 노드 |

**둘 다 `dir_global`을 쓰지 않는다.** 차이는 속도원뿐이다.

**함의 두 가지.**
- **같은 질의점이 두 개의 ETA를 갖는다.** 보고서·대시보드에 두 값이 함께 나오면 반드시 라벨을 붙여야 한다. 어느 하나를 대표값으로 삼는다면 그 결정을 D-기록에 남겨야 한다.
- stepE 쪽은 속도가 중앙값이라 **강건하지만 혼성**이다 — 앵커와 방향은 한 노드에서, 속도는 전체에서 온다. 이 조합의 오차 성질은 두 경로 어느 쪽의 성질도 아니며 별도 검증이 필요하다.

### 5-5. 가중치 결함이 ETA로 전파되지 않았다는 사실의 정확한 의미

D-059/D-062의 가중 결함은 `dir_global`에만 있었고, ETA는 `dir_global`을 쓰지 않으므로 **오염되지 않았다.**

> **★그러나 "오염되지 않았다"와 "검증되었다"는 다르다.** 같은 이유로 ETA 경로는 §4-5의 INSUFFICIENT 게이트도, invvar 정정도 **받지 못했다.** 결함이 닿지 않은 경로에는 수정도 닿지 않는다. ETA는 지금 **미검증 상태이며, 그 사실이 좋은 소식으로 오독되기 쉬운 위치**에 있다. 보고서에 "ETA는 이 문제의 영향을 받지 않았다"만 쓰고 끝내면 정직하지 않다.

## 6. 오차 전파

### 6-1. 국소 적합의 오차

관측 오차가 독립·동일분산 σ²라 가정하면

```
Cov(θ̂_j) = σ² (M_jᵀ M_j)⁻¹
```

**기울기 오차를 두 성분으로 분해한다.** 참 기울기 ∇T에 대해 오차 δ∇T를

- `δ∥` : ∇T와 **평행한** 성분 (크기 방향)
- `δ⊥` : ∇T에 **수직한** 성분 (방향 회전)

으로 나누면 1차 근사에서

```
방향(각) 오차:      δφ  ≈  δ⊥ / |∇T|                [rad]
속도 상대오차:      δs/s ≈  δ∥ / |∇T|
```

### 6-2. 분모가 같다는 관찰

두 식의 분모가 같다. 즉 **등방성 노이즈 아래에서 방향과 속도는 절대적 민감도가 비슷하다.** 그럼에도 실험에서 "지터 τ에 방향은 196배, 속도는 1.2~23배 나빠졌다"처럼 **배율이 크게 달라 보이는 이유는 기준선(baseline)이 다르기 때문**이다. 방향의 균일τ 기준선은 0.345°(≈0.006 rad)로 극히 작아 배율이 폭발적으로 보이고, 각도는 90°에서 포화한다.

> **→ 방향과 속도의 취약성은 배율이 아니라 절대오차로 비교해야 한다.**

**분모의 함의:** |∇T| = 1/s 이므로 **전선이 빠를수록(s 큼) |∇T|가 작아져 두 오차가 모두 커진다.** 빠른 화재가 추정에 불리하다는 것이 식에서 직접 나온다. — 그리고 §4-3의 가중치 결함은 정확히 이 관계를 **거꾸로 이용한** 셈이었다.

### 6-3. ★ 표본 중복에 의한 상관 — 역분산의 독립 가정은 낙관적이다

역분산 가중이 최적(minimum-variance)인 것은 **추정치들이 독립일 때**다. 그런데 여기서는 아니다.

**이유:** 이웃한 노드 j와 k의 국소 표본 S_j, S_k 는 **겹친다.** 같은 사망 이벤트 tᵢ가 여러 국소 적합에 동시에 들어가므로 ∇T_j 와 ∇T_k 는 같은 노이즈를 공유한다.

```
Cov(φ̂_j, φ̂_k) ≠ 0     (S_j ∩ S_k ≠ ∅ 이면)
```

**결과 두 가지.**

1. **집계 결과의 분산이 과소평가된다.** 독립을 가정하면 Var(집계) = 1/Σw_j 인데, 양의 상관이 있으면 실제 분산은 이보다 크다. → **우리가 보고하는 신뢰구간은 낙관적이다.**
2. **n_eff도 과대평가된다.** n_eff는 가중치 불균형만 반영하고 상관은 반영하지 않는다. 즉 `n_eff = 12.99`는 "독립 관측 13개어치"가 아니라 그보다 적다.

**엄밀한 처리:** 전체 공분산 Σ를 써서 일반화 최소자승(GLS) 가중 `w = Σ⁻¹1 / (1ᵀΣ⁻¹1)`을 쓰는 것. **구현하지 않았다.** Σ를 추정하려면 표본 중복 구조를 명시적으로 추적해야 하고 마감 내 회귀 위험이 크다.

> **→ 그러므로 정직한 표현은 이것이다: 역분산은 레거시보다 원리적으로 옳지만 그 자체도 최적은 아니다.** 보고서에 "최적 가중"이라고 쓰지 않는다. "불확실성이 큰 노드의 영향을 줄이는 가중"이라고 쓴다.

## 7. 센서 지연 τ의 형식적 효과

센서는 공기온도를 1차 지연(first-order lag)으로 따라간다.

```
dT_sensor/dt = ( T_air − T_sensor ) / τ
```

죽음은 T_sensor가 임계 T_th를 넘을 때 기록되므로 실제 공기가 임계를 넘은 시각보다 **dᵢ만큼 늦게** 찍힌다. dᵢ의 성질에 따라 세 경우로 갈린다.

**(1) 균일 지연 (dᵢ = d, 모든 i에 동일).** 평면 적합에서 상수항은 절편에 흡수된다.

```
â, b̂ 불변       →  방향·속도 불변
t_{j*} → t_{j*} + d  →  ETA가 d만큼 편향   (앵커 경로. 절편 경로였어도 결론 동일)
```

**→ 방향·속도는 균일 지연에 원리적으로 면역이고 ETA만 보정이 필요하다.**

> **★§5-1의 발견에도 결론이 바뀌지 않는다.** ETA가 절편 ĉ가 아니라 앵커 t_{j\*}를 쓴다는 사실이 드러났지만, **균일 지연은 앵커도 똑같이 d만큼 민다.** 두 경로 모두 ETA를 정확히 d만큼 편향시킨다. 이 결론은 구현 세부와 무관하게 성립한다.

> **★2단 구조에서의 단서:** 이 면역은 **1단(국소 적합)에서** 성립한다. 모든 국소 적합의 절편이 똑같이 d만큼 밀리므로 ∇T_j는 전부 불변이고, 따라서 어떤 집계를 쓰든 방향·속도는 보존된다. **즉 이 면역은 집계 방식과 무관하게 유지된다.** (v1에서는 이 구분을 할 수 없었다.)

**(2) 노드별 편차 (dᵢ가 제각각).** 편차는 상수로 흡수되지 않고 **잔차에 남아 εᵢ와 같은 역할**을 한다. 방향·속도·ETA가 **모두** 열화한다. σ_d가 커질수록 §6의 δ⊥, δ∥가 커진다.

> **★단, 세 출력의 열화 속도가 같지 않다(§5-2).** 방향·속도는 국소 적합 n_j개의 평균화를 받지만 **ETA의 앵커는 관측 하나**라 d_{j\*}가 감쇠 없이 실린다. 지터 τ에서 **ETA가 가장 먼저·가장 크게 무너질 것**으로 예측한다(사전등록, §5-2).

> **★2단 구조에서의 증폭:** 지터는 |∇T_j|를 노드마다 흔든다. 어떤 노드는 우연히 |∇T_j|가 작아지고, 레거시 가중치에서는 **그 노드가 곧바로 지배 노드가 된다.** 즉 지터의 해악은 δ⊥를 키우는 1차 효과만이 아니라 **가중치를 통해 증폭되는 2차 효과**를 갖는다. τ=78.5s에서 레거시가 76.77°였던 것이 이 결합의 결과다.

**(3) 균일 τ인데도 dᵢ가 불균일해지는 경우 (2차 효과).** dᵢ는 τ만이 아니라 **그 노드에서의 온도 상승률**에도 의존한다. 임계 근처에서 공기온도가 빠르게 오르면 지연이 짧고 느리면 길다. 곡선 전선에서는 노드마다 전선과의 기하 관계가 달라 상승률이 다르므로 **τ가 완전히 균일해도 dᵢ가 불균일해진다.**

**실측 τ (H0 세션, 2점):** 강제대류(드라이기) **11.07 s** (R²=0.884) / 준정지(에어컨 ON — 진짜 무풍 아님) **78.48 s** (R²=0.998). 비 7.1배. 시뮬이 시험한 범위는 {0, 2, 5, 10} s 뿐이었다 — **실측이 시험범위를 최대 8배 초과한다.** τ는 온도가 아니라 **유속**에 의존한다.

> **경고:** 과거에 제시한 `τ(u) = 24.6·u^−0.5`는 **2점에 2모수를 맞춘 자유도 0의 곡선**이며 검증된 관계가 아니다. 인용하지 말 것. H1 세션의 τ-1이 이것을 대체한다.

## 8. 탐지·판별 게이트

```
① 탐지 임계 T_th   : 센서 온도가 이 값을 넘으면 사망 후보
② 판별 게이트      : 사망 후보 중 화재로 인정되는 것만 적합에 채택
```

**구조적 사실:** 단일 스칼라 임계 T_th는 **방아쇠(trigger)와 판별자(discriminator)를 겸할 수 없다.** T_th를 낮추면 ①은 개선되지만 ②의 변별력이 무너진다 — 임계를 40~50℃로 낮췄을 때 (게이트 고정 시) 채택률 0, (게이트 동반 하향 시) 비화재 오염 89~100%가 이 사실의 발현이다.

**→ 임계 하향으로 τ를 구제할 수 없다.** 구제하려면 온도 이외의 판별 축(상승률, 공간 상관, Last-Gasp 같은 양성 증거)이 필요하다.

**Last-Gasp의 비대칭성:** 임종신호는 **양성 증거 축**으로만 쓴다 — 있으면 화재 쪽 증거가 되지만, **없다고 기각하지 않는다.** (전소로 신호를 못 보내는 경우가 바로 진짜 화재이므로, 부재를 기각 근거로 쓰면 최악의 경우에 가장 크게 틀린다.) 이 성질은 두 개의 테스트로 고정되어 있다.

## 9. 시뮬과 실물의 판정 일원화

판정 로직은 `Verifier._classify()` 한 곳에 있고 **시뮬과 실물이 같은 함수를 호출한다.** 두 경로가 다른 판정을 쓰면 시뮬 결과가 실물의 근거가 되지 못하기 때문이다.

**펌웨어 게이트는 의도적으로 느슨하다**(`lastTemp` → `peakTemp`). 말단에서 조이면 게이트웨이의 판별 분기가 볼 표본 자체가 굶기 때문이다. **판별은 정보가 가장 많은 곳(게이트웨이)에서 한다.**

## 10. 알려진 한계 — 각각 어느 가정에서 나오는가

**10-1. 곡률 한계 (A1).** 강하게 굽은 전선에서는 창 안에서 T가 1차 함수로 근사되지 않는다. τ=0에서도 방향오차가 남는 것이 이 때문이며 **τ 문제와 독립적인 별개 한계**다. 무차원 지표로 `κ·h`(곡률 × 노드간격)를 쓴다.

**10-2. 적합 창 요건 (A6).** 창 폭 W 안에 이웃의 사망이 들어와야 한다. 노드 간격 h, 전선 속도 s일 때 이웃 사망 간격은 대략 `h/s`이므로

```
W  ≳  K · h / s
```

**s가 작으면(느린 화재) 우변이 커져 고정 W로는 이웃이 창에 들어오지 않는다.** 이때 방향 추정은 오차가 커지는 게 아니라 **아예 불가능**해진다. 평면 3모수이므로 K ≥ 3이 하한, 잔차 검정을 살리려면 K ≥ 4 (D-061).

**10-3. 속도의 역수 편향.** s = 1/|∇T|는 볼록함수이므로 옌센 부등식에 의해 `E[1/|∇T|] ≥ 1/E[|∇T|]`, 즉 **속도에 상방 편향(과대추정)**이 있다. 방향에는 없다. **단, 집계가 중앙값이므로 이 편향은 평균 기반일 때보다 완화된다** — 중앙값은 옌센 편향을 그대로 물려받지 않는다(단조변환에 대해 중앙값은 보존되므로 `median(1/g) = 1/median(g)`). ★이건 §4-2의 중앙값 선택이 갖는 **부수적 이점**이며, 원래 의도한 바는 아니다.

**10-4. 공통 시계 요건 (A4).** 서로 다른 노드의 시각을 같은 축에서 빼는 연산이므로, 보드마다 기준이 다른 시계(부팅 기준 `millis()`)를 쓰면 ∇T가 **원리적으로** 무의미해진다. `mesh.getNodeTime()`(메시 동기 시각)을 쓴다. 또한 사망 시각은 **루트의 확정 시각이 아니라 당사자 노드가 각인한 시각**이어야 한다(확정 시각에는 침묵 감지 지연과 투표 지연이 섞인다).

**10-5. 사망 원인 판별 (A5).** 침묵의 원인은 화재 외에 통신두절·전원소진·크래시가 있다. 가짜 사망은 도착시각장에 잘못된 표본을 주입해 적합을 오염시킨다. §8의 게이트와 별도의 방어를 요구한다.

**10-6. 표본화 한계(Nyquist).** 노드의 죽음은 도착시각장의 **표본**이다. 표본 간격이 대략 h/s이므로 그보다 빠른 시간 규모의 전선 변동(돌풍에 의한 방향 요동 등)은 원리적으로 복원할 수 없다.

**10-7 ★신설. 집계의 붕괴점 (A7).** 방향 집계가 가중 벡터합이라 붕괴점 0이다. 가중치를 고쳐도 **연산자 자체는 여전히 비강건**하다. 역분산은 "나쁜 노드에 작은 가중치를 준다"로 대응할 뿐, "나쁜 노드가 있어도 무시한다"는 아니다. 근본 대응은 강건 집계(가중 기하중앙값 등)이며 미구현이다.

## 11. v1 명세의 오류 목록 (기록)

정직성 규율상 남긴다. **명세의 오류는 코드의 오류보다 발견이 늦다** — 실행되지 않기 때문이다.

| # | v1의 서술 | 실제 | 결과 |
|---|---|---|---|
| 1 | 전역 평면 적합 1회 | 노드별 국소 적합 N회 | 진단이 2단으로 향하지 못함 |
| 2 | 집계 단계 없음 | 존재하며 방향/속도가 다른 연산자 | **flank 82° 오진의 직접 원인** |

| 6 | 추정치 독립 암묵 가정 | 표본 중복으로 상관 | 신뢰구간 낙관 |
| **7** | **ETA = âx*+b̂y*+ĉ (절편 사용)** | **절편은 읽히지 않음. 최근접 노드의 관측 t_j를 앵커로 사용** | **INSUFFICIENT 게이트 우회를 못 봄** |

**★7번은 v1과 v2 초안이 둘 다 틀렸다.** 같은 오류를 두 판 연속 반복했고, 코드 추적으로만 잡혔다. 식이 그럴듯하면(교과서 형태이면) 검증 없이 통과한다는 사례다.

**메타 교훈:** 7개 중 **5개가 "존재하지만 명세에 없는 것"**, 1개(7번)가 **"명세에 있지만 코드에 없는 것"**이었다. 명세 점검은 "쓰인 것이 맞나"보다 다음 두 질문을 먼저 던져야 한다.

```
① 코드에 있는데 명세에 없는 것은?     ← 5/7
② 명세에 있는데 코드가 안 쓰는 것은?  ← 1/7  (죽은 필드 ĉ 가 그대로 살아있었다)
```

**②의 실용적 검사법:** 명세에 등장하는 모든 기호에 대해 **코드에서 그것을 읽는 지점이 존재하는가**를 확인한다. `ĉ`는 쓰이는 곳이 0곳이었고, 그 사실 하나만 봤어도 §5 전체가 틀렸음을 알 수 있었다.

## 13. 요약

```
입력 : {(xᵢ, yᵢ, tᵢ)}  — 노드 좌표와 노드 각인 죽음시각

1단  : 노드 j마다   S_j = 무선이웃(j) ∩ {|tᵢ−t_j| ≤ dt_window}
                   θ̂_j = (M_jᵀM_j)⁻¹M_jᵀt_j ,  ∇T_j = (â_j, b̂_j)
                   n̂_j = ∇T_j/|∇T_j| ,  s_j = 1/|∇T_j|
                   DOF_j = n_j − 3   (≥1 강제: n_j ≥ 4)

2단  : 방향  n̂ = Σ w_j n̂_j / |Σ w_j n̂_j| ,   w_j = |∇T_j|²   ← 정정됨(구 1/|∇T_j|)
       속도  s = median_j(s_j)                                  ← 강건, 유지
       진단  n_eff = (Σw)²/Σw²   ※ 반드시 n과 함께 표기
       미달  → 값을 내지 않음(INSUFFICIENT), 폴백 없음

ETA  : ★집계를 거치지 않는 별도 경로
       ETA(p) = t_{j*} + ∇T_{j*} · (p − pos_{j*}) ,  j* = p의 유클리드 최근접
       절편 ĉ는 계산되지만 읽히지 않는다
       → 가중 결함에 오염되지 않았으나, 정정과 게이트도 받지 못했다
```

**구조적 성질 여섯 줄:**

1. 방향·속도는 **기울기만** 쓰므로 균일 지연에 면역이고 이 면역은 **집계와 무관**하다. ETA는 **앵커**(절편이 아니라 관측 사망시각)를 써서 균일 지연에 그대로 편향된다 — 구현이 절편이든 앵커든 결론은 같다.
2. 방향·속도의 오차는 둘 다 `1/|∇T|`에 비례 — **절대오차로 비교해야** 하고, 빠른 전선일수록 불리하다.
3. **집계 가중치는 `|∇T|²`여야 한다.** `1/|∇T|`는 불확실성으로 가중하는 것이며 부호가 반대다. 두 가중치의 비는 `|∇T|³`이라 작은 |∇T|에서 폭발한다.
4. **방향은 비강건 집계, 속도는 강건 집계**를 쓴다 — 이 우연한 비대칭이 결함을 찾아낸 통제군이었다.
5. 자유도 `n_j−3`, 창 요건 `W ≳ K·h/s`, 국소 평면성 — 이 셋이 1단이 성립할 최소 조건이고, 여기에 **집계의 붕괴점**이 2단의 조건으로 추가된다.
6. **ETA는 집계를 우회한다.** 앵커가 관측 1개라 잡음 평균화가 없고(분산↑), 대신 앵커 노드에서 잔차가 0이라 곡률 편향이 없다(편향↓). 이 맞바꿈은 **선택된 적이 없다.**
