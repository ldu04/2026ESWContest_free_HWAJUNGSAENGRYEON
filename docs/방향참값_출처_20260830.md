# 방향 참값 55.48° / 75.96° 의 출처 — 재현 완료 (2026-08-30)

D-069(속도 변경) 검증 중 "현 설정으로 55.48° 가 안 나온다"고 보고했다. 추적한 결과
**둘 다 정확히 재현됐다.** 내가 틀린 정의로 재고 있었다.

## 결론

| 값 | 정의 | 계산 | 결과 |
|---|---|---|---|
| **75.96°** | 행 우선(n01→n16) 순차 가열의 **도착시각 평면 기울기** | `atan2(4, 1)` | **75.9638°** |
| **55.48°** | **점화점 → 판 중심** 방향 | `atan2(0.30−(−0.11), 0.30−0.02)` = `atan2(0.410, 0.280)` | **55.4826°** |

출처 문장: `docs/cowork/데모설계_결정표.md:121` — 「**참값 (점화점 → 판 중심)**」.
75.96 은 같은 문서 29~30행 — 「행 우선 순서에서 `t = (d/h)·x + (4d/h)·y` … 방향 = `atan2(4,1)`」.

**둘 다 현재 설계(간격 0.20 m, 점화점 (0.02, −0.11), 현 매핑)에서 그대로 나온다.**
바꿀 것이 없다. 덱 v9 의 인용도 옳다.

## 내가 왜 못 찾았나

세 가지 정의를 시도했는데 **문서가 쓴 정의가 그 셋에 없었다.**

| 정의 | 값 (간격 0.20 m) | 문서의 55.48 인가 |
|---|---|---|
| 국소 법선의 벡터평균 (16노드) | 57.2618° | 아니오 |
| 전역 단일 평면적합 | 54.7696° | 아니오 |
| **점화점 → 판 중심** | **55.4826°** | **예** |

"전역 평균" 이라는 표현을 「노드별 법선의 평균」으로 읽었는데, 실제로는
**「전선 전체를 하나의 방향으로 대표시킨 값」** = 점화점에서 판 중심을 향하는 방향이었다.
원형 전선에서는 위치마다 법선이 다르므로, **판 전체를 대표하는 하나의 각도**로는
중심 방향을 쓰는 것이 자연스럽다.

## 세 정의의 값 — 현재 설계 기준으로 확정

간격 0.20 m · 점화점 (0.02, −0.11) m · `nXX → id = XX−1`:

    점화점 → 판 중심      55.4826°   ← 덱·문서가 쓰는 "참값"
    국소 법선 벡터평균     57.2618°
    전역 단일 평면적합     54.7696°

**세 값 모두 화선 속도 v 와 무관하다.** 앞의 둘은 시각을 전혀 쓰지 않고,
평면적합은 `∇T = (1/v)·r̂` 이라 v 가 크기만 바꾸고 방향은 안 바꾼다.
→ D-069 의 속도 변경(1.10 → 0.61 mm/s)이 참값을 건드리지 않았다는 결론은 그대로 유효하다.

## 남는 주의

`75.96°` 는 **격자 간격과 무관**하지만(한 행 4개라는 사실에서 나온다),
`55.48°` 는 **간격에 의존한다**(중심 좌표가 간격으로 정해지므로).
배치를 0.20 m 에서 바꾸면 55.48 도 다시 계산해야 한다. 0.15 m 였다면 58.54° 다.
