라즈베리파이 위치 — 앞쪽 아님. 판 뒤쪽.

좌표는 판 기준 cm. 판 0~70, 노드 5/25/45/65.

항목좌표 (판 기준)이유
앞쪽 −y불가 받침 3장이 y 0 → −25.7 차지, 거치대 다리가 y −41 → +54 왕복. 파이 놓을 자리 자체가 없고, 놓으면 다리에 채임.
뒤쪽 모서리x 76~94 / y 76~89 판 뒷변(y=70)에서 6cm 이상, 오른쪽으로 비켜서 케이블 다발과 안 겹침. 거치대가 가장 뒤로 갔을 때(앞다리 y=54, 총구 y=65) 파이까지 11cm 여유.
브리지 ESP32파이 USB에 직결 파이 옆에 붙어 있어야 "여기가 관제"로 읽힘. 메시는 방 전체 범위라 위치 자유.
허브 · 충전기y ≥ 96파이보다 뒤. 화각 밖.
카메라뒤쪽 우측, 45° 부감 근경에 파이, 원경에 판 대각선, 맨 끝에 열풍기. 한 프레임에 관제 → 필드 → 화원이 다 들어감.
확인결과
열가장 가까운 노드(y=65)까지 11cm. 제트 감쇠 f(x)=3.12/(x+3.12) → 11cm에서 22%, 실제로는 4cm 지점에서 이미 표적에 꽂히므로 파이 위치는 상온. 문제 없음.
케이블 길이A행(y=5)에서 판 뒤까지 65 + 8 = 73cm. 보유 케이블 75~80cm — 확인됨.
철회"파이를 앞쪽으로"는 A행 케이블 길이 대책이었음. 길이 확인됐으니 철회. 앞쪽 배치 안 함.
