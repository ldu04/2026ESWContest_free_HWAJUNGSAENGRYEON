둘 다 허용치 안입니다. 코너만으로도 됩니다. 다만 판지 다리 면이 얼마나 곧은지에 그대로 걸립니다.

그래서 — 둘 다 하면 됩니다

추가 노력이 거의 없습니다.

  • 가로선 1개 (행마다) — 다리 2개 앞면을 여기 댐 → 각도
  • 상자 1개 (열마다) — 다리 하나를 여기 넣음 → 좌우 위치

상자는 실제 다리 대고 연필로 한 바퀴. 판 위에 행마다 3개, 총 9개면 됩니다 — 옆 열이 같은 상자를 공유하기 때문입니다.

A4 패드 4장 — 전부 이동식

패드놓는 법표시
앞판 앞 가장자리 밀착 → 좌우로 밀어 판 세로선에 맞춤가로선 1 + 세로선 2
좌판 왼쪽 밀착 → 위아래로 밈없음
우판 오른쪽 밀착 → 위아래로 밈없음
뒤앞 패드 뒤에 대충없음

앞 패드만 표시가 있고, 그 표시는 패드가 움직여도 유효합니다. 밀착시키면 앞뒤가 고정되고, 좌우는 패드 세로선을 판 세로선에 이어 맞추면 되기 때문입니다.

좌·우·뒤 패드는 받치기만 합니다. 거치대 위치는 이미 판 위 가로선 + 상자로 정해져 있어서, 이 패드들은 어디 놓이든 상관없습니다.
