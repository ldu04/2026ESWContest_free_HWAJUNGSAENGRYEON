03 값을 바꾸면 무엇이 무너지는가

지금까지 여기서 계속 사고가 났다. 바꾸기 전에 해당 사슬을 끝까지 돌린다.

감지부 높이 → 노즐 높이 → 프로브 재검증 (다리 위치는 안 바뀜 — 높이만 축 방향으로 흡수) 받침 두께 → 다리 높이 → 거치대 기울기 → 조준 전체 ★ 가장 위험. 종이가 눌리면 여기가 무너진다 격자 위치 → 다리 상자 16개 전부 다시 → 다림추 재정렬 커넥터 방향 → 스탠드오프 위치 → ESP32 위치 → USB 케이블 경로 → LED 위치 → 점퍼 길이 ★ 가장 넓게 퍼진다. 16개 통일 여부만 중요 체류시간 → B 대본 전체 재계산 (전선속도·16개 사망시각) 방향 참값은 불변 (기하학)

감지부 실측 좌표는 빼먹으면 안 된다. 판 격자에 5mm 오차가 있어서, 알고리즘에 공칭값(0/20/40/60)을 넣으면 방향 참값에 약 0.2° 오차가 그대로 들어간다. A 시나리오가 자랑하는 값이 0.03°다. 조립 직후 자로 16개 × (x, y)를 재서 게이트웨이 설정 파일에 넣는다.

이 문서는 실측·실물 기준이다. 공칭값이 아니라 잰 값을 적는다. 값이 바뀌면 03의 사슬을 끝까지 돌린 뒤 이 문서를 갱신한다.
