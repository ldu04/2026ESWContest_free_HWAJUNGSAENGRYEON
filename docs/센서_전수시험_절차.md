# 센서 전수 반응시험 — 16대 (2026-09-01)

## 왜 필요한가
n01 은 배선(DAT↔VCC)이 바뀌어 있어서 **온도를 못 읽었고, 그래서 죽지 않았다.**
그 고장은 화면에서 **25.00℃ = 실온**과 구별되지 않는다. 구별하는 유일한 방법은
**열을 넣어 값이 오르는지 보는 것**이다. 눈으로 못 잡는 고장이므로 **전수로** 한다.

## 준비
1. 브리지는 **노트북**에 꽂혀 있어야 한다(파이 경로는 쓰지 않는다 — [D-075]).
2. 음성 온도계를 띄운다. **브리지 포트는 자동으로 제외된다**(`is_root` 로 거른다).
   ```
   python scripts/temp_voice.py
   ```
3. 열풍기 예열 — **5분**. t80 을 그 조건에서 쟀으므로 조건을 바꾸면 결과가 무의미하다.

## 방법 (노드당 약 15초)
노드마다 **열풍기를 멀리서 3초**. 판정은 셋 중 하나다.

| 관측 | 판정 | 조치 |
|---|---|---|
| 기준보다 **+2℃ 이상 상승** | 통과 | 다음 노드 |
| 값이 **안 움직임** | ★ 센서를 못 읽는다 | DAT 가 **가운데 다리 → GPIO4** 인지 확인 |
| 패키지가 **따끈함**(전원만 넣었는데) | ★ 극성 반대 | 즉시 분리. DAT↔VCC 확인 |

**손가락으로 하지 마라.** n07 을 손으로 잡아도 440 표본 내내 26.00℃ 를 못 넘었다 —
TO-92 패키지의 열용량 때문에 손가락은 판정 자극이 못 된다.

## 온도를 시리얼로 직접 볼 수 있는 노드
TT 트레이스는 **그 기능이 들어간 뒤 구운 보드**에만 있다: **n01 · n04 · n07**.
나머지는 **브리지를 거쳐**(하트비트의 `temp` 필드) 본다 — `scripts/rollcall.py` 가 그걸 쓴다.
하트비트는 5초 간격이라 반응이 느리게 보인다. 급하면 그 노드만 노트북 시리얼에 물려
`temp_voice.py --ports <포트>` 로 본다.

## 통과 기준
**16대 전부 +2℃ 이상 반응.** 하나라도 못 넘으면 그 노드는 리허설에서 **죽지 않는다** —
1회차가 정확히 그래서 무산됐다.
