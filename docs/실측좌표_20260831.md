## 1. 산출 방법

**인접 간격 24개(가로 12·세로 12)를 자로 실측하고, 행 수평·열 수직 정렬을 가정해
누적합으로 절대좌표를 복원했다. 기울어짐은 측정하지 않았다.**

    행 총합 60.4 / 60.6 / 60.4 / 60.5 cm
    열 총합 60.3 / 60.2 / 60.1 / 60.2 cm      → 편차 0.2 cm 이내

반영 결과:

    명목 대비 이동량   최대 0.61 cm · 중앙 0.40 cm · 이동 없음 2개
    최근접거리 중앙값  0.1990 m   (설정 spacing_m 0.200 대비 −0.5%)
    이웃수 분포        {3:4, 5:8, 8:4}  ← 4×4 정격자 기대값과 일치
    라벨 규약          nXX → id = XX−1  (n01→id0 … n16→id15)

### ★ 측정하지 않은 것 — 반드시 같이 읽을 것

- **판의 기울어짐(회전)과 직각도를 재지 않았다.** 각 행이 수평이고 각 열이 수직이라고
  **가정**했다. 판이 기울어져 있으면 이 방법은 그 성분을 좌표에 반영하지 못한다.
- 대각선(예: n01↔n06)을 재서 직각도를 교차검증하지 **않았다.**
- 높이(z)는 재지 않았다. 추정은 2차원 평면이다.

## 3. ★★ 참값이 바뀐다 — 덱·문답을 손대기 전에 판단이 필요하다

「참값 = 점화점 → 판 중심」은 **판 중심 좌표에 의존**한다. 실측으로 중심이 옮겨졌다.

| | 명목 격자 | **실측 좌표** | 차이 |
|---|---|---|---|
| 판 중심 (외곽 중점) | (0.3000, 0.3000) m | **(0.3030, 0.3015) m** | +3.0, +1.5 mm |
| **참값 (점화점 → 판 중심)** | **55.6698°** | **55.4826°** | **−0.1872°** |
| (참고) 16노드 무게중심 기준 | — | 55.5358° | −0.1340° |

**−0.19° 는 무시할 크기가 아니다.** 무잡음 기하학적 하한이 0.2483° 였으므로
(`docs/추정기_강건성_20260831.md` §0) **같은 자릿수**다.

### ★ 사람이 정해야 할 것

덱(발표15·발표16)과 `docs/예상질문_답변.md` Q9 는 **참값 55.67°** 를 쓴다.
실측 좌표로 촬영하면 그 숫자는 **55.48°** 여야 맞다.

| 안 | 내용 |
|---|---|
| **A** | 덱을 55.48° 로 고친다 (v10 동결 해제 필요) |
| **B** | 덱은 두고, 발표에서 「명목 격자 기준 55.67°, 실측 좌표 기준 55.48°」로 함께 말한다 |
| C | 좌표를 명목으로 되돌린다 — **권하지 않는다.** 실측을 버리는 것이다 |

**B 를 권한다.** 두 값의 차이(0.19°)가 왜 생기는지 설명할 수 있으면 오히려 강점이 된다.
**덱은 건드리지 않았다.**

## 4. 파이 ↔ 노트북 대조 — ★ 미확정

노트북 쪽 `gateway/deploy_config.json` 의 노드 좌표 지문:

    SHA-256(앞 16) = ba8dd13f4150c69c        ← 노트북 (2026-08-31 반영 후)

**양쪽에서 같은 명령을 돌려 지문이 같으면 완전히 동일하다:**

```bash
python - <<'EOF'
import json, hashlib
d = json.load(open('gateway/deploy_config.json', encoding='utf-8'))
s = ';'.join('%d:%.4f,%.4f' % (n['id'], n['x'], n['y'])
             for n in sorted(d['nodes'], key=lambda z: z['id']))
print('measured =', d['deployment']['measured'])
print('fingerprint =', hashlib.sha256(s.encode()).hexdigest()[:16])
EOF
```

### ★ 2026-08-31 대조 완료 — **완전히 같다**

| | `measured` | 지문 (SHA-256 앞 16) |
|---|---|---|
| 노트북 | `true` | **`ba8dd13f4150c69c`** |
| **파이** (`bulsa.local`) | `true` | **`ba8dd13f4150c69c`** |

**두 지문이 일치한다 = 16개 노드의 x/y 가 소수 넷째 자리까지 동일하다.**
파이에는 SSH 키를 넣어 무비밀번호로 접속해 직접 확인했다(개인키는 노트북 밖으로 내보내지 않았다).
