# 유도 — 표본 적정성 자기진단 기준 (2.M §1-1)

> **★ 이 문서는 측정보다 먼저 작성·커밋된다.** 결과를 보고 기준을 정하면 p-해킹이다.
> 아래 임계는 전부 **선형최소자승의 성질에서 유도**했거나 **이미 승인된 실용선**을 그대로 쓴 것이며,
> 2.L §4의 결과 수치(82~86°, per_node 20~60 % 등)를 보고 고른 값이 **하나도 없다.**
> 유도 → 문서화(이 커밋) → 구현 → 측정 순서를 지킨다.
>
> **참고 문서 부재 기록:** 지시서가 인용한 `명세_FailurePattern_수학적정식화.md`는 **저장소에 없다**
> (Cowork 측 문서). 그래서 그 문서를 인용하지 않고 `sim/estimator.py`의 실제 코드에서 직접 유도했다.
> 결과가 그 명세와 어긋나면 명세를 정본으로 삼아 정정해야 한다.

## 0. 무엇을 진단하는가

`estimator._fit_local`이 각 사망 노드 i에서 푸는 것:

```
A = [[x_k, y_k, 1] for k in S_i]      (n×3)
b = [t_k          for k in S_i]       (n,)
(a, b, c) = lstsq(A, b)   →   ∇T = (a, b),  방향 = ∇T/|∇T|,  속도 = 1/|∇T|
```

`S_i` = {i} ∪ {사망 이웃 j : |t_j − t_i| ≤ `dt_window`}.

**진단 대상은 "이 적합이 방향을 구속하고 있는가"이다.** 답이 나왔다는 사실은 구속됐다는 증거가 아니다 —
`lstsq`는 악조건에서도 (최소노름 해로) **무언가를 돌려준다.** 2.L §4의 flank가 정확히 그 경우였다.

---

## 1. (a) 개수 하한 — 자유도에서 유도

평면은 **3 파라미터**다. 관측 n개면 잔차의 자유도 `DOF = n − 3`.

| n | DOF | 성질 | 등급 |
|---|---|---|---|
| ≤ 3 | ≤ 0 | 잔차가 **항등적으로 0**. 노이즈가 감쇠 없이 그대로 기울기로 통과하고, **자기 오차를 추정할 방법조차 없다** | **INSUFFICIENT** |
| 4 | 1 | σ̂ 추정은 되나 χ²(1) — 추정치 자체의 상대불확실성이 100 % 수준 | **DEGRADED** |
| ≥ 5 | ≥ 2 | 잔차로 노이즈 크기를 의미 있게 추정 가능 | 개수 기준 **OK** |

> **유도만으로 나온 값이다.** 3은 파라미터 수, 4·5는 DOF 1·2의 경계일 뿐 조정 여지가 없다.
> `min_samples=3`(현행)은 **적합이 성립하는 최소**이지 **믿을 수 있는 최소**가 아니다 — 이 구분이 요점이다.

---

## 2. (b) ★기하 조건 — 공선성이 개수보다 근본이다

상수항 c는 잉여모수이므로, 기울기 (a,b)를 구속하는 것은 **중심화된 좌표**뿐이다:

```
M̃ = [[x_k − x̄, y_k − ȳ]]        (n×2)
(a, b) 의 공분산  Cov(ĝ) = σ_t² · (M̃ᵀM̃)⁻¹
```

`M̃`의 특이값을 σ₁ ≥ σ₂ ≥ 0 이라 하면 `(M̃ᵀM̃)⁻¹`의 고유값은 `1/σ₁², 1/σ₂²`.

**관측이 한 줄로 늘어서면(공선) σ₂ → 0 이고, 그 선에 수직한 기울기 성분의 분산이 발산한다.**
→ **개수가 아무리 많아도 방향의 한 성분이 구속되지 않는다.** 이것이 개수 지표가 못 잡는 실패다.

**순수 기하 지표(무차원):**
```
s₂ = σ₂ / (h · √n)          h = 노드 간격
```
정사각 배치면 s₂ = 0.5, 완전 공선이면 s₂ = 0. **노드 간격과 표본 수로 정규화**했으므로 배치 밀도·크기와 무관하다.

---

## 3. ★ 두 축을 하나로 — **예측 각불확실성** (이것이 주 지표)

개수와 기하를 따로 임계 잡으면 임의성이 들어간다. 둘 다 **같은 결과량**으로 환산하면 임계가 하나로 준다.

기울기 추정의 수직 성분 오차가 방향 오차를 만든다. ĝ에 수직인 단위벡터를 u⊥라 하면

```
Var(ĝ·u⊥) = σ_t² · u⊥ᵀ (M̃ᵀM̃)⁻¹ u⊥
δφ̂ = √(Var(ĝ·u⊥)) / |ĝ|            [rad]
```

`σ_t`는 사망시각 노이즈인데 **런타임에 잔차로 추정된다**:
```
σ̂_t = √(SSR / DOF)                  (DOF ≥ 1 필요 → 위 §1의 n ≥ 4와 자동으로 맞물린다)
```

**`δφ̂`는 전부 런타임 관측량이다** — 참값·시뮬 내부를 쓰지 않는다. 실물에서 그대로 계산된다.

**보수 상한(진단용 보조):** 최악 방향을 가정하면 `δφ̂_max = σ̂_t · v / σ₂` (v = 추정 속도).

---

## 4. (c) 등급 — ★임계는 **이미 승인된 실용선**을 그대로 쓴다

새 숫자를 만들지 않는다. 방향 실용선 **5°**는 지시서 #1 DoD 이래 이 프로젝트가 계속 써온 값이다.

| 등급 | 조건 | 뜻 |
|---|---|---|
| **INSUFFICIENT** | `DOF < 1`(n ≤ 3) **또는** `σ₂ ≤ ε_geom` | 자기 오차를 추정할 수 없거나 방향이 원리적으로 구속되지 않음 → **답을 내지 않는다** |
| **DEGRADED** | `δφ̂ > 5°` | 답은 내되 **신뢰도 낮음**을 표시 |
| **OK** | `δφ̂ ≤ 5°` | 표본이 방향을 실용선 안에서 구속함 |

- `ε_geom`: 수치 하한. `σ₂ ≤ 1e-9 · σ₁` 이면 공선으로 본다(부동소수 잡음 수준). **조정 대상 아님.**
- **DOF=1(n=4)은 §1에서 DEGRADED**이므로, `δφ̂ ≤ 5°`여도 DEGRADED로 강등한다(σ̂ 자체가 못 미더우므로).

### 전역 등급 (per-node 적합들을 합친 방향)
`_fit_global`은 per-node 방향의 속도가중 평균이다. 전역 신뢰도는 두 가지에 걸린다:

```
δφ̂_stat = RMS(per-node δφ̂) / √n_ok          (평균화 이득)
δφ̂_disp = 원형표준편차(per-node 방향) / √n_ok  (서로 얼마나 어긋나는가)
δφ̂_global = max(δφ̂_stat, δφ̂_disp)            (보수적으로 큰 쪽)
```
같은 5° 선으로 등급을 매긴다. `n_ok = 0`이면 INSUFFICIENT.

---

## 5. ★ 이 진단이 **못 잡는 것** (미리 밝힌다)

1. **계통 편향(bias).** 모든 국소 적합이 **일관되게** 틀리면 δφ̂도 분산도 작다. 진단은 통과시킨다.
   → 곡률로 인한 오차가 여기 해당할 수 있다. **§2가 그래서 필요하다.**
2. **모델 오차.** 진단은 "평면 모델 하에서 표본이 충분한가"만 본다. 전선이 평면이 아니면 그건 다른 문제다.
3. **사망시각 자체의 계통 오차**(τ 편향 등). 잔차에 안 잡히는 공통 시프트는 보이지 않는다.

> ⇒ **`OK`는 "정확하다"가 아니라 "표본 부족으로 틀린 건 아니다"라는 뜻이다.** 이 구분을 문서·출력에 명시한다.

## 7. 분기③ 초기 표본 문제와의 관계 (§1-4)

`Verifier._residual`도 **같은 3파라미터 평면적합**을 쓴다(확정 사망들의 (x,y,t)).
`len(acc) < min_samples`면 `None`을 돌려주고 Fix A가 제외한다 — **개수 기준만 있고 기하 기준은 없다.**
같은 `s₂`·`δφ̂` 도구를 여기에도 적용할 수 있는지 §1-4에서 코드를 읽어 확인한다(추정하지 않는다).

# 부록 A — 분기③ residual 검사의 DOF 결함 (2.N §3, 측정 전 유도)

> **이 절도 측정보다 먼저 쓰고 커밋한다.** 아래는 자유도에서 **유도되는 사실**이지 결과를 본 뒤 정한 값이 아니다.

## A-1. n=3에서 검사가 공허한 이유

`Verifier._residual`은 확정 사망 이웃 `acc`의 (x, y, t)로 **3파라미터 평면**을 적합한 뒤,
후보의 도착시각이 그 평면에서 얼마나 벗어나는지를 본다.

```
A = [[x_k, y_k, 1]]  (n×3),   b = [t_k]
sol = lstsq(A, b)  →  pred = sol·(x, y, 1)  →  residual = |t_est − pred|
```

**`n = 3`이면 미지수 3개·방정식 3개다.** A가 특이가 아닌 한 평면은 세 점을 **정확히** 지나므로
적합 잔차는 **항등적으로 0**이다. 그 평면은 세 점의 어떤 노이즈도 그대로 흡수한다.

⇒ 그 상태에서 `residual ≤ residual_gate_s`를 재는 것은 **노이즈를 통과시킨 평면과 후보를 비교**하는 일이다.
검사가 무엇을 걸러내는지에 대한 통계적 근거가 없다. **판별력을 가지려면 잉여 관측이 필요하다: `n ≥ 4`(DOF ≥ 1).**

- `n = 4` (DOF=1): 잔차가 0이 아닐 수 있어 평면이 데이터에 **저항**하기 시작한다. 최소 요건.
- `n = 5` (DOF=2): 잔차로 노이즈 크기(σ̂)를 의미 있게 추정할 수 있다(본문 §1과 동일한 경계).

**본문 §1(a)와 같은 유도이며 같은 경계값이다** — 대상이 estimator의 국소 적합이 아니라
verifier의 residual 적합일 뿐이다.

## A-2. 그러나 조이는 데는 대가가 있다

`n`을 올리면 `_residual`이 `None`을 돌려주는 경우가 늘고, 배포 기본값 Fix A는 그때 **제외**한다.
⇒ **공허한 통과는 줄지만 진짜 화재사망도 더 많이 버려진다.** 이건 교환관계이므로
**스윕으로 재서 표로 내야 하며, 채택 여부는 이 문서가 정하지 않는다**(판정 규칙 변경은 baseline 재확정을 요구).

## A-3. ★변수 분리 (중요)

`cfg.min_samples`는 **두 곳**에서 쓰인다:
`estimator._fit_local`(국소 평면의 최소 표본)과 `Verifier._residual`(분기③ residual 적합).
**그대로 스윕하면 추정기까지 같이 바뀌어 교란된다.**
⇒ `residual_min_samples`를 신설하고 **기본값 `None` → `min_samples`로 폴백**(비트 동일)한 뒤,
분기③만 스윕한다. estimator는 건드리지 않는다.

## A-4. 사전등록 예측 (측정 전)

| # | 예측 | 등급 |
|---|---|---|
| **N1** | `residual_min_samples`를 3→4로 올리면 분기③ 채택률이 **감소**한다 | [식 유도] |
| **N2** | 같은 조작으로 비화재 오염률도 **감소**한다(공허한 통과가 줄므로) | [유추] |
| **N3** | 방향오차·첫 방향 산출 시각은 **거의 안 변한다** — 2.M §1-4에서 baseline은 분기③을 거의 쓰지 않았다(strict 제외 0.00건) | [측정 기반: 2.M §1-4] |
| — | 어느 값을 채택할지는 **예측하지 않는다.** 스윕 결과만 낸다 | — |

# 부록 B — 전역 집계 가중의 유도 (2.N 추가-G, 측정 전)

> **★ 이 절도 측정보다 먼저 쓰고 커밋한다.** 아래 가중식은 최소자승의 분산에서 **유도**한 것이지
> 결과를 보고 고른 것이 아니다. **채택은 하지 않는다** — 기본값은 legacy 유지.

## B-1. 현행 가중이 무엇인가

`_fit_global`은 per-node 단위 방향벡터를 **`w_i = speed_i = 1/|∇T_i|`** 로 가중해 벡터합한다
(상세는 `docs/구조보고_estimator_2단집계.md`).

## B-2. 최적 가중은 무엇인가 — 역분산

본문 §3에서 per-node 방향의 각오차 분산은
```
Var(δφ_i) = σ_t,i² · q_i / |∇T_i|² ,      q_i = u⊥ᵀ (M̃ᵀM̃)⁻¹ u⊥   (기하 인자)
```
서로 독립인 추정치들을 합칠 때 분산을 최소화하는 가중은 **역분산**이다:
```
w_i^opt ∝ 1/Var(δφ_i) = |∇T_i|² / (σ_t,i² · q_i)
```

## B-3. ★두 가중은 `|∇T|`에 대해 **반대 방향**이다

```
현행 :  w_i ∝ |∇T_i|^(−1)
최적 :  w_i ∝ |∇T_i|^(+2) / (σ̂_t,i² q_i)
```
`|∇T_i|`가 작아질수록 현행 가중은 **커지고** 최적 가중은 **작아진다.** 지수 차이가 **3**이다.

그리고 명세 §6(δφ ≈ δ⊥/|∇T|)과 결합하면 `|∇T|`가 작다는 것은 곧 **그 적합의 방향오차가 크다**는 뜻이므로,
현행 규칙은 **"방향오차가 클수록 큰 가중"**이 된다. 추정이론의 역분산 가중과 **정반대**다.

> **왜 이렇게 돼 있었는지에 대한 추정은 하지 않는다**(코드에 근거 주석이 없다). 관찰만 기록한다.

## B-4. 실무형: `δφ̂`가 이미 있다

본문 §3의 `δφ̂_i`가 곧 `√Var(δφ_i)`의 런타임 추정치이므로
```
w_i^opt ≈ 1 / δφ̂_i²
```
로 바로 쓸 수 있다. **새 양을 만들 필요가 없다** — 2.M §1의 진단 지표를 그대로 재사용한다.

## B-5. 비교할 후보 (하나만 고르지 않는다)

| 코드 | 가중 | 근거 |
|---|---|---|
| **legacy** | `1/\|∇T\|` | **현행. 기본값으로 유지** |
| **uniform** | 1 | 가중을 없앤 대조군 |
| **median** | 원형 중앙값 | 이상치에 강함(순위 기반) |
| **invvar** | `1/δφ̂²` | **B-2의 이론적 정답 후보** |
| **invvar_trim** | `1/δφ̂²` + INSUFFICIENT 배제 | (d) + 퇴화 적합 제외(2.M §1 등급 재사용) |

## B-6. ★유효표본수 — 진단의 세 번째 축 (추가-G-5)

가중 평균의 **유효표본수**(Kish):
```
n_eff = (Σ w_i)² / Σ w_i²        ,   1 ≤ n_eff ≤ n
```
- 모든 가중이 같으면 `n_eff = n`. **하나가 지배하면 `n_eff → 1`**.
- `w_max/Σw → 1` 이면 **실질적으로 표본이 1개**라는 뜻이고, 그 1개가 틀리면 전역이 통째로 틀린다.

**유도되는 판정선:** 전역 방향이 "여러 국소 적합의 평균"이라는 전제가 성립하려면 최소한
`n_eff ≥ 2`(둘 이상이 실질 기여)여야 한다. 그 미만이면 평균의 이점이 없으므로
**전역 등급을 per-node 최악 등급으로 강등**하는 것이 정합적이다.
**이 선(2)은 "평균이 성립하려면 2개 이상"이라는 정의에서 나온 값이지 결과를 보고 고른 값이 아니다.**

기존 `disp`는 **비가중** 원형표준편차라 가중 후 붕괴를 보지 못했다([D-059]에서 확인).
⇒ **가중 반영 disp**도 함께 낸다: 각 방향을 `w_i`로 가중해 평균벡터를 만든 뒤 R을 구한다.
