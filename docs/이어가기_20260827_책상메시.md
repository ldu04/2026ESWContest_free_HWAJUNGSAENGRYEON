브리지만 노트북 데이터, 노드 3대는 허브 전원.

1. **4대가 다 보이는가** — 브리지 시리얼에서 5초마다 나오는 `{"type":"TOPO",...,"n_peers":N,"sub":{...}}`.
   `n_peers` 가 3 이어야 한다(브리지 제외).
2. **붙는 데 몇 초** — 전원 인가부터 `n_peers=3` 까지의 `ms` 값.
3. **재접속** — 한 대를 전원에서 뽑았다 꽂고 `n_peers` 가 2→3 으로 돌아오는지, 몇 초 걸리는지.

여기서 안 붙으면 원인부터. 아래로 넘어가지 말 것.
