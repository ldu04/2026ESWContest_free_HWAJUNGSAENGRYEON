### 왜 PowerPoint 가 아닌가 — 둘 다 돌려보고 정했다

PowerPoint COM 내보내기는 **이제 된다.** v8 에서 규격 위반 도형(음수 크기 130개)을 고쳤기 때문이다.
그전에는 PowerPoint 가 파일 자체를 못 열었다(`0x80070570`). 그런데 두 결과물을 재보니:

| 항목 | PowerPoint | LibreOffice |
|---|---|---|
| 어절 중간 줄바꿈 | **40건** | **4건** |
| `n̂` (결합 곡절) | `n^` 으로 깨짐 | 정상 |
| 미임베딩 폰트 | 0 | 0 |
| 넘침·겹침 | 0 | 0 |

한국어 줄바꿈과 수식 기호 둘 다 LibreOffice 가 낫다. **제출본은 LibreOffice 로 뽑는다.**

### 그래도 음수 크기 수정은 반드시 유지한다

심사위원이 **pptx 를 직접 열 수 있다.** v7 까지는 PowerPoint 에서 「복구할 수 없습니다」로 안 열렸다.
v8 부터 열린다. 이건 렌더 경로와 무관하게 지켜야 할 수정이다.

  > **1번 항목의 개요 표에 반드시 들어가는 칸**: 작품명 / 개발 배경 / 동기 / 목표 / 필요성 /

## 2순위 — 분량 배분 두 곳이 어긋난다

| 항목 | 요강 | 실제(v11) | 차이 |
|---|---|---|---|
| 1 개발 개요 | 3P | 본문 1~3 = **3P** | ✓ |
| **2+3+4** 환경·프로그램·장애요인 | **10P 합계** | 본문 4~15 = **12P** | **+2P** |
| **5+6** 차별성·파급력 | **5P 합계** | 본문 16~19 = **4P** | **−1P** |
| **7** 일정·업무 분장 | **2P** | 본문 20 = **1P** | **−1P** |
| 합계 | 20P | **20P** | ✓ |

요강에 「일부 조정은 허용」이 있으므로 정확히 맞출 필요는 없다. 다만 **+2P / −1P / −1P 는 눈에 띈다.**

**제안:** 장애요인(4번, 현재 5P)에서 **2P를 덜어** 5·6번에 +1P(판매가치·시장성 보강),
7번에 +1P(일정·업무 분장 상세)로 옮긴다. 4번은 서사가 이어지는 부분이라 두 장을 합치기 쉽다.
