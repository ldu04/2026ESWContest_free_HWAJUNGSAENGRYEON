## A. 하드웨어-시뮬 괴리 지도 (시뮬 가정 → 실물 현실 → 영향 → 대응)

### ★ A-1. 시계 동기 (clock sync) — 가장 큰 위험
- **시뮬 가정:** 모든 노드가 **하나의 시계**를 공유. 죽은 시각이 정확히 일관됨.
- **실물 현실:** ESP32마다 **자기 시계**가 있고 서로 **드리프트(drift=시계 오차)**. 수백 ms만 어긋나도 노드 간 "죽은 시각" 비교가 오염.
- **영향:** 우리 추정기는 죽은 시각 **차이**(초 단위)로 방향·속도를 뽑음 → 시계 오차가 그대로 **방향·속도 오차**로 번짐. **시뮬에선 절대 안 보이는 실물 전용 위험.**
- **대응:** ① **painlessMesh의 메시 시각 동기**(`getNodeTime()` = 메시 전체가 공유하는 동기 시각) 사용 — 우리가 고른 라이브러리가 마침 이걸 제공. ② 보조로 게이트웨이가 **도착 시각 스탬프**(단 전송 지연이 새 노이즈). → **①을 기본, 시뮬로 잔여 지터 영향 측정(B).**

### A-2. 실제 RF의 지저분함
- **시뮬:** 링크가 확률적으로 잠깐 두절(dropout)만.
- **실물:** 패킷 유실·지연 편차·재연결·hidden node(서로 안 보이는 노드). 훨씬 지저분.
- **영향:** 하트비트 누락 오탐↑, 릴레이 지연.
- **대응:** painlessMesh 재전송·자동복구, 하트비트/타임아웃 여유. 시뮬로 **고 dropout·비대칭 링크** 스트레스.

### A-3. 노드 좌표 오차
- **시뮬:** 정확 좌표. **실물:** 손으로 배치 → 오차.
- **영향:** 추정 방향·속도에 편차. **대응:** 배치 흔들림은 이미 S4에서 테스트(견고 확인). 실물 배치 시 좌표 기록 정확히.

### A-4. 온도센서 지연·노이즈
- **시뮬:** 온도 = 전선 거리의 즉시 함수. **실물:** DS18B20은 **응답시간(수백 ms~초)**·측정 노이즈 존재.
- **영향:** 임계 감지 타이밍 지터 → 죽은 시각 지터. **대응:** 온도 필터·이력 사용. 시뮬로 **온도 노이즈·지연** 주입해 영향 측정(B).

### A-5. 비화(spot fire) — 단일 전선 가정 붕괴
- **시뮬:** 전선 하나가 쓸고 감. **실물/현실:** 불티가 앞으로 튀어 **새 발화점**이 생김(비화).
- **영향:** "하나의 방향" 가정이 깨져 추정이 흔들릴 수 있음. **대응:** 국소 추정이 부분 흡수하지만, 시뮬로 **비화 시나리오** 넣어 어디서 깨지는지 확인(B). (다중 소스 추정은 발전방향)

### A-6. 화재가 아닌 노드 사망 (배터리·고장)
- **실물:** 노드가 **불이 아닌 이유**(배터리 방전·리셋·고장)로도 죽음.
- **영향:** 화선 아닌 죽음을 **가짜 화선 신호로 오해** 가능.
- **대응:** **온도 교차검증**으로 이미 부분 방어(직전 고온 없으면 화선 아님으로 분류). 시뮬로 **무작위 비화재 사망** 주입해 오탐/오추정 확인(B). ← 이게 오탐 방어의 진짜 시험대.

### A-7. 재라우팅 실지연
- **시뮬 "100ms"는 틱값**(성능 아님). **실물에서 처음 실측**(Phase C). 발표선 이 구분 명확히.

### A-8. 전력 브라운아웃
- **실물:** WiFi 송신 순간 전류 급증 → 전압 강하 → 리셋 가능. **대응:** 5V 승압·충분한 전원, 필요 시 커패시터.

## B. 구현 지시서 #2c — 위 위험을 시뮬로 정량화

**목표:** A에서 뽑은 실물 위험 중 **시뮬로 미리 잴 수 있는 것**을 주입해 강건성·오탐을 측정. (measure-first: 방어 파라미터·추정기 불변)

**주입할 새 요인(환경만 어렵게):**
1. **시계 지터:** 각 노드의 죽은 시각에 노드별 오프셋(정규분포, 표준편차 스윕 0/50/100/300ms) 추가 → 방향·속도 추정오차 곡선.
2. **온도 노이즈·지연:** 임계 감지 시각에 지터(0/0.2/0.5s) → 위와 결합.
3. **비화(spot fire):** 전선 진행 중 확률적으로 앞쪽에 **새 발화점** 생성 → 추정 붕괴 지점 확인(국소 방향오차 분포).
4. **비화재 사망:** 매 시나리오에 화선 무관 노드 사망을 확률적으로 주입 → **오탐률/오추정** 측정(온도 교차검증이 거르는지).

**측정:** 각 요인 강도별 방향·속도 오차(±std), 오탐률, 커버리지. **작동 한계선에 신규 축 추가.**

**완료 기준(DoD):**
1. 4개 요인 스윕 실행 → `results/stress/`에 CSV·곡선 추가.
2. STRESS_REPORT에 신규 축 결과 + **"시계 지터 X ms까지 실용" 같은 한계선** 서술.
3. 특히 **비화재 사망에서 오탐 방어가 작동하는지** 명시(작동/한계).
4. DECISIONS(D-026~)·PROGRESS 갱신. **파라미터·추정기 불변**(measure-first).

**하지 말 것:** 결과 나쁘다고 파라미터 튜닝 금지(기록만). 추정기 알고리즘 변경 금지(개선은 별도). 실물/펌웨어 손대지 않음.
