# 협업 핸드오프 규칙 — Cowork(기획·설계) ↔ Claude Code(구현) 동기화
### 화중생련 「불사」 / 두 AI가 아는 내용이 어긋나지 않게 하는 최소 안전장치

> **문제:** 나(Cowork)와 Claude Code(터미널 코딩)는 서로의 대화를 못 본다.
> 각자 다른 걸 알게 되면 설계와 코드가 어긋난다.
> **해결 원칙:** "기억은 사람 머리나 채팅이 아니라 **레포 안 문서(docs/)에 있다.**" 둘 다 그 문서를 읽고 쓴다.

---

## 1. 단일 진실 원천(Single Source of Truth) = 레포의 `docs/` 폴더

레포 안에 아래를 둔다. 이게 두 AI의 **공용 뇌**다.
```
docs/
├── 프로젝트헌장_v3_통합.md        # 무엇을·왜 (설계 확정본)   ← 주로 Cowork가 갱신
├── 구현지시서_1_...md              # 어떻게 (모듈 명세)         ← 주로 Cowork가 갱신
├── DECISIONS.md                    # 결정 로그(선택+이유)       ← 둘 다 추가
└── PROGRESS.md                     # 진행 로그(한 것·바뀐 것·미해결) ← 주로 Claude Code가 갱신
```

- **DECISIONS.md** = "왜 이렇게 정했나"를 한 줄씩 쌓는 곳. (예: "언어는 Python — 팀 단독·빠른 검증 위해.")
- **PROGRESS.md** = "지금 어디까지 됐고, 지시서와 뭐가 달라졌고, 막힌 게 뭔지." Claude Code가 작업 후 매번 갱신.

---

## 2. 두 도구의 역할 경계 (겹치면 어긋난다)

- **Cowork(나):** 헌장·지시서·문서·신청서/보고서·알고리즘 설계·자료조사·리허설. → `docs/`의 헌장·지시서를 쓴다.
- **Claude Code:** 실제 코드·git·실행·디버깅·하드웨어. → 코드와 `PROGRESS.md`를 쓴다.
- **철칙:** 설계를 바꾸고 싶으면 코드부터 고치지 말고 **먼저 문서(헌장/지시서/DECISIONS)를 고친 뒤** 구현한다.

---

## 3. 오갈 때의 "복붙 규칙" (사용자가 실제로 할 일)

두 도구를 오갈 때, 최신 상태를 **파일로 들고 다닌다.** (사람이 다리 역할)

**Cowork → Claude Code 로 갈 때:**
1. 최신 `구현지시서`(+필요시 `헌장`)를 Claude Code에 준다.
2. "먼저 `docs/`의 헌장과 지시서를 읽고 시작해. 작업 후 `PROGRESS.md`와 `DECISIONS.md`를 갱신해."라고 지시.

**Claude Code → Cowork(나) 로 돌아올 때:**
1. `PROGRESS.md`와 `DECISIONS.md`(코드가 지시서와 달라진 부분 포함)를 나에게 붙여준다.
2. "여기까지 진행됐어. 지시서와 달라진 점 반영해서 다음 단계 설계해줘."라고 요청.
→ 이러면 내가 코드 현재 상태에 맞춰 다시 동기화된다.

---

## 4. 어긋남 감지 신호 (이러면 동기화 필요)

- 내가 설명하는 구조와 실제 코드 파일/함수 이름이 다르다.
- Claude Code가 "지시서엔 없는데 이렇게 했다"고 한다.
- 같은 용어를 둘이 다르게 쓴다(예: 나는 estimator, 코드엔 predictor).
→ 이때는 **PROGRESS.md를 나에게 보여주고 재동기화.** 용어는 지시서 표기를 정본으로 통일.

---

## 5. Claude Code에게 줄 시작 지시(복붙용 템플릿)

```
이 레포의 docs/ 폴더에 프로젝트 헌장(v3)과 구현지시서 #1이 있어.
① 먼저 그 두 문서를 읽고 요약해줘.
② 지시서 #1대로 sim/ 시뮬레이터와 estimator를 구현해줘.
③ 작업하면서 내린 선택은 docs/DECISIONS.md에, 진행 상황·지시서와 달라진 점은
   docs/PROGRESS.md에 계속 기록해줘.
④ 지시서와 다르게 구현할 필요가 생기면, 코드보다 먼저 그 이유를 DECISIONS.md에 적고 진행해.
```

_핸드오프 규칙 확정 / 기억은 docs/에, 사람이 파일로 다리 역할, 용어는 지시서가 정본._
