#   - Python 3.11 이상 (OS 기본 python3 로 충분)
#   - sudo apt install -y python3-pip python3-venv
#   - 시리얼 포트 권한:  sudo usermod -a -G dialout $USER   (재로그인 필요)
#     ※ 이거 안 하면 /dev/ttyUSB0 열 때 Permission denied 가 난다.
#   - 포트 이름이 다르다: Windows COM3  ->  파이 /dev/ttyUSB0 (CP210x)
#     `--port auto` 를 쓰면 이름을 몰라도 role=ROOT(bridge) 로 찾는다.
#   - Bookworm 은 PEP668 로 시스템 pip 를 막는다. venv 를 쓰거나
#     `pip install --break-system-packages -r gateway/requirements.txt`
